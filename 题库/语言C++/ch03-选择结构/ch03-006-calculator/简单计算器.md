# 讲解稿：简单计算器（ch03-006）

## 一、题目解读

实现一个四则运算计算器：输入"数 运算符 数"，输出结果。另有两个特殊要求：除数为 0 输出 `Divided by zero!`；运算符不是 +−*/ 输出 `Invalid operator!`。这是课件例 3.10，本章的综合收官题——**switch 语句 + 异常情况处理**一起考。

## 二、思路分析

按运算符分四种情况。多路分支当然可以用 if / else if 链，但当"分支依据是同一个变量的不同取值"时，C++ 提供了更清爽的写法——**switch**：

```
switch (op) {
    case '+': ...; break;
    case '-': ...; break;
    ...
    default:  ...;
}
```

除了正常四路，还有两个"防御点"：
1. 除法前必须**先检查除数**是否为 0——顺序不能反，先除后判就已经出错了（整数除 0 是运行时错误，程序直接崩溃 RE）；
2. `default` 分支兜底所有非法运算符——**永远给意外情况留一条出路**，这是程序健壮性的第一课。

## 三、代码讲解

```cpp
int a, b;
char op;
cin >> a >> op >> b;
switch (op)
{
case '+': cout << a + b << endl; break;
case '-': cout << a - b << endl; break;
case '*': cout << a * b << endl; break;
case '/':
    if (b == 0) cout << "Divided by zero!" << endl;
    else        cout << a / b << endl;
    break;
default:
    cout << "Invalid operator!" << endl;
}
```

三个要点：
- **读入技巧**：`cin >> a >> op >> b` —— cin 读 char 时自动跳过空格，所以"3 + 5"能正确拆成三份。这是 cin 的便利之处；
- **break 千万别丢**！switch 的 case 像多米诺骨牌，没有 break 会"贯穿"到下一个 case 继续执行——输入 `3 + 5` 会把加减乘除全输出一遍。每写一个 case，顺手写上 break；
- case 标签里是**字符常量** `'+'`（单引号），不是字符串 `"+"`（双引号）。

除法结果按整数除法（`10 / 3 = 3`），题面已说明，不要画蛇添足输出小数。

## 四、易错点

1. **丢 break**——switch 第一大坑，症状是多输出了几行。
2. 除 0 判断放在除法之后，或者干脆没判——测试点 `5 / 0` 直接让程序 RE。
3. 特殊输出的拼写：`Divided by zero!`、`Invalid operator!` 大小写、空格、感叹号必须一字不差。
4. `case "+"` 用了双引号——编译错误。

## 五、小结

switch 适合"一个变量、多个离散取值"的分支；case 必配 break；default 兜底非法输入；危险操作（除法）前先检查。这道题的"先判错、再计算"思维，就是以后写所有健壮程序的雏形。第 3 章到此完结——程序已经会"选择"了，下一章让它学会"重复"。
