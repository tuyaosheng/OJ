# 装备品质判定——讲解稿

## 一、题目解读

按战力值给装备"定色"，五个区间五种颜色——标准的**分段判断**，和成绩转等级、阶梯计费是同一个模型，只是换了游戏的皮。

## 二、思路分析

区间**从小到大**排好，用 if - else if 链：

- 第一个条件 `v < 100`；
- 之后每个 `else if (v < 上界)`——能走到这里，说明前面的条件都不成立，也就是 v 已经 ≥ 上一个上界了，**不用重复写下界**；
- 最后一个 `else` 兜底（≥1000）。

## 三、代码讲解

对着标程注意两点：

1. 五个分支**只会进一个**——else if 链是"互斥"的，这正是它和五个独立 if 的区别；
2. 输出的是中文文本，写在双引号里原样输出即可。

## 四、易错点

1. 区间顺序打乱（先判 `v < 600` 再判 `v < 100`）→ 低战力全被吞进蓝色；
2. 边界归属：100 属于绿色不属于白色——条件用 `<` 还是 `<=` 要对着表抠；
3. 每个分支重复写下界（`v >= 100 && v < 300`）不算错，但冗余且容易写错——利用 else if 的隐含条件。

## 五、小结

"查表定级"型题目 = 区间排序 + else if 链 + 边界抠字眼。下次见到个税、快递计费，直接套。
