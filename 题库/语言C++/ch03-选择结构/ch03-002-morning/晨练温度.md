# 讲解稿：晨练温度（ch03-002）

## 一、题目解读

温度 t 在 25 到 30 度之间（含两端）适合晨练，输出 ok，否则输出 no。考点只有一个，但极其重要：**区间判断怎么写**。

## 二、思路分析

数学里我们写 25 ≤ t ≤ 30，一个式子搞定。但 C++ **不能**照抄！

如果写 `if (25 <= t <= 30)`，编译器不报错，程序却是错的。它的实际执行顺序是：先算 `25 <= t`，结果是 0（假）或 1（真）；再拿这个 0 或 1 去和 30 比——0 和 1 都小于等于 30，所以**整个条件永远为真**！输入 -100 它也说 ok。

正确写法是把区间拆成两个条件，用**逻辑与 `&&`**（读"并且"）连接：

`t >= 25 && t <= 30`

两个条件**同时**成立，整体才成立。

## 三、代码讲解

```cpp
if (t >= 25 && t <= 30)
    cout << "ok" << endl;
else
    cout << "no" << endl;
```

顺便把逻辑运算符一家三口都认识一下：
- `&&`（与）：两边都真才真——"既要……又要……"；
- `||`（或）：有一边真就真——"要么……要么……"；
- `!`（非）：真变假、假变真——"不是……"。

比如"不适合晨练"也可以写成 `t < 25 || t > 30`（太冷**或**太热）。注意它和 `&&` 版本刚好是一对"反面"，这就是逻辑上的德摩根定律，感兴趣的同学可以自己验证。

## 四、易错点

1. `25 <= t <= 30` 连写——本题第一大坑，必考。
2. 边界取舍：25 和 30 都算适合（`>=`、`<=` 带等号）。测试点专门放了 25、30、24、31 四个边界值，差一个等号就挂两个点。
3. `&&` 写成 `&`：单个 `&` 是位运算，含义完全不同。

## 五、小结

区间判断 = 两个条件 + `&&`。边界值是否含等号，一定回题面确认。出题人最爱在边界上埋测试点——以后你们自己出数据，也要学会这一招。
