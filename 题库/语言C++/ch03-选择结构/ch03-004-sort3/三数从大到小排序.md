# 讲解稿：三数从大到小排序（ch03-004）

## 一、题目解读

输入三个整数，按从大到小输出。上一题只要"最大值"，这一题要**全部排好序**——这是我们人生中第一道排序题。

## 二、思路分析

用"比较-交换"法，三步走：

1. 比较 a、b：如果 a < b，交换它们 → 保证 **a ≥ b**；
2. 比较 a、c：如果 a < c，交换它们 → 保证 **a ≥ c**。此时 a 同时不小于 b 和 c，**a 已是最大**；
3. 比较 b、c：如果 b < c，交换它们 → 保证 **b ≥ c**。

三次比较后 a ≥ b ≥ c，按顺序输出即可。

为什么这样一定对？用"不变式"思维想：第 1、2 步把最大的顶到 a 的位置（像冒泡一样"冒"上去），第 3 步再把剩下两个排好。这正是**冒泡排序在 n=3 时的样子**——到第 5 章你会见到它的完整版。

## 三、代码讲解

```cpp
if (a < b) { t = a; a = b; b = t; }
if (a < c) { t = a; a = c; c = t; }
if (b < c) { t = b; b = c; c = t; }
cout << a << " " << b << " " << c << endl;
```

- 交换用的还是第 2 章的三变量法（`t` 是临时变量）；
- 每个 if 带一对花括号 `{}`——**交换的三条语句必须都归 if 管**。如果不写花括号，if 只管第一条语句，后两条无条件执行，数据就乱了。这是"复合语句"的第一次实战。

测试点设计：`9 9 9`（全相等，不该发生任何交换出错）、`3 3 1`（两个相等）、`1 2 3`（完全逆序，三次交换全触发）、含负数和极值。

## 四、易错点

1. **忘写花括号**：`if (a < b) t = a; a = b; b = t;` 是重灾区——后两句每次都执行。
2. 三次比较的顺序不能乱：必须先把最大的顶到 a，最后比 b、c。若先比 b、c 再比 a、b，会出现排不完整的情况（如 3 1 2）。
3. 输出中间的空格别漏。

## 五、小结

三句"比较-交换"完成三数排序，本质是冒泡排序的雏形；花括号决定 if 管辖几条语句——这两个知识点都是后面大章节的地基。课后挑战：改成从小到大输出，想想每个 `<` 要不要换方向？
