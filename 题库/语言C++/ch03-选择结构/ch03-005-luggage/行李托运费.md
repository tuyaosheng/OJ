# 讲解稿：行李托运费（ch03-005）

## 一、题目解读

飞机托运行李：不超过 20 公斤，每公斤 1.68 元；超过 20 公斤，**整个重量**按每公斤 1.98 元。输入重量，输出费用（保留两位小数）。这是课件例 3.5，是一道"分段计费"问题——生活里的水费、电费、个税都是这个模型。

## 二、思路分析

题意的关键：费率取决于重量在哪个区间，**整段重量用同一个费率**（注意本题不是"超出部分"按高价，审题！）：

- w ≤ 20：费用 = w × 1.68
- w > 20：费用 = w × 1.98

一个 if/else 就分好段。边界 w = 20 归哪边？题面说"小于等于 20 公斤时按 1.68"，所以 20 走低价档——**边界归属永远以题面为准**，测试点必卡 20 这个点（20 × 1.68 = 33.60，如果你写成 `w < 20`，就会输出 39.60，一分没有）。

## 三、代码讲解

```cpp
double w, cost;
cin >> w;
if (w <= 20)
    cost = w * 1.68;
else
    cost = w * 1.98;
cout << fixed << setprecision(2) << cost << endl;
```

- 重量是实数（样例有 20.5），所以用 **double**；
- 这次保留两位小数用的是 **cout 的方式**：`fixed << setprecision(2)`，需要包含头文件 `<iomanip>`。它和第 2 章学的 `printf("%.2f")` 效果一样，两种都要会：
  - `fixed`：固定小数点格式（不用科学计数法）；
  - `setprecision(2)`：小数点后 2 位（四舍五入）。
  - 注意这两个设置**一直生效**，设置一次后面输出都按这个格式。

## 四、易错点

1. 边界 `w <= 20` 写成 `w < 20`——20 公斤按错档计费。
2. 误解题意算成"超出部分 1.98"：20.5 公斤 ≠ 20×1.68 + 0.5×1.98。本题是整段换费率。
3. 忘了 `<iomanip>` 头文件，`setprecision` 编译不过。
4. 用 int 读重量，20.5 被截成 20。

## 五、小结

分段计费 = if/else 选费率；边界归属看题面；`fixed + setprecision` 是 cout 家的保留小数法。课后想一想：如果改成三段计费（≤20、20~50、>50 三种费率），if 该怎么写？（提示：if / else if / else 三连。）
