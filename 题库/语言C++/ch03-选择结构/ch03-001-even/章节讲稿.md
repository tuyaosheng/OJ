## 上课怎么开场

前两章写的程序，不管输入是什么，代码永远是"从上到下、一条路走到底"。今天要打破这件事。黑板上写一句生活里的话："明天如果下雨，就带伞；不下雨，就不带。" 问学生："这句话有几种可能的结果？" ——两种，但**具体走哪一种，要等明天早上看了天气才知道**。这就是"分支"：程序不再是一条直线，而是一个岔路口，走哪条路取决于当时的条件。

C++ 里最基本的岔路口就是 `if...else`，今天这一章，从最简单的两岔路口，一路学到能同时处理好几条岔路的 `switch`。

## if 与条件表达式：这章最凶的坑先摆出来（例1）

判断一个数是不是偶数：

```cpp
if (n % 2 == 0) cout << "yes";
else            cout << "no";
```

拿 `n=7` 走一遍：`7 % 2 = 1`，`1 == 0` 不成立，条件为假，走 `else`，输出 `no`。再拿 `n=8` 走一遍：`8 % 2 = 0`，`0 == 0` 成立，条件为真，走 `if`，输出 `yes`。到这里学生都能懂，真正要停下来讲的是另一件事。

在黑板上把 `==` 悄悄改成 `=`：`if (n = 1) cout << "yes";`。问学生："这句话能编译通过吗？会输出什么？" ——**能编译通过，而且不管 n 原来是几，都会输出 yes**。因为 `n = 1` 不是在"比较"，是在"赋值"，赋值表达式本身的值就是被赋的那个值（这里是 1），而 C++ 里非 0 就是"真"，所以这个 `if` 条件永远成立。这是本章最凶的一个坑：**`==` 是比较，`=` 是赋值，一个字符之差，代码却"看起来完全正常"，编译器不会替你报错**，只能靠自己盯着看。

切到 `分支路径演示.html` 的"偶数判断"页签，输入 7 和 8 各跑一遍，看流程图上那个判断框怎么根据条件真假点亮不同的路径，最后停在对应的输出框上。

## 逻辑运算组合条件（练1 铺垫）

有时候一个条件不够用，需要"并且"（`&&`）、"或者"（`||`）、"取反"（`!`）组合起来。晨练温度这道题：`25 ≤ t ≤ 30` 才适合晨练。数学上这样写没问题，但**C++ 里绝对不能写成 `25 <= t <= 30`**——它会先算 `25 <= t` 得到一个 0 或 1，再拿这个 0/1 去和 30 比，逻辑完全变了。正确写法是拆成两个条件用 `&&` 连起来：

```cpp
if (t >= 25 && t <= 30) cout << "ok";
else                     cout << "no";
```

拿 `t=27` 走一遍：`27>=25` 真，`27<=30` 真，两个都真，`&&` 结果为真，输出 `ok`。再拿 `t=32` 走一遍：`32>=25` 真，`32<=30` 假，一真一假，`&&` 结果为假，输出 `no`。顺手把闰年判断这个经典组合背下来：`(y%4==0 && y%100!=0) || y%400==0`——这是逻辑运算组合条件的标准范例，以后见到"既要满足这个又要排除那个"的题目就套这个思路。

## 打擂台：从两个数扩展到 n 个数（例2）

三个数求最大值，与其套嵌套 `if`，更推荐"打擂台"的写法：先让第一个数"站上擂台"当擂主，后面的数一个个来"挑战"，打得过就换擂主：

```cpp
int mx = a;
if (b > mx) mx = b;
if (c > mx) mx = c;
```

拿 `a=3, b=9, c=5` 走一遍：`mx=3`；`b>mx` 即 `9>3` 成立，`mx` 换成 `9`；`c>mx` 即 `5>9` 不成立，`mx` 保持 `9`。最终输出 `9`。再拿一组 `a=9, b=2, c=15` 走一遍，让第三个数才是真正的冠军：`mx=9`；`2>9` 不成立，`mx` 仍是 `9`；`15>9` 成立，`mx` 换成 `15`。最终输出 `15`。

问一句能让学生眼前一亮的问题："如果题目给的不是 3 个数，是 300 个数呢？" ——嵌套 `if` 写 300 层想都不敢想，但打擂台只要"再来一个数就再挑战一次"，这正好是第 5 章数组和循环要解决的事，打擂台的思路今天先埋进脑子里。

## if-else if 链与分段问题（例3）

有些题目的规则是"分段"的：行李托运费，`w ≤ 20` 公斤按每公斤 1.68 元收费，超过 20 公斤按每公斤 1.98 元收费：

```cpp
if (w <= 20) cost = w * 1.68;
else         cost = w * 1.98;
```

拿 `w=15` 走一遍：`15<=20` 成立，`cost = 15*1.68 = 25.2`，保留两位小数输出 `25.20`。再拿 `w=35` 走一遍：`35<=20` 不成立，走 `else`，`cost = 35*1.98 = 69.3`，输出 `69.30`。

这道题恰好只分两段，但**分段的思路不会因为段数变多而变复杂**——如果以后见到阶梯电费、个人所得税这类分三段、四段的题目，写法是完全一样的 `if / else if / else if / .../ else` 链，唯一要注意的是：**区间必须从小到大依次判断，每一个 `else if` 已经隐含了"前面的条件都不满足"，不需要在条件里重复写下限**，比如判断完 `w<=20` 之后，紧接着的 `else if (w<=50)` 其实已经等价于"20 < w <= 50"，不用再手写一遍 `w>20`。边界值该归哪一段，**必须一个字一个字照着题面来**，不能凭直觉猜。

切到 `分支路径演示.html` 的"行李托运费"页签，输入 15 和 35 各跑一遍，看流程图里那个判断框怎么把两种重量分流到不同的计费公式上。

## switch 多路分支（例4）

按运算符 `+ - * /` 做加减乘除，四选一用 `switch` 比一长串 `else if` 清爽得多：

```cpp
switch (op) {
    case '+': cout << a + b; break;
    case '-': cout << a - b; break;
    case '*': cout << a * b; break;
    case '/':
        if (b == 0) cout << "Divided by zero!";
        else        cout << a / b;
        break;
    default: cout << "Invalid operator!";
}
```

拿 `a=6, op='+', b=3` 走一遍：命中 `case '+'`，输出 `9`，遇到 `break` 跳出 `switch`。再拿 `a=6, op='/', b=0` 走一遍：命中 `case '/'`，**这个分支里面还嵌套了一层判断**——`b==0` 成立，输出 `Divided by zero!`；如果 `b` 不是 0，才会走 `a/b`。再拿一个不认识的符号，比如 `op='?'`：四个 `case` 都对不上，落到 `default`，输出 `Invalid operator!`。

现在故意在黑板上把 `case '+'` 后面的 `break;` 擦掉，问学生："`op='+'` 时还会输出 `9` 吗？" 会，但**紧接着会不停手地往下"贯穿"进 `case '-'` 继续执行**，同样拿 `a=6,b=3` 走一遍：先输出 `9`，然后没有 `break` 拦住，接着执行 `cout << a - b`，又多输出了一个 `3`。屏幕上凭空多出一行谁都没料到的内容，这就是"漏 `break`"的真实后果——**本章第二凶残的坑**，`switch` 里每一个 `case` 用完都要主动 `break`，`default` 因为在最后一个可以省略。

切到 `分支路径演示.html` 的"简单计算器"页签，先跑一遍正常的 `+`，再跑一遍 `/` 且除数为 0，最后跑一遍非法符号，让学生看着流程图上那个 `switch` 分支框，是怎么把请求"甩"到 5 条路里的某一条上的，`/` 那条路走到一半还会再岔出一层。

## 三数排序：比较-交换链（练2，预告冒泡排序）

三个数从大到小排序，套路是连续三次"比较，不对就交换"：

```cpp
if (a < b) swap(a, b);   // 保证 a >= b
if (a < c) swap(a, c);   // 保证 a >= c，此时 a 已经是最大的
if (b < c) swap(b, c);   // 保证 b >= c，三个数排好序
```

拿 `a=3, b=9, c=5` 走一遍：第一步 `a<b` 即 `3<9` 成立，交换后 `a=9, b=3`；第二步 `a<c` 即 `9<5` 不成立，不动；第三步 `b<c` 即 `3<5` 成立，交换后 `b=5, c=3`。最终 `a=9, b=5, c=3`，从大到小排好了。这三步"比较+交换"的写法，就是第 12 章要学的冒泡排序在三个数上的缩影——今天先在小范围里把手感练熟，以后扩展到 n 个数只是换成循环去重复它。

## 学生最容易栽的坑

1. `==` 写成 `=`——条件恒为真，编译器不报错，最难自己发现的坑；
2. `switch` 漏 `break` 贯穿到下一个 `case`；`case` 后面只能接常量，不能是变量或表达式；
3. `0 < x < 10` 的数学写法在 C++ 里是错的——先算 `0<x` 得到 0/1，再拿这个 0/1 去和 10 比；
4. else-if 链的区间顺序写乱，或者边界值归属想当然，没有照着题面一个字一个字核对；
5. 除法忘了先判断除数是不是 0；
6. 浮点数比较相等不要用 `==`（要用 `fabs(a-b) < 1e-6`，本章点到为止，后面章节会正式用到）。
