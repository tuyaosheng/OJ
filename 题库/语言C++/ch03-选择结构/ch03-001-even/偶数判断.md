# 讲解稿：偶数判断（ch03-001）

## 一、题目解读

读入一个整数，是偶数输出 yes，否则输出 no。这是我们的第一道"程序会拐弯"的题——之前的程序都是一条道走到黑，从今天起，程序能**根据条件选择不同的路**。

## 二、思路分析

什么是偶数？能被 2 整除的整数。"能被 2 整除"翻译成 C++ 就是：除以 2 的余数为 0，即 `a % 2 == 0`。

于是逻辑是：**如果** a % 2 == 0，输出 yes；**否则**输出 no。这个"如果……否则……"就是 if/else 语句，程序从此有了两条分支，走哪条由条件的真假决定。

## 三、代码讲解

```cpp
if (a % 2 == 0)
    cout << "yes" << endl;
else
    cout << "no" << endl;
```

- `if (条件)`：条件写在圆括号里，成立就执行紧跟的语句；
- `else`：条件不成立时执行；
- **`==` 是"判断相等"，`=` 是"赋值"**——写成 `if (a = 0)` 是初学者最经典的 bug：它把 0 赋给 a，条件恒为假，编译器还不报错！

再说一个隐藏考点：本题 a 可能是**负数**。`-8 % 2` 等于 0，所以负偶数判断不受影响；但如果你习惯用 `a % 2 == 1` 判断奇数，负奇数就出事了——`-7 % 2` 在 C++ 里等于 **-1**，不等于 1！所以判断奇偶的标准姿势是：**与 0 比较**（`== 0` 是偶，`!= 0` 是奇）。测试点里的 -7、-8 就是专门查这个的。

## 四、易错点

1. `=` 与 `==` 混用。
2. 用 `a % 2 == 1` 判断奇数，被负数卡掉。
3. if 后多写分号：`if (a % 2 == 0);` ——这个分号是一条空语句，后面的输出会无条件执行。

## 五、小结

if/else 让程序学会"选择"。记住两条军规：判断相等用 `==`；判断奇偶与 0 比较。下一题我们让条件更复杂——两个条件同时满足才行。
