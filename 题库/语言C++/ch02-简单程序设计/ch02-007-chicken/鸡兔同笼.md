# 讲解稿：鸡兔同笼（ch02-007）

## 一、题目解读

笼子里有鸡有兔，数头共 h 个，数脚共 f 只，问鸡兔各几只。这是我国古代《孙子算经》里的名题，也是课件例 2.3（那里 h=30、f=90）。我们的版本把数字改成输入，数据保证有解。

## 二、思路分析

设鸡 j 只、兔 t 只，列方程组：
- 头：j + t = h
- 脚：2j + 4t = f

课件教的是"假设法"，特别适合心算：**假设笼里全是鸡**。那么应该只有 2h 只脚；可实际有 f 只，多出来 f − 2h 只。为什么会多？因为有些"鸡"其实是兔——每把一只鸡换成兔，脚多 2 只。所以：

**兔 t = (f − 2h) ÷ 2，鸡 j = h − t。**

验证课件数据：h=30、f=90 → t = (90−60)÷2 = 15，j = 15。鸡兔各 15 只。✓

注意：这是 O(1) 的公式解。有同学可能想"枚举鸡的数量从 0 到 h 挨个试"——也对，但那是第二部分"枚举算法"的思路。**能用数学消元直接算的，就不要枚举**——数学永远是最快的算法。

## 三、代码讲解

```cpp
long long h, f;
cin >> h >> f;
long long t = (f - 2 * h) / 2;   // 兔
long long j = h - t;             // 鸡
cout << j << " " << t << endl;
```

- 公式翻译成代码只有两行，功夫全在纸面推导上；
- h 最大 10⁶，f 最大 4×10⁶，其实 int 也够，用 long long 是"保险写法"——数据范围临界时不纠结，直接上 long long；
- 题目保证 2h ≤ f ≤ 4h 且 f 为偶数，所以 t 一定是 0 到 h 之间的整数，不需要判无解。想想两个端点：f = 2h 时全是鸡，f = 4h 时全是兔——这两种极端正是测试点。

## 四、易错点

1. 公式记反：把 (f − 2h)/2 当成鸡——代入样例查一遍就能发现，**写完公式先带样例验算**。
2. 输出顺序：题目要求先鸡后兔。
3. 如果题目不保证有解（f 是奇数、或 t 算出负数/超过 h），就要输出无解——本题不需要，但要有这根弦，第 3 章学了 if 就能处理。

## 五、小结

本题是第 2 章的收官综合题：方程建模 → 消元化简 → 顺序结构实现。"假设法"的本质是解二元一次方程组，古人没有代数也能算出来，我们用 C++ 一行搞定。记住今天的方法论：**先数学、后编程；先推导、后验算。** 下一章学选择结构，我们就能处理"无解要报告"这类分情况讨论的问题了。
