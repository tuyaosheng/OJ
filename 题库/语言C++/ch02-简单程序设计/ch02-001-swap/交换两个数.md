# 讲解稿：交换两个数（ch02-001）

## 一、题目解读

输入两个数 A 和 B，交换它们的值再输出。这是课件例 2.1，看似简单，却是程序设计里最经典的入门问题——"交换"这个动作，以后在排序算法里要做成千上万次。

## 二、思路分析

课件里有个绝妙的比喻：一瓶酱油和一瓶醋要互换瓶子，直接倒行不行？不行，会混在一起。正确做法是**先拿来一个空瓶子**：

1. 把酱油倒进空瓶（`t = a`）；
2. 把醋倒进原来的酱油瓶（`a = b`）；
3. 把空瓶里的酱油倒进原来的醋瓶（`b = t`）。

三步完成，谁也没混。这个"空瓶子"就是**临时变量**。

有同学会问：直接写 `a = b; b = a;` 行不行？我们模拟一下：a=3、b=8。执行 `a = b` 后 a 变成 8——注意，a 原来的 3 **已经被覆盖，永远找不回来了**；再执行 `b = a`，b 得到的是 8。结果两个都是 8。这就是为什么必须先"备份"。

## 三、代码讲解

```cpp
int a, b, t;
cin >> a >> b;
t = a;               // ① 备份 a
a = b;               // ② b 的值放进 a
b = t;               // ③ 备份的原 a 值放进 b
cout << a << " " << b << endl;
```

赋值语句 `x = y` 的本质：把右边的**值复制一份**放进左边的变量，右边不变，左边原值被覆盖。理解了"覆盖"，就理解了为什么需要第三个变量。

另外偷偷说一句：本题输出其实等价于"先输出 B 再输出 A"，直接 `cout << b << " " << a` 也能过。但请大家老老实实写三步交换——我们练的是"交换"这个基本功，不是投机取巧。

## 四、易错点

1. `a = b; b = a;` 两步交换——最典型的逻辑错误，输出两个相同的数。
2. A、B 最大 10 亿，int 够用（上限约 21.4 亿），但要有意识地看一眼数据范围。
3. 两数相等时（如 7 7）交换后还是 7 7，程序不需要特殊处理——这也是测试点之一。

## 五、小结

三变量交换法：`t=a; a=b; b=t;`——请把它练成条件反射。第二部分学排序算法时，冒泡排序的核心动作就是不停地交换相邻元素，到时候你会感谢今天打下的基础。
