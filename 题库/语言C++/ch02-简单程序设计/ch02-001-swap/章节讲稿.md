## 上课怎么开场

上一章会"读进来、算一下、打出去"了。这一章把中间那个"算一下"展开来讲：**数据是有类型的，类型决定了它能存什么、算出来的是什么**。而讲类型之前，得先把一件更基础的事情讲透——**赋值到底在干什么**。

黑板上写：`a = 3, b = 5`。问学生："现在我想让 a 变成 5、b 变成 3，交换一下，怎么写？" 十有八九会有人脱口而出：`a = b; b = a;`。别急着否定，就让他把这两行的效果**在黑板上一步步算给全班看**。

第一步 `a = b;`：把 b 的值（5）复制一份塞进 a。此刻 `a = 5, b = 5`——注意，a 原来的 3 已经**永久消失**了，没人记得它了。第二步 `b = a;`：把 a 的值（现在已经是 5 了）复制给 b。结果 `a = 5, b = 5`，两个变量都变成了 5！

问一句："b 该变成的 3 去哪了？" 学生这时候才反应过来：**`a = b` 不是数学课上的"相等"，是"把右边的值抄一份，覆盖到左边"**。覆盖是不可逆的操作，一旦执行，被覆盖的旧值就彻底没了，除非你提前把它存到别的地方。

## 交换两个数：为什么必须借一个空杯子（例1）

题面给了一个很形象的比方：想象一瓶酱油和一瓶醋要互换瓶子，直接倒来倒去肯定会混在一起——**你需要先拿来一个空瓶子**。程序里这个"空瓶子"就是一个临时变量：

```cpp
int t = a;   // 第一步：把 a 的值先倒进临时杯 t，留个备份
a = b;       // 第二步：把 b 的值倒进 a
b = t;       // 第三步：把 t 里存的原始 a 值倒进 b
```

拿 `a=3, b=5` 走一遍，列成表格，一行行看变量怎么变：

```
              a     b     t
初始状态      3     5     ?
int t = a;    3     5     3     ← 备份完成，t 里存着 a 原来的 3
a = b;        5     5     3     ← a 被覆盖成 5 也没关系，3 已经在 t 里存好了
b = t;        5     3     3     ← 把备份取出来交给 b，交换完成
```

和刚才那个错误写法对比着看：**多的这一句 `int t = a;`，就是"覆盖前先备份"**。这是本章要建立的第一个、也是最重要的编程直觉：**任何时候要修改一个变量，先想一下它现在的值还有没有用，有用就先存起来**。

切到 `变量交换动画.html`，先点开"错误写法"页签，输入 3 和 5，一步步点"下一步"，让学生亲眼看着 b 格子在第二步"悄悄"变成了 5——原来的 5 没丢，丢的是本该属于 b 的那个 3。再切到"正确写法"页签，同样的初始值，看 t 格子是怎么在第一步就把 3 稳稳接住的，交换才真正成立。

## 整数类型与整除、取余（例2）

`int` 能存的范围大约是 ±21 亿，超过这个数就要换 `long long`（这件事现在先点一句，第 11 章讲高精度的时候还会回来收这个坑）。

带余除法（例2）是上一章 `/` 和 `%` 的直接延伸，拿 `a=17, b=5` 走一遍：`17 / 5` 整数除法舍去小数得 `3`，`17 % 5` 取余得 `2`。别忘了那条恒等式：`17 = 3×5 + 2`，即 `a = a/b*b + a%b` 永远成立，这是检验自己写没写错的最快方法。

再教一个以后天天用的技巧——**拆位三件套**。拿 `n = 738` 举例：

```
n % 10   = 738 % 10 = 8     ← 个位
n / 10   = 738 / 10 = 73    ← 去掉个位后剩下的数
73 % 10  = 3                ← 也就是 (n/10)%10，十位
n / 100  = 738 / 100 = 7    ← 也就是 n/100%10，百位
```

个位永远是 `n%10`；想拿十位，先用 `n/10` 把个位"切掉"，再 `%10` 拿新的个位；百位同理再切一层。这套"先除掉低位、再取余拿新低位"的操作，后面数字类题目（反转三位数、数位和、回文数）几乎每题都要用。

## 浮点数与输出格式（例3）

圆柱体表面积公式：`S = 2×π×r² + 2×π×r×h`，题目里 π 取 `3.14159`。拿 `r=2, h=5` 手算一遍：

```
上下底面积：2 × 3.14159 × 2² = 2 × 3.14159 × 4 = 25.13272
侧    面积：2 × 3.14159 × 2 × 5              = 62.83180
总    面积：25.13272 + 62.83180 = 87.96452
保留 3 位小数：87.965
```

代码里对应两句：`double s = 2*PI*r*r + 2*PI*r*h;` 算出 `87.96452`，`cout << fixed << setprecision(3) << s;` 才是"保留 3 位小数"这四个字真正对应的代码——**`fixed` 和 `setprecision` 要搭配着用，只写 `setprecision` 是控制"有效数字位数"，不是"小数位数"**，这是本节最容易混的一个点，得在黑板上把两种效果都写一遍对比。

顺带把整数除法的坑再钉一遍：如果两个整数相除想要一个小数结果，**至少要有一边先变成浮点数**，比如 `1.0 * a / b`，直接 `a / b` 只会得到整数商。

## 字符类型与 ASCII（例4）

`char` 本质就是一个"很小的整数"。黑板上写：`'A'` 对应 `65`，`'a'` 对应 `97`，`'0'` 对应 `48`。让学生自己推一下：既然 `'0'` 是 `48`、`'7'` 是 `55`，那 `'7' - '0'` 算出来是多少？——`55 - 48 = 7`，正好是这个数字字符对应的数值！这就是**数字字符转数值的标准写法 `c - '0'`** 的道理所在，不是死记硬背的公式，是两个 ASCII 码相减。

大小写互转同理：`'a' - 'A' = 97 - 65 = 32`，所以大写转小写是 `c + 32` 或者写成 `c - 'A' + 'a'`（后者更不容易记错方向）。代码里 `char` 参与算术会自动升级成 `int`，想直接看到某个字符的编号，强制转换一下：`cout << (int)ch;`。

## 用公式代替蛮力：鸡兔同笼（练3）

这是本章"从算术走向代数"的关键一题。题目给了一个具体例子：`h=30` 个头、`f=90` 只脚，答案是鸡兔各 15 只。别急着列方程，先用**假设法**带学生手推一遍：

"假设笼子里全是鸡，`30` 个头就该有 `30×2=60` 只脚。可题目说实际有 `90` 只脚，多出了 `90-60=30` 只。这多出来的 30 只脚是怎么来的？——因为每被"换成"一只兔子，就比鸡多出 2 只脚。所以兔子数量就是 `30÷2=15` 只，鸡的数量是总头数减去兔子数：`30-15=15` 只。"

翻译成公式，跟假设法一一对应：

```cpp
long long t = (f - 2*h) / 2;   // 多出来的脚数 ÷ 2 = 兔子数
long long j = h - t;           // 总头数 - 兔子数 = 鸡数
```

代入验证：`t = (90-60)/2 = 15`，`j = 30-15 = 15`，和题目给的答案完全对上。**能推出一个公式直接算，就不要写循环一只只去试**——这是"程序设计"和"用程序硬算"的第一次分道扬镳，后面章节还会反复强调这个取舍。

## 学生最容易栽的坑

1. 三步交换顺序写错（比如先 `a=b` 再 `int t=a`），临时变量存的已经是被覆盖后的值，等于白存；
2. `1/2 = 0`：整数除法陷阱，浮点场合记得乘 `1.0`；
3. `%` 只能用于整数，对 `double` 用会编译错误（要用 `fmod`，本章不要求）；
4. `printf("%.2f")` 对应的变量必须是 `double`，`%d` `%f` 混用会输出乱值；
5. π 的取值按题面给的位数来，多写少写都可能 WA；
6. 鸡兔同笼要判**无解**（算出负数或除不尽）——边界意识从现在开始建立。
