# 讲解稿：打印ASCII码（ch02-006）

## 一、题目解读

输入一个可见字符，输出它的 ASCII 码。比如输入 `A`，输出 65。这道题一行代码就能解决，但它背后的概念——**字符的本质是整数**——是整个字符串处理的地基。

## 二、思路分析

计算机里没有"字符"，只有数字。ASCII 码表就是一张"字符 ↔ 整数"的对照表：`'0'` 是 48，`'A'` 是 65，`'a'` 是 97，空格是 32。

C++ 的 char 类型占 1 个字节，存的就是这个整数。所以 char 可以直接参与算术运算：
- `'a' + 1` 等于 98，也就是 `'b'`；
- `'z' - 'a'` 等于 25——两个字符相减得到它们在字母表里的距离；
- 大小写转换：`'A' + 32 = 'a'`（课件例 2.7 讲的就是这个）。

本题只需要"把 char 当 int 看"这一步。

## 三、代码讲解

```cpp
char ch;
cin >> ch;
cout << (int)ch << endl;
```

关键在 `(int)ch`——**强制类型转换**：临时把 ch 的值当作 int 类型使用。为什么必须转？因为 `cout << ch` 会按"字符"打印出 `A`，而 `cout << (int)ch` 按"整数"打印出 65。**同一块内存，解释方式不同，输出就不同**——这是理解类型系统的钥匙。

也可以不用转换，赋值给 int 变量：`int x = ch; cout << x;`，效果一样。

三个必背锚点：`'0'`=48、`'A'`=65、`'a'`=97。有了锚点，其他字符都能推出来（数字和字母在表里是连续排列的）。

## 四、易错点

1. 分不清 `5` 和 `'5'`：前者是整数 5，后者是字符，ASCII 码 53。`'5' - '0' == 5`——字符转数字的经典技巧，必须掌握。
2. `cout << ch` 忘了转 int，输出的是字符本身。
3. `cin >> ch` 会自动跳过空格和换行，本题输入保证是非空格可见字符，正好安全。

## 五、小结

一句话总结：**char 就是小整数**。三个锚点值 48 / 65 / 97 背下来。后面第 7、8 章处理字符串时，"字符算术"（判断大小写、转数字、加密移位）全是今天这个知识点的延伸。课后自测：不查表，说出 `'C'` 和 `'c'` 的 ASCII 码。（答案：67 和 99。）
