# 讲解稿：圆柱体的表面积（ch02-004）

## 一、题目解读

输入圆柱体的底面半径 r 和高 h（都是实数），求表面积，保留 3 位小数，π 取 3.14159。这是课件例 2.2，考三样东西：**实数运算、符号常量、格式化输出**。

## 二、思路分析

圆柱体表面积拆成三块：上底 + 下底 + 侧面。
- 上、下底都是圆：各 π r²，共 2πr²；
- 侧面展开是长方形：长是底面周长 2πr，宽是高 h，面积 2πrh。

合起来：**S = 2πr² + 2πrh**（也可以提公因式写成 2πr(r + h)，计算量更小）。

用样例验证：r=3.5、h=9 → S = 2×3.14159×3.5×(3.5+9) = 274.889125 → 保留 3 位小数得 274.889。✓

## 三、代码讲解

```cpp
const double PI = 3.14159;

int main()
{
    double r, h;
    scanf("%lf%lf", &r, &h);
    double s = 2 * PI * r * r + 2 * PI * r * h;
    printf("%.3f\n", s);
    return 0;
}
```

重点讲 `const double PI = 3.14159;` 这行——**符号常量**：
1. `const` 表示"常量"，定义后不许再修改，误改会被编译器当场抓住；
2. 写 PI 比满篇 3.14159 **可读性**强；
3. 如果题目要求 π 换成 3.1415926，只需改这一处——**易改性**。
课件的习惯是常量名全大写（PI），变量名小写（r、h），一眼区分。

`%.3f` 表示保留 3 位小数输出（自动四舍五入）。r² 写成 `r * r` 即可，不需要调用幂函数。

## 四、易错点

1. **π 的取值必须按题目来**：本题指定 3.14159，如果你用 3.14 或 M_PI（3.1415926…），部分测试点会因小数位差异判错。
2. 忘记乘 2（只算了一个底面）——公式抄错是几何题的头号失分点。
3. 输出保留位数不对：`%.3f` 的 3 别写错。
4. 用 int 读入 r、h——它们是实数（样例就是 3.5），必须 double + `%lf`。

## 五、小结

本题三个收获：实数题一律 double；固定不变的数学常数用 `const` 定义成符号常量；`printf("%.nf")` 控制小数位数。这套组合拳在所有几何计算题里通用。课后思考：如果再让你求圆柱体**体积**（πr²h），代码要改哪一行？
