# 伤害结算——讲解稿

## 一、题目解读

把游戏的伤害公式直接翻译成一行算式：`atk * mult - def`。难点不在算，在**类型**和**输出格式**。

## 二、思路分析

- atk、def 是整数，mult 是小数——所以 mult 必须用 `double` 存；
- `atk * mult`：整数遇到浮点，C++ 会自动把整数"升格"成浮点再算，结果是 double；
- 题目要求保留两位小数，这是**输出格式**问题，不是计算问题。

## 三、代码讲解

两种输出写法都要会：

```cpp
printf("%.2f\n", damage);                          // C 风格
cout << fixed << setprecision(2) << damage << endl; // C++ 风格，要 #include <iomanip>
```

`scanf` 读 double 用 `%lf`，输出用 `%f`——这一对经常被写反。

## 四、易错点

1. mult 用 int 存 → 1.50 变成 1，全错；
2. `%.2f` 写成 `%.2d` 或对 int 用 `%f` → 输出乱值；
3. 忘了保留两位：120 和 120.00 在评测里不是一回事。

## 五、小结

"整数×小数保留两位"是浮点题的最小模型，后面算平均分、算面积都长这样。
