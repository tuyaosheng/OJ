# 讲解稿：带余除法（ch02-003）

## 一、题目解读

给定被除数和除数，输出整数商和余数。题面特意强调"使用默认的整除和取余运算，无需特殊处理"——这句话是在提示：本题就是要你观察 C++ 的 `/` 和 `%` 在各种输入下（尤其是**负数**）的原生行为。

## 二、思路分析

正数情况大家都熟：17 ÷ 5 = 商 3 余 2。

重点是负数：**-17 ÷ 5 在 C++ 里商是多少？**

数学老师可能告诉你：-17 = 5 × (-4) + 3，商 -4 余 3（余数非负）。
但 C++ 的规则是"**向零取整**"：-17 / 5 = -3.4，把小数砍掉、朝 0 的方向取，得 **-3**；余数则由恒等式 `a == a/b*b + a%b` 倒推：-17 - (-3)×5 = -2，所以 `-17 % 5 == -2`。

记忆口诀：**商向零取整，余数符号跟着被除数走。**

## 三、代码讲解

```cpp
int a, b;
cin >> a >> b;
cout << a / b << " " << a % b << endl;
```

代码就两行，本题的"知识含量"全在规则里：

- `a / b`：整数除法，直接砍小数（不是下取整！下取整是朝负无穷方向，C++ 是朝零方向，负数时两者不同）；
- `a % b`：满足 `a == a/b*b + a%b` 的那个余数；
- 测试点里有 `-17 5`，期望输出 `-3 -2`——如果你手工按数学习惯写了"调整余数为正"的代码，反而会错。

## 四、易错点

1. 自作主张把余数调成非负——题目明说了"无需特殊处理"。
2. 被除数最大 10 亿，int 尚可容纳；但如果两个数相乘就会溢出——本题没有乘法，安全。
3. 除数保证非零，所以不用判 0；但要养成习惯：**看到除法先想"除数会不会是 0"**。

## 五、小结

C++ 整除向零取整、余数同被除数符号——这个细节在竞赛里坑过无数人（尤其是负数下标、循环数组的场合）。以后遇到"把 % 的结果调成非负"的需求，标准写法是 `(a % b + b) % b`，先记下来，学到同余和哈希时会派上大用场。
