# 讲解稿：计算(a+b)×c的值（ch02-002）

## 一、题目解读

读入三个整数 a、b、c，输出 (a + b) × c。题目本身不难，它真正考的是两件事：**运算符优先级**和**负数参与运算**。

## 二、思路分析

表达式怎么写？照抄数学式：`(a + b) * c`。

问题来了：括号能不能省？不能！C++ 的优先级和数学一样，乘法高于加法。`a + b * c` 会先算 `b * c`，完全是另一道题。**题目给了括号，代码里就保留括号。**

再看数据范围：a、b、c 的绝对值都小于 10000。最坏情况 (9999 + 9999) × 9999 ≈ 2 亿，int（约 ±21.4 亿）装得下，不用 long long。这个"最坏情况估算"每道题都要做一遍，防止溢出。

## 三、代码讲解

```cpp
int a, b, c;
cin >> a >> b >> c;
int ans = (a + b) * c;
cout << ans << endl;
```

值得注意的是**负数**：本题 a、b、c 都可能是负数。C++ 的加法和乘法对负数完全按数学规则处理，比如 (-5 + 3) × 4 = -8，程序不需要任何特判——这正是测试点里放负数的原因：验证你没有画蛇添足。

## 四、易错点

1. 丢括号写成 `a + b * c`——样例都过不了（样例 2 3 5：正确答案 25，错误写法算出 17）。
2. 把乘号写成 `x` 或 `×`。
3. 想当然地加 `abs()` 或对负数特殊处理——不需要，直接算。

## 五、小结

本题记两条：优先级拿不准就加括号；拿到题先用最坏数据估算结果范围，决定用 int 还是 long long。顺便预告：如果把式子换成 (a + b) ÷ c，就有新故事了——那是下一题"带余除法"的内容。
