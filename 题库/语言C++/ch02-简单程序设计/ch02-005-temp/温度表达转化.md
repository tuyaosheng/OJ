# 讲解稿：温度表达转化（ch02-005）

## 一、题目解读

给一个华氏温度 F，用公式 C = 5 × (F − 32) ÷ 9 换算成摄氏温度，保留 5 位小数。公式题面直接给了，看起来"抄公式"就行——但这道题埋着 C++ 最著名的一个陷阱。

## 二、思路分析

陷阱就在 `5 / 9` 这三个字符上。

如果有同学写 `c = 5 / 9 * (f - 32);`，会发现**输出永远是 0**。为什么？`5` 和 `9` 都是整数，`5 / 9` 按整数除法算，商 0——后面乘什么都是 0。

怎么避免？三种写法任选：
1. 调整运算顺序：`5 * (f - 32) / 9`——先算 `5 * (f-32)`，f 是 double，结果是 double，再除以 9 就是浮点除法；
2. 把常数写成小数：`5.0 / 9 * (f - 32)`；
3. 强制类型转换：`(double)5 / 9 * (f - 32)`。

标程用第 1 种。核心规则：**两个 int 相除是整除；只要有一边是浮点数，就是浮点除法。**

## 三、代码讲解

```cpp
double f;
scanf("%lf", &f);
double c = 5 * (f - 32) / 9;
printf("%.5f\n", c);
```

按运算顺序拆解：`f - 32` 是 double；`5 * (f-32)` int 乘 double 自动提升为 double；再 `/ 9` 也是浮点除法。全程没有整除，精度安全。

几组有意义的数据：32°F → 0°C（冰点）；212°F → 100°C（沸点）；98.6°F → 37°C（体温）；-459.67°F → -273.15°C（绝对零度，也是题目给的输入下界）。测试点正是用这些"有物理意义的值"设计的。

## 四、易错点

1. `5 / 9` 整数除法得 0——本题第一大坑，务必理解。
2. 保留 5 位小数：`%.5f`，别写成 `%.2f`。
3. 输入可能是负数、小数，用 double + `%lf` 读。

## 五、小结

记住一句话：**整数 ÷ 整数 = 整数（截断），想要小数就让至少一边是浮点。** 这个坑从入门到省选都在坑人。附加练习：把程序反过来写——输入摄氏输出华氏（F = 9×C÷5 + 32），检验自己是否真的掌握。
