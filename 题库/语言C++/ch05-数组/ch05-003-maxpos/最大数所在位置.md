# 讲解稿：最大数所在位置（ch05-003）

## 一、题目解读

n 个数存进数组，输出**最大数第一次出现的位置**（下标从 1 数）。课件例 5.5 原题，样例：`67 43 90 78 32` 中最大是 90，位置 3。

第 4 章"数据统计"我们边读边求最值、不用数组；这题为什么要数组？因为要的是**位置**——而且是"第一次出现"的位置，需要下标参与打擂台。

## 二、思路分析

打擂台升级版：擂台上现在站着**两个人**——最大值 maxa 和它的位置 k。每个挑战者 a[i] 上台：

- 如果 `a[i] > maxa`：值和位置**一起**更新（`maxa = a[i]; k = i;`）；
- 否则：什么都不做。

"第一次出现"怎么保证？全靠比较符号——**严格大于 `>`**：后面出现相等的最大值时，`a[i] > maxa` 不成立、不更新，位置停留在第一次。反过来，若题目要"最后一次出现的位置"，把 `>` 改成 `>=` 即可。**一个等号，控制"取首个还是取末个"**——这是面试和竞赛都爱考的细节。

## 三、代码讲解

```cpp
int maxa = a[1], k = 1;
for (int i = 2; i <= n; i++)
    if (a[i] > maxa)
    {
        maxa = a[i];
        k = i;          // 值和位置必须同步更新
    }
cout << k << endl;
```

- 初值取第一个元素及位置 1（老规矩：初值来自数据本身，全负数据不翻车）；
- 花括号不能省：两条更新语句都归 if 管；
- 测试点 `9 9 1 9`：最大值 9 出现三次，正确答案 1——专门验收"严格大于"。

## 四、易错点

1. `>=` 和 `>` 用错——多个最大值时位置输出成最后一次。
2. 只更新 maxa 忘更新 k（或反之）——花括号丢失的典型后果。
3. 位置从 0 数起——题目要求从 1 开始，输出差 1。
4. 数组开小于 10000。

## 五、小结

打擂台可以同时守护多个信息（值 + 下标）；`>` 与 `>=` 决定"首个还是末个"。这套模板延伸一下就是"次大值""最大值与最小值的距离"等一票题目。课后练手：同时输出最大数第一次**和**最后一次出现的位置。
