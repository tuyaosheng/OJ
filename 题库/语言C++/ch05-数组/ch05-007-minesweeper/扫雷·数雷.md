# 扫雷·数雷——讲解稿

## 一、题目解读

还原扫雷的棋面：雷照印，空地印"周围 8 格的雷数"。输入是字符网格，输出也是字符网格——**二维数组的读、算、写**一条龙。

## 二、思路分析

对每个格子独立处理即可，没有任何全局依赖：

1. 是雷 → 输出 `*`；
2. 是空地 → 检查周围 8 格，逐个数 `*`。

n、m ≤ 100，每格最多查 8 个邻居，总量 100×100×8 = 8 万次，毫无压力。

## 三、代码讲解

核心是"**偏移量枚举**"：

```cpp
for (int dx = -1; dx <= 1; dx++)
    for (int dy = -1; dy <= 1; dy++)
```

3×3 = 9 种组合去掉 (0,0) 正好 8 个方向。比写 8 个 if 干净得多，而且这个写法在第 15 章搜索（迷宫、连通块）里就是**方向数组**的前身——现在练熟，将来白捡。

**越界判断**必须放在访问 `g[ni][nj]` 之前：角上的格子只有 3 个邻居，不判越界就是数组越界，出鬼都查不出来。

## 四、易错点

1. 忘了跳过 (0,0)——把自己也数进去；
2. 越界判断漏了某一边（四个条件一个都不能少）；
3. 读入用 `cin >> g[i]` 整行读（char 数组），不要逐字符混着 `cin.get` 折腾；
4. 输出的数字和 `*` 之间**没有**空格，紧挨着拼成一行。

## 五、小结

二维网格 + 邻域统计 = 扫雷模型。记住偏移量双循环，第 15 章的迷宫搜索会再见到它的进化版。
