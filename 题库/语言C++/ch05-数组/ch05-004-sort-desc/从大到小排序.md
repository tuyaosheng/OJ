# 讲解稿：从大到小排序（ch05-004）

## 一、题目解读

n 个整数，从大到小输出。课件例 5.6（十个正整数）的一般化。今天正式学习**冒泡排序**——第 3 章"三数排序"埋的伏笔，现在收网。

## 二、思路分析

冒泡排序的画面感：一排气泡，大的轻、往上冒。具体规则：

- **一轮**：从头到尾，相邻两个两两比较，前面的比后面的小就交换。一轮结束，**最小的沉到了最底**（本题从大到小排，"底"就是末尾）；
- **重复 n−1 轮**：每轮把当前剩余里最小的沉底一个，n−1 轮后全体有序。

拿 `5 3 8` 走一遍第一轮：比 (5,3) 不换 → 比 (3,8) 换 → 变成 `5 8 3`，最小的 3 沉底；第二轮比 (5,8) 换 → `8 5 3`。完成。

复杂度：两层循环约 n²/2 次比较，n=1000 时 50 万次——完全够快。等 n 到 10 万，n² 就是 100 亿，那时就得请出快速排序/`sort` 函数了（第二部分"数据排序"章再讲）。

## 三、代码讲解

```cpp
for (int i = 1; i < n; i++)             // 第 i 轮（共 n-1 轮）
    for (int j = 1; j <= n - i; j++)    // 只比到 n-i：后面 i 个已就位
        if (a[j] < a[j + 1])            // 从大到小：前小后大就换
        {
            int t = a[j];
            a[j] = a[j + 1];
            a[j + 1] = t;
        }
```

两处精华：
- 内层上界 **`n - i`**：第 1 轮沉底 1 个，第 2 轮时最后 1 个已经就位、不用再比……每轮少比一个。写成 `j < n` 也对，只是白比；但写成 `j <= n` 就**越界**了——比较 a[n] 和 a[n+1]；
- 排序方向由比较符决定：`a[j] < a[j+1]` 时交换 → 大的往前 → 从大到小。想从小到大，换成 `>` 即可。**记方向不如记规则："想让谁在前，就在'谁不在前'时交换"**。

测试点：含重复值（3 3 1 3 2——相等不交换，照样排对）、负数、已有序（最好情况）、n=1、n=1000 随机大数据。

## 四、易错点

1. 内层边界 `j <= n` 越界，或 `j <= n-i` 写成 `j <= i`。
2. 交换三句缺花括号。
3. 比较方向搞反，排成从小到大。
4. 输出行尾多空格。

## 五、小结

冒泡排序：n−1 轮、每轮相邻比较交换、内层递减。它慢，但"比较-交换"的思想是一切排序的起点，也是必考的手写排序。课后自检：在纸上对 `4 1 3 2` 完整模拟两轮，写出每步的数组状态——能默写过程，才算真会。
