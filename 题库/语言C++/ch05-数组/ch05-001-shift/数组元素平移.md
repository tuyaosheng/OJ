# 讲解稿：数组元素平移（ch05-001）

## 一、题目解读

把数组第一个元素挪到末尾，其余整体前移一位：`1 2 3 4 5` 变 `2 3 4 5 1`。课件例 5.2 原题。这是数组的"搬运"基本功——**批量移动元素**，以后的插入、删除操作全是它的变体。

## 二、思路分析

跟第 2 章"交换两个数"神似：直接挪会把数据踩坏，所以先把 a[1] 存进临时变量 temp"避难"，腾出位置后大家依次前移，最后 temp 落到末尾。三步：

1. `temp = a[1]`；
2. 对 i = 1..n-1 执行 `a[i] = a[i+1]`；
3. `a[n] = temp`。

**方向是命门**：前移必须**从前往后**做。想象一排人往前挪座位——必须第 2 个人先坐到 1 号位，第 3 个再坐 2 号位……如果反着来（先 a[n-1]=a[n]），前面的值还没搬走就被覆盖了。口诀：**往前挪，从前扫；往后挪，从后扫。**这个方向感在"插入元素"（要后移腾位）时还会反过来考你。

## 三、代码讲解

```cpp
int temp = a[1];
for (int i = 1; i < n; i++)
    a[i] = a[i + 1];
a[n] = temp;
```

- 数组下标从 1 用起（`int a[105]` 开大 5 个），和题面"a[1] 至 a[n]"对齐，少一层换算心智负担；
- 循环条件 `i < n`：最后一次是 `a[n-1] = a[n]`，i 到 n-1 为止。写成 `i <= n` 会访问 a[n+1]——**数组越界**，OJ 上轻则答案错、重则 RE；
- 输出用 `if (i > 1) cout << " ";` 的方式控制空格——行尾不留空格的标准写法，本章每题都用它。

边界测试点 n=1：循环一次不走，temp 又放回原位，输出不变——正确。好代码常常"天然处理"边界，不需要补丁。

## 四、易错点

1. 挪动方向反了——输出变成一串重复的 a[n]。
2. 不用 temp 直接挪——a[1] 原值丢失。
3. 循环边界差一（`i <= n`）——越界。
4. 行尾多空格。

## 五、小结

数组搬运三件套：临时变量保底、方向从前往后、边界差一要抠。把这题改成"最后一个元素移到开头"（反向平移），方向就得倒过来——课后写写看，方向感立刻见分晓。
