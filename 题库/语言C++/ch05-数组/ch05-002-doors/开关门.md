# 讲解稿：开关门（ch05-002）

## 一、题目解读

n 扇门全关着。第 i 个服务员把 i 的倍数号的门全部"反转"（开↔关），i 从 1 到 n。问最后哪些门开着。课件例 5.3（n=100）的一般化。这是 **bool 数组模拟**的招牌题，结局还藏着一个漂亮的数学彩蛋。

## 二、思路分析

每扇门只有开/关两种状态——**bool 数组**天生就是干这个的：`door[j]` 为 true 表示开。

模拟过程是双重循环：
- 外层 i = 1..n：第 i 个服务员；
- 内层 j = i, 2i, 3i, …：他碰的门——**从 i 出发、步长为 i**（`j += i`），这是"枚举倍数"的标准姿势，比"对每扇门判断 j % i == 0"快得多（总操作数是 n/1 + n/2 + … + n/n ≈ n·ln n，n=10000 时约 10 万次，瞬间跑完）。

反转一扇门一行搞定：`door[j] = !door[j];`——逻辑非运算符让 true/false 互换。

## 三、代码讲解

```cpp
bool door[10005];                     // 全局数组自动全 false（关）
for (int i = 1; i <= n; i++)
    for (int j = i; j <= n; j += i)   // i 的倍数
        door[j] = !door[j];
```

讲两个细节：
- **全局数组自动清零**——放在 main 外面的数组，所有元素初始为 0/false。局部数组则是随机值，要手动初始化。这是很多人栽过的暗坑；
- 内层 `j += i` 而不是 `j++`：步长踩着倍数走。

**数学彩蛋**：跑 n=100 会输出 1 4 9 16 25 36 49 64 81 100——全是完全平方数！道理：j 号门被反转的次数 = j 的约数个数；约数总是成对出现（d 和 j/d），只有完全平方数的 √j 和自己配对、约数个数为奇数——反转奇数次才开着。**先模拟看结果，再回头想数学**，这是信奥里非常宝贵的探索路径：程序是你的实验室。

## 四、易错点

1. 内层用 `j++` 加 `if (j % i == 0)`——能对，但 O(n²)，n=10000 时 10⁸ 次就慢了；步长法才是正解。
2. 数组开小（n 最大 10000，至少开 10001）。
3. 局部 bool 数组没初始化——初始状态就是乱的。
4. 输出格式：编号之间一个空格，行尾无空格。

## 五、小结

bool 数组存状态、`j += i` 枚举倍数、`!` 做反转——三个新工具入库。更重要的收获是方法论：**模拟出结果 → 观察规律 → 数学解释**。下次遇到猜不透的题，先写个暴力模拟"做实验"，往往就有灵感了。
