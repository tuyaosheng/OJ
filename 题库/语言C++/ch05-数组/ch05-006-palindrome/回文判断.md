# 讲解稿：回文判断（ch05-006）

## 一、题目解读

判断一个字符串正读反读是否一样：`12321`、`ABCBA` 是回文，`abca` 不是。课件例 5.12 的变体（原题以"."结尾，我们直接读一个完整字符串，更贴近现代写法）。本章收官题，主角是**字符数组/string** 和大名鼎鼎的**双指针**。

## 二、思路分析

朴素想法：把字符串反转一份，比较两串是否相等——可行，但要多一份存储和一次拷贝。

更漂亮的是**双指针**：既然回文是"对称"，那就直接检查对称位置——

- i 指向头（0），j 指向尾（len−1）；
- 比较 s[i] 与 s[j]：不等 → 立刻宣判"不是回文"；相等 → i 右移、j 左移，继续比内圈；
- 直到 i ≥ j（指针相遇或交错），全程无异议 → 是回文。

每对字符只看一次，扫到一半就结束，还能提前退出——**对称问题，两头夹逼**，这个思想以后在有序数组找数对、快排划分里反复登场，今天是它的首秀。

## 三、代码讲解

```cpp
string s;
cin >> s;
int i = 0, j = s.length() - 1;
bool ok = true;
while (i < j)
{
    if (s[i] != s[j]) { ok = false; break; }
    i++;
    j--;
}
```

- **string 类型**：可以像数组一样用 `s[k]` 取字符（下标从 0 开始），长度是 `s.length()`；
- 循环条件 `i < j`：奇数长度时最中间的字符不用比（自己跟自己永远相等），偶数长度时 i、j 交错即停——一个条件通吃两种长度；
- 标志变量 + break：和"区间素数"同款结构，找到反例立刻收工；
- 边界：长度为 1 的串（测试点 `A`），i=0、j=0，循环直接不进——输出 yes，正确。大小写敏感：`Aa` 不是回文（'A' 和 'a' 的 ASCII 码不同，第 2 章的知识联动）。

## 四、易错点

1. j 初值写成 `s.length()`——忘了减 1，比到字符串外面。
2. 循环条件写 `i <= j`——不算错（中点自比恒真），但理解上要清楚为什么 `<` 就够。
3. 只比了首尾一对就下结论——必须循环夹逼到底。
4. 用 `int len = s.length()` 时注意 length() 返回无符号类型，空串 `-1` 会变天文数字（本题长度 ≥1，无此险情，但埋个印象）。

## 五、小结

双指针三步：两头站位、逐对比较、相遇收兵。string + 下标访问让字符题和数组题打通。第 5 章至此完结——你已经手握循环、分支、数组、字符串四大件，第一部分剩下的章节是给这套装备装"函数化"和"工程化"的外挂。
