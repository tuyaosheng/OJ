# 讲解稿：杨辉三角（ch05-005）

## 一、题目解读

打印杨辉三角前 n 行：两端全是 1，中间每个数等于"肩上"两数之和。课件例 5.11（前 10 行）的一般化。这是**二维数组**的第一道招牌题，也是"递推"思想的启蒙——用已算出的一行，推出下一行。

## 二、思路分析

把三角形靠左放进二维数组 a\[i\]\[j\]（第 i 行第 j 个）：

- **边界**：`a[i][1] = a[i][i] = 1`（每行头尾）；
- **递推**："肩上两数"翻译成下标——正上方偏左是 `a[i-1][j-1]`，正上方是 `a[i-1][j]`，于是

  `a[i][j] = a[i-1][j-1] + a[i-1][j]`

按 i 从小到大填表：算第 i 行时，第 i−1 行已经填好了——**先有边界，再按顺序递推**，这个套路第二部分"递推算法"一整章都在用，今天是预告片。

数据范围小算一笔账：第 30 行中间的数是 C(29,14) ≈ 7756 万，int 放得下；标程用 long long 上双保险——**递推数列涨得快，类型宁大勿小**。

## 三、代码讲解

```cpp
for (int i = 1; i <= n; i++)
{
    a[i][1] = a[i][i] = 1;                    // 两端
    for (int j = 2; j < i; j++)               // 中间（第1、2行没有中间）
        a[i][j] = a[i-1][j-1] + a[i-1][j];    // 肩上两数之和
}
```

- 内层 `j` 从 2 到 i−1：i=1、2 时这个循环一次都不走——只有两端的 1，天然正确；
- 连续赋值 `a[i][1] = a[i][i] = 1;` 一行搞定两端（i=1 时其实是同一个格子，赋两次也无妨）；
- 输出仍用 `if (j > 1) cout << " ";` 控制行内空格。

杨辉三角的身份彩蛋：第 i 行第 j 个数正是组合数 C(i−1, j−1)；每行的和是 2^(i−1)。学到计数与二项式定理时，这张表会一再出现。

## 四、易错点

1. 递推式下标写错（如 `a[i-1][j+1]`）——打印出来一眼歪。
2. 忘了先设两端的 1 就去递推——用到未初始化的值。
3. 数组开小：至少 a\[31\]\[31\]，标程开 35 留余量。
4. n 上限再大一点（40 行）int 就会溢出——换 long long 的警觉要有。

## 五、小结

二维数组 = 表格，行列下标各管一维；递推 = 边界打底 + 顺序填表。杨辉三角是"用空间记住历史，用历史算出未来"的最小示范——这句话就是动态规划的胚芽。课后把输出改成"只打印第 n 行"，想想还需要二维数组吗？（提示：滚动一行就够。）
