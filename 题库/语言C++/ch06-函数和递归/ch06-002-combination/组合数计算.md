# 讲解稿：组合数计算（ch06-002）

## 一、题目解读

求组合数 C(m, n)——从 m 个不同东西里取 n 个的方案数，公式 C(m,n) = m! / (n! × (m−n)!)。课件例 6.2。这题让我们体会函数的核心价值：**写一次，用多次**。

## 二、思路分析

公式里出现了三个阶乘：m!、n!、(m−n)!。难道要把求阶乘的循环抄三遍？当然不。把"求阶乘"封成一个函数 `fact(x)`，然后：

```
C = fact(m) / (fact(n) * fact(m-n))
```

一个函数调用三次，代码短、不易错、改一处全生效——这就是**复用**。

关键是数据范围：m 最大 20，20! ≈ 2.4×10¹⁸，逼近 long long 上限（约 9.2×10¹⁸）但没超。所以 `fact` 的返回类型和累乘变量**必须是 long long**，用 int 早在 13! 就溢出了。

## 三、代码讲解

```cpp
long long fact(int x)
{
    long long s = 1;
    for (int i = 2; i <= x; i++) s *= i;
    return s;              // 0! = 1! = 1，循环不执行，直接返回初值 1
}

int main()
{
    int m, n;
    cin >> m >> n;
    long long ans = fact(m) / (fact(n) * fact(m - n));
    cout << ans << endl;
}
```

- `fact` 里 s 初值为 1（乘法的单位元），x 为 0 或 1 时循环不进、直接返回 1——**边界天然正确**，不用特判；
- 组合数一定是整数，所以 `fact(m) / (...)` 整除没有精度问题；
- 注意先算分母 `fact(n) * fact(m-n)` 再让分子除——加了括号保证顺序。

测试点覆盖 C(0,0)=1、C(20,0)=1、C(20,10)=184756、C(20,20)=1 等边界。

## 四、易错点

1. `fact` 用 int——13! 就溢出，中大数据全错。
2. 想"边乘边除"优化却处理不好整除，引入精度 bug——本题范围小，老老实实三个阶乘最稳。
3. 漏了 C(m,0)、C(m,m) 这些边界（=1），好在阶乘函数已天然处理。

## 五、小结

一个 `fact` 函数复用三次，就是"函数抽象"的威力。以后你会发现：好程序往往是一堆小函数搭起来的，每个函数只干一件事、干好一件事。数据范围决定返回类型——这根弦要一直绷着。
