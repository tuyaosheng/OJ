# 讲解稿：判断素数（函数版）（ch06-001）

## 一、题目解读

判断一个数是不是素数，是输出 yes，不是输出 no。第 4 章我们已经会判素数了，为什么再做一遍？因为这一章的主角是**函数**——今天要把"判素数"这段逻辑**打包成一个函数** `isPrime`，学会"造工具"。

## 二、思路分析

函数就像一台专用小机器：你给它一个输入（参数 n），它还你一个结果（返回值 true/false）。判素逻辑不变（试除法），变的是"组织方式"：

- 把逻辑封进 `bool isPrime(int n) { ... }`；
- 主函数只需一句 `if (isPrime(n))`，读起来像说人话。

好处有三：主函数干净、逻辑可复用（下次要判素直接调用）、便于单独调试。这就是**函数式抽象**——把"怎么做"藏进函数，主流程只关心"做什么"。

## 三、代码讲解

```cpp
bool isPrime(int n)
{
    if (n < 2) return false;               // 边界：1 及以下不是素数
    for (long long i = 2; i * i <= n; i++)
        if (n % i == 0) return false;      // 找到约数，立刻返回 false
    return true;
}
```

三个讲点：
- **返回类型 bool**：函数结论是"是/否"，用 bool 最贴切。`return` 一执行，函数立即结束并把值交回去；
- **边界在函数内部处理**：`n < 2` 直接 return false——把特判封在函数里，调用者就不用操心；
- **溢出陷阱**：n 可到 20 亿，`i * i` 若 i 是 int 会溢出（int 上限约 21 亿，i 到 ~46341 时 i*i 就爆了）。把 i 声明成 `long long`，或用 `i <= n / i` 避开乘法。这是数据范围警觉性的又一次实战。

## 四、易错点

1. 忘了 `n < 2` 的边界——把 1 或负数误判成素数。
2. `i * i` 用 int 溢出，大数据 WA。
3. 函数声明了返回 bool 却漏写某条 return 路径——有的编译器只警告，结果随机。确保每条分支都有返回值。

## 五、小结

函数三要素：参数（输入）、返回值（输出）、函数体（逻辑）。把常用逻辑封装成函数，是从"写代码"迈向"设计程序"的第一步。往后的 gcd、快速幂、判回文都会被我们做成函数，攒成自己的"工具箱"。
