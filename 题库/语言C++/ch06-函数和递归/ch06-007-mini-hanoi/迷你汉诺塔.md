# 迷你汉诺塔——讲解稿

## 一、题目解读

《原神》木偶齿轮谜题 = 汉诺塔。本题只问**最少步数**，不问过程——正适合本章练"把递推式写成递归函数"。

## 二、思路分析

为什么 T(n) = 2T(n−1) + 1？想最大的那个齿轮：它要从左柱到目标柱，必须先把压在它上面的 n−1 个**全部挪去中转柱**（T(n−1) 步），然后它自己走 1 步，最后那 n−1 个再**从中转柱挪到目标柱**（又 T(n−1) 步）。

三段加起来：T(n−1) + 1 + T(n−1)。

## 三、代码讲解

```cpp
long long T(int n) {
    if (n == 1) return 1;
    return 2 * T(n - 1) + 1;
}
```

递归两要素逐条对照：边界 n==1；调用时 n−1 规模严格变小。调用链是一条直线：T(60)→T(59)→…→T(1)，一共 60 层，然后一层层"归"回来把值算出去——线性递归，没有重复计算（对比递归斐波那契的指数爆炸，体会一下差别）。

数学上可以解出 T(n) = 2^n − 1；n=60 约 1.15×10^18，所以**返回值必须 long long**——递归写对了但返回 int，一样全错。

## 四、易错点

1. 返回类型写 int → n 大时溢出；
2. 边界写成 `n == 0 return 0` 也可以，但要保证递归到得了边界；
3. `2 * T(n-1)` 中 2 与 long long 相乘没问题，但若把中间结果存进 int 变量就前功尽弃。

## 五、小结

"递推式 → 递归函数"是一步直译。第 13 章会用递推数组再算它，第 14 章会把每一步怎么移完整输出——同一座塔，三个章节三个视角。
