# 讲解稿：递归求幂（ch06-004）

## 一、题目解读

用**递归**求 x 的 n 次方。课件例 6.10。这是我们第一道真正的递归题——函数**自己调用自己**。理解了它，就摸到了递归的门。

## 二、思路分析

递归的钥匙是"用自己定义自己"。x 的 n 次方可以这样拆：

- 当 n = 0：x⁰ = 1（这是**递归的尽头**，叫边界/终止条件）；
- 当 n > 0：xⁿ = x × xⁿ⁻¹（把问题**缩小一层**，交给自己去算）。

看，求 xⁿ 用到了 xⁿ⁻¹，而 xⁿ⁻¹ 又是同一个问题的更小版本——这就是递归。它像剥洋葱：一层层调用进去（n 递减），碰到 n=0 触底，再一层层把结果乘出来。

**每个递归函数必须有两部分：边界（何时停）和递推（如何缩小）**。缺了边界就会无限递归，直到栈溢出崩溃。

## 三、代码讲解

```cpp
long long power(int x, int n)
{
    if (n == 0) return 1;                    // 边界：触底返回
    return (long long)x * power(x, n - 1);   // 递推：调用自己算更小的
}
```

跟着 `power(2,3)` 走一遍，感受"进去再出来"：
- power(2,3) 要算 2 × power(2,2)
- power(2,2) 要算 2 × power(2,1)
- power(2,1) 要算 2 × power(2,0)
- power(2,0) = 1 ← 触底！开始往回返
- power(2,1) = 2×1 = 2
- power(2,2) = 2×2 = 4
- power(2,3) = 2×4 = 8 ✓

强转 `(long long)x` 保证乘法在 long long 下进行，防溢出（题目保证结果在 long long 内）。

## 四、易错点

1. **忘写边界** `if (n==0)`——无限递归，栈溢出（运行时崩溃）。这是递归第一大坑。
2. 递推没有"向边界靠近"：必须是 `power(x, n-1)`（n 减小），写成 `power(x, n)` 就永远到不了底。
3. 返回值溢出——不转 long long。

## 五、小结

递归 = 边界 + 递推。写递归先问两句话：**什么时候停？怎么把问题变小？**答得上来，代码几乎是照抄。递归威力巨大（汉诺塔、全排列、DFS 都是它），但也危险（忘边界就崩），务必先想清楚终止条件。下一题我们用递归重写辗转相除，再练一遍这套思维。
