# 讲解稿：最小公倍数（函数版）（ch06-003）

## 一、题目解读

求两个正整数的最小公倍数（LCM）。课件例 6.6。这题把"求最大公约数"做成函数，再用一条数学关系推出 LCM——函数 + 数学，配合默契。

## 二、思路分析

有个漂亮的定理：**两数之积 = 最大公约数 × 最小公倍数**，即 LCM(x,y) = x × y / GCD(x,y)。

所以只要能求 GCD，LCM 顺手就有。GCD 用**辗转相除法**（欧几里得算法）：不停用"大数除以小数取余数"，直到余数为 0，此时的除数就是 GCD。把它封成 `int gcd(int a, int b)`。

**溢出坑**：x、y 各到 10⁶，直接算 x × y = 10¹² 会爆 int。技巧是**先除后乘**：`x / gcd(x,y) * y`——因为 x 一定能被 gcd 整除，先除不丢精度，再乘 y 就把中间结果压小了。稳妥起见结果仍用 long long 存。

## 三、代码讲解

```cpp
int gcd(int a, int b)
{
    while (b != 0)
    {
        int r = a % b;
        a = b;
        b = r;
    }
    return a;                 // b 为 0 时 a 是 GCD
}
...
long long lcm = (long long)(x / gcd(x, y)) * y;
```

- 辗转相除的循环：每轮把 (a,b) 变成 (b, a%b)，余数越来越小直到 0；
- `(long long)(x / gcd) * y`：先整除再乘，且转成 long long 防溢出。对比错误写法 `(long long)x * y / gcd`——虽然结果对，但 `x * y` 若在转换前已按 int 算就已经溢出了（这里加了强转在前所以安全，但"先除后乘"是更保险的习惯）。

测试点含 `1000000 999999`（互质，LCM 就是乘积 999999000000，专门验收溢出处理）。

## 四、易错点

1. 直接 `x * y / gcd` 且不转 long long——中间乘积溢出。
2. gcd 函数写错终止条件（`while (b)` 等价 `while (b != 0)`，别写成 `while (a)`）。
3. LCM 结果用 int 存——10¹² 装不下。

## 五、小结

GCD 与 LCM 是数论的一对好基友，靠"积 = gcd × lcm"串联。辗转相除法是必背模板，本章还会用递归再写一遍（例 6.12）。记住"先除后乘防溢出"这个小技巧，很多计算题都用得上。
