# 讲解稿：子集和（ch06-006）

## 一、题目解读

给一个数组和目标值 m，问能否从数组里选若干个数，使它们的和恰好是 m。课件例 6.13。这是本章的压轴题，也是**递归搜索（DFS）**的启蒙——第 15 章"搜索与回溯"的雏形今天先见一面。

## 二、思路分析

前面几题的递归是"一条线往下钻"，这题的递归会**分叉**。关键洞察：对每一个元素，我们都面临一个二选一的决策——**选它，还是不选它？**

于是定义递归函数 `dfs(i, sum)`：表示"已经决定了前 i−1 个元素，当前选中的和是 sum，现在轮到考虑第 i 个"。它做两件事：
- **选**第 i 个：`dfs(i+1, sum + a[i])`；
- **不选**第 i 个：`dfs(i+1, sum)`。

两条分支都试，就把所有"选法组合"走遍了。边界：当 i 超过 n（所有元素都决定完了），检查 sum 是否等于 m。

n 个元素、每个两种选择，共 2ⁿ 种组合。n ≤ 20，2²⁰ ≈ 100 万，暴力枚举完全跑得动。这种"每步做选择、分叉搜索所有可能"就是 **DFS/回溯**的核心。

## 三、代码讲解

```cpp
void dfs(int i, long long sum)
{
    if (found) return;               // 剪枝：已找到就别再搜了
    if (i > n)                       // 边界：所有元素决定完毕
    {
        if (sum == m) found = true;
        return;
    }
    dfs(i + 1, sum + a[i]);          // 分支一：选第 i 个
    dfs(i + 1, sum);                 // 分支二：不选第 i 个
}
```

三个要点：
- **两次递归调用** = 两个分支，这是"分叉递归"和前几题"直线递归"的本质区别；
- **边界**在 `i > n`：走到头了才结算，检查 sum 是否命中 m；
- **剪枝** `if (found) return;`：一旦某条分支找到了答案，其余分支没必要再搜——用一个全局 bool 提前止损。虽然最坏还是 2ⁿ，但实际能快很多。

样例 `[3,34,4,12]` 求 7：选 3 和 4 就是 7，输出 YES。测试点里 `[1,2,4] 求 100` 怎么选都不够，输出 NO。

## 四、易错点

1. 只写一个分支（只选或只不选）——漏掉一半组合。必须两个分支都调用。
2. 边界条件 `i > n` 写成 `i >= n` 或 `i == n`——差一，会漏掉或重复处理最后一个元素。
3. sum 用 int——m 可到 10⁹，若干个大数相加会溢出，用 long long。
4. 忘记剪枝也能过（n 小），但养成"找到即止"的习惯对后面大搜索很重要。

## 五、小结

"每个元素选或不选 → 两路递归 → 搜遍所有子集"，这就是子集枚举的 DFS 框架。它是回溯算法的最简形态，第 15 章的八皇后、连通块、排列组合全都长在这个骨架上。第一部分的函数与递归到此收尾——你已经能"造工具"（函数）也能"分叉搜索"（递归），第二部分我们把这些武器用到真正的算法上。
