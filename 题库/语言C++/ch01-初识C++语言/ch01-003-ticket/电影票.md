# 讲解稿：电影票（ch01-003）

## 一、题目解读

一张电影票 10 元，x 个小朋友一起看电影，问总共要花多少钱。这是课件里的例 1.3，也是我们第一道**有输入**的题：x 不再是固定的，而是由评测机"喂"给程序的。

## 二、思路分析

解决问题分三步，这也是以后 90% 程序的通用套路：

1. **输入**：把人数 x 读进来；
2. **计算**：总票价 y = 10 × x；
3. **输出**：把 y 打印出去。

"输入 → 处理 → 输出"，记住这个三段式。

## 三、代码讲解

```cpp
int x, y;            // 先声明两个整型变量
cin >> x;            // 输入：>> 把键盘数据"流进"变量 x
y = 10 * x;          // 计算：乘号是 *，不能写成数学里的 ×
cout << y << endl;   // 输出
```

几个新知识点：
- `int x, y;` 表示声明两个整数变量。变量像一个"抽屉"，能存一个值，用之前必须先声明。
- `cin >> x` 与 `cout << y` 方向相反：`>>` 数据流**进**变量，`<<` 数据流**出**到屏幕。箭头方向就是数据流动方向，不会记混。
- `y = 10 * x` 中的 `=` 不是"等于"，是"赋值"——把右边算出来的结果放进左边的抽屉。

想想数据范围：x 最大 100000，总价最大 1000000（一百万），int 能存大约 ±21 亿，完全够用。**每次写题前都估一下结果会不会超 int，这个习惯现在就要养成。**

## 四、易错点

1. 输出时**只输出数字**，不要画蛇添足输出"总票价是"这几个字——OJ 会判错。
2. 乘法符号是 `*`，写 `10x` 或 `10·x` 都是编译错误。
3. 变量没读入就使用（忘写 `cin >> x`），结果是随机值。

## 五、小结

本题的收获：变量、`cin`、赋值运算。从今天起，你写的程序不再是"死"的——同一份代码，输入不同数据就有不同结果，这正是程序的威力。回家可以试试改成"票价 15 元"，只需改一个数字。
