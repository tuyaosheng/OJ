# 讲解稿：分苹果（ch01-005）

## 一、题目解读

n 个苹果，每袋恰好装 m 个，问：能装满几袋？剩下几个？比如 17 个苹果、每袋 5 个：能装满 3 袋，剩 2 个。这道题引出 C++ 中一对形影不离的运算符：`/`（整除）和 `%`（取余）。

## 二、思路分析

"能装满几袋"就是 17 ÷ 5 商 3；"剩几个"就是 17 ÷ 5 余 2。小学的"带余除法"，在 C++ 里正好对应两个运算符：

- `17 / 5` 结果是 `3`——**两个整数相除，小数部分直接扔掉**（不是四舍五入！）；
- `17 % 5` 结果是 `2`——`%` 读作"模"（mod），取余数。

它们满足一个恒等式：`n == n / m * m + n % m`，即"总数 = 商×每袋个数 + 余数"。

## 三、代码讲解

```cpp
int n, m;
cin >> n >> m;
int bags = n / m;        // 整除：装满的袋子数
int rest = n % m;        // 取余：剩下的苹果数
cout << bags << " " << rest << endl;
```

看几组边界数据帮助理解：
- n = 0：`0 / 3 = 0`，`0 % 3 = 0`——没有苹果，0 袋 0 剩；
- n < m（如 3 个苹果每袋装 7 个）：`3 / 7 = 0`，`3 % 7 = 3`——一袋都装不满，苹果全剩下；
- 恰好整除（10 个每袋 2 个）：`10 / 2 = 5`，`10 % 2 = 0`——剩 0 个。

这三种情况就是本题测试点的设计思路，也是你以后自己出数据时要想到的"边界"。

## 四、易错点

1. 以为 `/` 会四舍五入。`7 / 2` 是 `3` 不是 `3.5` 也不是 `4`——整数除法**向零取整**。
2. `%` 只能用于整数，`3.5 % 2` 是编译错误。
3. n 最大 10 亿，还在 int 范围内（约 21 亿），但已经很贴近了——要有"数据范围警觉性"。

## 五、小结

`/` 和 `%` 是信奥中出镜率最高的运算符组合：拆数位（`n % 10` 取个位、`n / 10` 去掉个位）、判断奇偶（`n % 2`）、循环报数……全靠它俩。记住恒等式"商×除数+余数=被除数"，后面学同余、进制转换时还会反复见到它们。
