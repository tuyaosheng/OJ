# 讲解稿：Hello World!（ch01-001）

## 一、题目解读

同学们好，今天我们写人生中第一个 C++ 程序。题目要求非常简单：让计算机在屏幕上打出一行字——`Hello World!`。注意三个细节：H 和 W 是大写的、两个单词中间有一个空格、末尾有个英文感叹号。少一个、错一个，OJ 都会判错——计算机是"一个字符都不放过"的。

## 二、思路分析

这道题不需要"思路"，需要的是记住一个 C++ 程序的**固定骨架**。就像写作文要有开头、正文、结尾，C++ 程序也有三样必备的东西：

1. `#include <iostream>` —— 告诉编译器："我要用输入输出功能，请把 iostream 这个工具箱搬过来。"
2. `using namespace std;` —— C++ 标准库里的名字都住在一个叫 `std` 的"小区"里，这句话相当于说"后面提到的名字默认都是这个小区的住户"，这样我们写 `cout` 就不用写成 `std::cout`。
3. `int main() { ... }` —— 主函数，程序的入口。电脑运行程序时，就从 `main` 的第一行开始，一行一行往下执行。

## 三、代码讲解

```cpp
#include <iostream>
using namespace std;

int main()
{
    cout << "Hello World!" << endl;
    return 0;
}
```

核心就一行：`cout << "Hello World!" << endl;`。
- `cout` 读作"C-out"，就是"往屏幕上输出"；
- `<<` 像一个漏斗，把右边的内容"灌"到屏幕上；
- 双引号里的内容会**原样**打印；
- `endl` 表示换行（end line）。
- 最后 `return 0;` 是礼貌性地告诉操作系统："我正常结束了。"

## 四、易错点

1. **中文标点**！在中文输入法下打出的引号 `“”`、分号 `；` 编译器不认识，必须全部用英文符号。这是初学者第一大坑。
2. 每条语句末尾的分号 `;` 不能丢。
3. 在 OJ 上提交时，**不要**写 `system("pause")`，也不要多输出"请输入"之类的提示文字——OJ 是机器判题，多一个字都算错。
4. 大小写：`Cout`、`Main` 都是错的，C++ 严格区分大小写。

## 五、小结

今天记住一件事就够了：C++ 程序的三件套——`include`、`using namespace std`、`main` 函数，以及用 `cout <<` 输出。以后每道题的程序都长在这个骨架上。课后把这几行代码**亲手敲三遍**，不要复制粘贴，肌肉记忆很重要。
