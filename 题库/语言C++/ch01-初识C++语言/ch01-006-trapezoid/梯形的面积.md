# 讲解稿：梯形的面积（ch01-006）

## 一、题目解读

这是课件例 1.2 的一般化版本。梯形上底 a、下底 b，里面藏着一个阴影三角形：以**上底**为底边、高和梯形一样，面积是 s。求梯形面积，保留两位小数。

题目没有直接给"高"，这是本题的关键——高藏在三角形面积里。

## 二、思路分析

分两步推导：

1. 三角形面积公式 s = a × h ÷ 2，反过来解出高：**h = 2s ÷ a**；
2. 把 h 代入梯形面积公式：梯形面积 = (a + b) × h ÷ 2。

用课件的数字验证：a=15、b=25、s=150 → h = 300 ÷ 15 = 20 → 面积 = (15+25) × 20 ÷ 2 = 400。✓

先在草稿纸上把数学式子推清楚，再动手写代码——**数学建模在前，编程实现在后**，这是信奥解题的标准流程。

## 三、代码讲解

```cpp
double a, b, s;
scanf("%lf%lf%lf", &a, &b, &s);
double h = 2 * s / a;
double ans = (a + b) * h / 2;
printf("%.2f\n", ans);
```

三个新知识点：
- **double 类型**：能存小数。本题虽然输入是整数，但除法会产生小数（比如 h = 22/3），必须用 double 存，否则小数部分被整除运算砍掉。
- **scanf/printf**：C 风格输入输出。`%lf` 对应读 double；输出的 `%.2f` 表示"保留两位小数"（自动四舍五入）。格式化输出用 printf 比 cout 方便得多，信奥中非常常用。
- `&a`：scanf 里变量名前要加 `&`（取地址符），意思是"把读到的数放到 a 的地址上"。忘写 `&` 程序会崩溃。

## 四、易错点

1. 全程用 int 计算：`2 * s / a` 如果 s、a 都是 int，除法就变整除，精度丢失。**只要计算过程会出现小数，变量就用 double。**
2. scanf 忘写 `&`，运行时直接崩（RE）。
3. `%.2f` 写成 `%.2lf` 输出——printf 输出 double 用 `%f` 系即可（`%.2lf` 在现代编译器也能用，但读入必须是 `%lf`）。
4. 数学公式没化简也可以：直接算 `(a+b)*s/a` 是等价的，殊途同归。

## 五、小结

本题是第 1 章的"综合题"：顺序结构 + 数学推导 + 浮点数 + 格式化输出，四合一。重点记两条：会出现小数就用 double；保留 n 位小数用 `printf("%.nf", x)`。这两条在后面章节会一直用到。
