# 我的世界·合成计算——讲解稿

## 一、题目解读

游戏里的合成规则翻译成数学：1 木头=4 木板，6 木板=1 门。给 n 个木头，问"最多几扇门、剩几块板"。

关键词是"**尽可能多**"和"**剩下**"——听到这两个词，就要想到**整除**和**取余**这对搭档。

## 二、思路分析

分两步：

1. 总木板数 = `4 * n`（乘法）；
2. 门数 = 总木板 `/ 6`（整除，商就是"最多能做几个"），剩余 = 总木板 `% 6`（余数就是"分剩下的"）。

不需要循环、不需要判断，两个运算符解决战斗。

## 三、代码讲解

```cpp
int planks = 4 * n;
cout << planks / 6 << " " << planks % 6 << endl;
```

注意 `a = a/b*b + a%b` 恒成立——门用掉的木板（`planks/6*6`）加上剩下的（`planks%6`）正好是全部木板，可以用这个式子自己验算。

## 四、易错点

1. 输出两个数之间是**一个空格**，多了少了都判错；
2. 先做乘法再整除：`4*n/6` 和 `4*(n/6)` 结果不同（后者先把木头整除，是错的）；
3. n 最大 10000，`4*n` 最大 40000，int 完全够。

## 五、小结

整除取余的"分配"模型：总量、每份大小 → 份数与剩余。以后凡是"最多装几袋、剩多少"都是它。
