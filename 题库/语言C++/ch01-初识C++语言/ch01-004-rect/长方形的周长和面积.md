# 讲解稿：长方形的周长和面积（ch01-004）

## 一、题目解读

给一个长方形的长 a 和宽 b，让我们同时算两样东西：周长和面积。跟上一题相比有两个升级：一次要**读入两个数**，一次要**输出两个数**。

## 二、思路分析

公式小学就学过：周长 = (长 + 宽) × 2，面积 = 长 × 宽。程序还是"输入 → 计算 → 输出"三段式，只是每段都变成了"双份"。

顺便估算数据范围：a、b 最大 10000，面积最大是 10000 × 10000 = 1 亿。int 能存约 21 亿，够用。但如果题目把范围改成 10 万，面积就是 100 亿，int 就爆了，要换 `long long`——这个判断今后每题都要做。

## 三、代码讲解

```cpp
int a, b;
cin >> a >> b;               // 连续读两个数，>> 可以串联
int c = (a + b) * 2;         // 注意括号！
int s = a * b;
cout << c << " " << s << endl;
```

- `cin >> a >> b;`：`>>` 可以连着用，输入时不管两个数之间是空格还是换行，`cin` 都能正确拆开——这是 `cin` 的贴心之处。
- `(a + b) * 2`：**括号不能省**。如果写成 `a + b * 2`，按运算优先级会先算 `b * 2`，结果就错了。C++ 的运算优先级跟数学一样：先乘除后加减，括号最优先。
- 输出两个数时，中间要手动输出一个空格 `" "`，否则两个数字会粘在一起变成一个大数字。

## 四、易错点

1. `cout << c << s` 忘了中间的 `" "`，输出 `1615` 而不是 `16 15`——这是本题最常见的错误。
2. 括号丢失导致周长算错。
3. 把周长和面积的输出顺序写反（题目要求先周长后面积）。

## 五、小结

两个要点：一是 `cin`、`cout` 都可以串联使用；二是表达式要注意运算优先级，**拿不准就加括号**，多余的括号不算错，少了括号就出 bug。学有余力的同学想一想：如果长和宽是小数，程序要改哪几处？（提示：int 换 double，其余不变——这就是第 2 章的内容。）
