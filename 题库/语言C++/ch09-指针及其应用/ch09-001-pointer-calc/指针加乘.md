# 讲解稿：指针加乘（ch09-001）

## 一、题目解读

输入两个数，**通过指针**求它们的和与积。课件例 1。指针是 C++ 里最强大也最让人头疼的概念，这题从最简单的用法入手，把"取地址 `&`""解引用 `*`"这对基本操作弄明白。

## 二、思路分析

先建立一个心智模型。变量 a 好比一个"抽屉"，里面放着值（比如 3），而这个抽屉有个"门牌号"——这就是它的**地址**。

- `&a` = 取 a 的门牌号（地址）；
- 指针 `int *pa` = 一个专门存"门牌号"的变量；
- `pa = &a` = 让 pa 记住 a 的门牌号，我们说"pa 指向 a"；
- `*pa` = 按门牌号找到那个抽屉，取出里面的值——所以 `*pa` 就等于 a。

一句话对应关系：**`pa` ↔ `&a`（地址）；`*pa` ↔ `a`（值）**。理解了这个，指针就入门了。

## 三、代码讲解

```cpp
int a, b;
cin >> a >> b;
int *pa = &a, *pb = &b;          // pa 指向 a，pb 指向 b
long long sum = (long long)(*pa) + (*pb);   // *pa 就是 a
long long prod = (long long)(*pa) * (*pb);
cout << sum << " " << prod << endl;
```

- 定义指针：`int *pa`，星号表示"这是个指针"；
- `pa = &a`：把 a 的地址装进 pa；
- 用值时解引用：`*pa` 取出 a 的值参与运算；
- 乘积可能到 10¹⁰，转 long long 防溢出。

注意两个星号在不同位置意义不同：定义时 `int *pa` 的 `*` 表示"指针类型"；使用时 `*pa` 的 `*` 表示"取指向的值"。

## 四、易错点

1. 混淆 `pa`（是地址）和 `*pa`（是值）：`cout << pa` 打印的是一串地址数字，`cout << *pa` 才是 3。
2. 给指针直接赋一个整数 `pa = 1000;`——错误，指针只能存地址（`&变量` 或 `new` 的结果）。
3. 指针没赋值就用 `*pa`——野指针，程序崩溃。

## 五、小结

指针的两块基石：`&` 取地址、`*` 解引用，对应关系 `*pa == a`。它看起来绕，多画"抽屉 + 门牌号"的图就通了。下面几题我们让指针去遍历数组、修改函数外的变量——那才是它真正发光的地方。
