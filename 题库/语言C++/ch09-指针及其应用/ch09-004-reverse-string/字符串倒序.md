# 讲解稿：字符串倒序（ch09-004）

## 一、题目解读

把一个字符串倒序输出。课件例 8。第 5 章我们用下标判过回文，这题用**指针**从两端往中间交换字符——把"指针 + 数组"和"双指针"结合起来练。

## 二、思路分析

字符数组也是数组，同样服从"数组名即首地址"。倒序的经典手法是双指针：
- `p` 指向第一个字符（`s`）；
- `q` 指向最后一个字符（`s + len - 1`，len 是字符串长度）；
- 交换 `*p` 和 `*q`，然后 `p++`、`q--`，向中间靠拢；
- 直到 `p >= q`（相遇或交错），倒序完成。

每对字符只交换一次，扫到中点就结束，O(n) 高效。

## 三、代码讲解

```cpp
char s[100005];
cin >> s;
int len = strlen(s);
char *p = s;                     // 指向开头
char *q = s + len - 1;           // 指向结尾
while (p < q)
{
    char t = *p; *p = *q; *q = t;   // 交换首尾字符
    p++;
    q--;
}
cout << s << endl;
```

- **`strlen(s)`**：求字符串长度（需 `#include <cstring>`），不含结尾的 `'\0'`；
- `s + len - 1`：最后一个字符的地址（下标 len−1）；
- 交换用临时变量 t（char 版的三变量交换）；
- 循环条件 `p < q`：相遇即停，中间字符（奇数长度时）不用动。

`cin >> s` 读字符数组：遇空格/换行停止，正好读一个不含空格的串，末尾自动补 `'\0'`。

## 四、易错点

1. `q` 初值写成 `s + len`——指向了结尾的 `'\0'`，交换会把空字符换到前面，输出出错。必须是 `len - 1`。
2. 循环条件 `p <= q`——不算错（中点自交换无影响），但 `p < q` 更清爽。
3. 忘 `#include <cstring>` 用不了 strlen。
4. 数组开小：长度可达 10 万，至少开 100001。

## 五、小结

双指针 + 指针移动实现原地倒序，是"两端向中间"套路的又一次应用（回文、快排划分都用它）。字符数组和普通数组一样能被指针遍历。当然，用 string + `reverse` 一行也能倒序（上一章学过）——但手写一遍，才真正理解它内部在做什么。
