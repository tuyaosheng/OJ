# 讲解稿：动态数组前缀和（ch09-005）

## 一、题目解读

用**动态数组**（`new`/`delete`）存 N 个数，计算并输出它们的前缀和数组。课件例 6。这题两个知识点：**动态内存分配**（指针的重要应用）和**前缀和**（后面章节的常用预处理）。

## 二、思路分析

以前我们开数组都是 `int a[100005]`——大小写死，不管实际用几个都占那么多。**动态数组**让你"按需申请"：运行时读到 N，再申请正好 N+1 个空间。

- 申请：`long long *b = new long long[n + 1];`——`new` 向系统要一块内存，返回它的首地址，用指针 b 接住；
- 用完释放：`delete[] b;`——把内存还给系统，避免"内存泄漏"。

**前缀和**：b[i] = a[1] + a[2] + … + a[i]，用递推 `b[i] = b[i-1] + a[i]` 一遍算出（b[0]=0）。前缀和是极其重要的预处理，第 10 章会用它 O(1) 回答区间和查询。

## 三、代码讲解

```cpp
long long *b = new long long[n + 1];   // 动态申请 n+1 个 long long
b[0] = 0;
for (int i = 1; i <= n; i++)
{
    long long x; cin >> x;
    b[i] = b[i - 1] + x;         // 前缀和递推
}
// ...输出 b[1..n]...
delete[] b;                      // 释放
```

- `new long long[n+1]` 返回首地址，b 既是指针也能当数组用：`b[i]` 就是 `*(b+i)`；
- 前缀和递推：当前 = 前一项前缀和 + 当前值；
- **`delete[] b`**：数组版释放要带 `[]`（区别于 `delete p` 释放单个对象）；
- 元素到 10⁹、累加 10 万个，前缀和用 long long。

## 四、易错点

1. `new long long[n+1]` 忘了 +1——下标用到 b[n] 就越界（我们用 b[1..n]）。
2. `delete b` 漏了 `[]`——数组必须 `delete[] b`。
3. 前缀和 b[0] 忘了初始化为 0。
4. 前缀和用 int 溢出。

## 五、小结

`new`/`delete[]` 让数组大小在运行时决定，是指针的一大实用场景（不知道数据规模时特别有用）。前缀和递推 `b[i]=b[i-1]+a[i]` 则是"用历史加速查询"的经典预处理。下一章的区间和查询，就是前缀和的正式主场。
