# 讲解稿：指针遍历数组（ch09-002）

## 一、题目解读

用**指针**遍历数组，求所有元素的和与最大值。课件例 2、例 5。这题揭示一个重要真相：**数组和指针是一家人**——数组名本身就是一个地址。

## 二、思路分析

关键认知：**数组名 `a` 就是数组首元素的地址**（即 `&a[0]`）。由此：
- `a + i` 指向第 i 个元素；
- `*(a + i)` 就是 a[i]。

也就是说，`a[i]` 只是 `*(a + i)` 的"糖衣写法"，两者完全等价！

于是遍历数组有了指针版：让指针 `p` 从 `a`（首地址）出发，每次 `p++` 后移一格，`*p` 就是当前元素，直到 `p` 走到 `a + n`（尾后）停止。

## 三、代码讲解

```cpp
for (int *p = a; p < a + n; p++)
{
    sum += *p;                   // *p 是当前元素
    if (*p > maxv) maxv = *p;
}
```

- `int *p = a`：p 指向数组开头（数组名 = 首地址，可直接赋给指针）；
- `p++`：指针后移**一个 int** 的位置（编译器知道 int 占几字节，自动跳对）——这叫"指针算术"；
- `p < a + n`：走到第 n 个元素之后（尾后地址）就停，正好遍历 n 个；
- `*p`：解引用取当前值。

对比普通 `for (int i=0;i<n;i++) a[i]`，指针版和它做的事一模一样，只是用地址移动代替下标递增。理解这点，就理解了 C++ 数组的本质。

## 四、易错点

1. `p < a + n` 写成 `p <= a + n`——多访问一个越界元素。
2. 把 `p++`（指针移动）和 `*p`（取值）搞混。
3. 数组和用 long long（元素可到 10⁹，10 万个求和溢出 int）。
4. 以为 `p++` 是地址加 1 字节——其实是加 `sizeof(int)`，编译器帮你算好，你只管"下一格"。

## 五、小结

数组名即首地址、`a[i]` 等价 `*(a+i)`、指针 `p++` 逐格遍历——这三点把"数组"和"指针"彻底打通。虽然平时用下标更直观，但理解指针视角能帮你看懂很多底层代码，也是学链表、动态数组的基础。
