# 讲解稿：数组中第一个质数（ch09-006）

## 一、题目解读

在数组中找到第一个质数，返回它的位置（从 1 计），没有则返回 -1。课件例 10。这题把第 6 章的"判素函数"和本章的"遍历查找"结合起来，是一道综合小练习。

## 二、思路分析

两步走，都是老朋友：
1. **判素函数** `isPrime(int)`（第 6 章学过）：n < 2 不是素数；试除到 √n。
2. **遍历查找**：从第 1 个元素扫到最后，遇到第一个满足 isPrime 的就记下位置、`break` 退出；一个都没有则位置保持 -1。

课件里用"返回指针"（指向那个元素）来表达，我们返回位置更直观——本质一样：都是"定位数组中第一个满足条件的元素"。

## 三、代码讲解

```cpp
bool isPrime(int n)
{
    if (n < 2) return false;
    for (long long i = 2; i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}
...
int pos = -1;
for (int i = 1; i <= n; i++)
    if (isPrime(a[i])) { pos = i; break; }   // 找到第一个就停
cout << pos << endl;
```

- pos 初值 -1：代表"还没找到"，若整轮扫完没更新，输出的就是 -1；
- 找到第一个立即 `break`——题目要"第一个"，不能继续找；
- 判素注意边界：负数、0、1 都不是质数（isPrime 里 `n < 2` 挡住）。

测试点特意放了"全是合数"（输出 -1）、"负数和 0、1"（都不算质数）、"第一个就是质数"等情况。

## 四、易错点

1. 找到质数后不 break——会一直扫到最后一个质数，位置就错了。
2. 位置从 0 计——题目要从 1 计，差 1。
3. isPrime 漏了 `n < 2` 的边界，把 1 或负数误判成质数。
4. `i * i` 用 int，元素到 10⁹ 时溢出（用 long long 或 `i <= n/i`）。

## 五、小结

"判素函数 + 遍历找第一个满足条件的元素"是一个高频组合，本质是"线性查找"。它把第 6 章的函数封装和本章的数组遍历串在一起。第一部分（语言 C++）到此全部完成——从 Hello World 到指针，你已经掌握了 C++ 的核心语法与常用工具，可以正式进入第二部分的算法世界了。
