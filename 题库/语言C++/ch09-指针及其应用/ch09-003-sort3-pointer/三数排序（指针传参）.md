# 讲解稿：三数排序（指针传参）（ch09-003）

## 一、题目解读

写一个函数，把三个整数排成从小到大。课件例 9。第 3 章我们在 main 里排过三个数，这次要**用函数 + 指针**来排——目的是搞懂指针最重要的用途：**让函数能修改外部的变量**。

## 二、思路分析

先看一个"失败"的尝试：如果写 `void mySwap(int x, int y)` 交换 x、y，函数里确实换了，但外面的变量**纹丝不动**。为什么？因为普通参数是**值传递**——函数拿到的是变量的"复印件"，改复印件不影响原件。

要真正改动外面的变量，就把变量的**地址**传进去：`void mySwap(int *x, int *y)`，函数内用 `*x`、`*y` 直接操作原变量所在的内存。这就是**指针传参**（也叫传地址）。C++ 的 `swap` 函数底层就是这么干的。

## 三、代码讲解

```cpp
void mySwap(int *x, int *y)      // 参数是地址
{
    int t = *x; *x = *y; *y = t; // 通过地址直接改原变量
}

void sort3(int *a, int *b, int *c)
{
    if (*a > *b) mySwap(a, b);
    if (*a > *c) mySwap(a, c);   // 此时 *a 最小
    if (*b > *c) mySwap(b, c);
}
...
sort3(&a, &b, &c);               // 传地址！
```

- 调用时传 `&a`（a 的地址），不是 a 本身；
- 函数内 `*x` 就是主函数里的 a，改 `*x` 就是改 a；
- `mySwap(a, b)` 里 a、b 已经是指针（sort3 的参数），直接传，不用再 `&`；
- 排序逻辑和第 3 章一样，只是全程隔着指针操作。

## 四、易错点

1. 调用时忘了 `&`，传成 `sort3(a, b, c)`——类型不匹配，编译错误。
2. 函数内忘了 `*`，写 `x > y`（比较的是两个地址）而不是 `*x > *y`（比较值）。
3. 混淆：参数 `int *x` 定义时的 `*` 是"指针类型"，函数体里 `*x` 的 `*` 是"取值"。

## 五、小结

值传递改不了外部变量，**传地址（指针）才能**——这是指针最核心的用途。C++ 还提供了更简洁的"引用传参"（`int &x`），效果相同但写起来像普通变量，很多场合更常用。理解了指针传参，你就明白了函数如何"向外传递结果"（除了 return，还能通过参数改值）。
