# 讲解稿：求排名（ch07-002）

## 一、题目解读

给 N 个互不相同的整数，输出每个数按从小到大的排名（最小的排名 1）。课件例 7.3，标题叫"离散化基础"——这是一个在图论、数据结构里极其常用的预处理技巧的入门版。

## 二、思路分析

难点在于：排序会打乱原来的顺序，但我们要**按输入顺序**输出每个数的排名。怎么在"排序求排名"和"按原顺序输出"之间搭桥？

答案是用结构体记住每个数的**原始位置**：
- 定义 `struct Node { int val; int pos; }`——数值 + 它在输入中的下标；
- 按 val 从小到大排序；排好后，第 i 个（从 0 数）的排名就是 i+1；
- 把这个排名**写回它的原始位置**：`rankArr[a[i].pos] = i + 1`；
- 最后按 0..n−1 顺序输出 rankArr，就是按输入顺序的排名。

核心思想：**排序时带着"身份证"（原始下标），排完好认领结果**。这就是离散化的骨架。

## 三、代码讲解

```cpp
struct Node { int val, pos; };
bool cmp(const Node &a, const Node &b) { return a.val < b.val; }
...
for (int i = 0; i < n; i++) { cin >> a[i].val; a[i].pos = i; }
sort(a, a + n, cmp);
for (int i = 0; i < n; i++) rankArr[a[i].pos] = i + 1;
```

- 读入时同步记下 `pos = i`（原始位置）；
- 排序按 val 升序；因为题目保证**互不相同**，普通 `sort` 就够，不用考虑并列；
- 关键一步 `rankArr[a[i].pos] = i + 1`：排好序后位于第 i 名的那个数，它当初来自位置 `a[i].pos`，就把排名 i+1 记到那个位置的答案格里；
- 输出时遍历 rankArr[0..n−1]，天然是输入顺序。

样例 `30 10 50 20 40` → 排名 `3 1 5 2 4`：10 最小排 1、20 排 2、30 排 3……再按输入顺序摆好。

## 四、易错点

1. 排完序直接输出排序后的数组——那是"排好序的数"，不是"按输入顺序的排名"，顺序全错。必须借 pos 写回。
2. 排名从 0 开始——题目要求从 1 计，记得 +1。
3. 忘了记 pos，排完序找不回原始位置。
4. 若数据可能重复，还要处理并列——本题保证不重复，暂不用管（但要知道有这回事）。

## 五、小结

"带原始下标一起排序，再把结果写回原位"——这是离散化 / 求排名的通用套路，后面线段树、树状数组、图论建图前几乎都要做一次离散化。结构体在这里的作用，就是让"数值"和"身份（位置）"如影随形。
