# 战队排行榜——讲解稿

## 一、题目解读

竞技游戏的排行榜结算：先比积分，再比用时，最后比队名。三条规则就是三个**关键字**，优先级从高到低——这是第 7 章多关键字排序的直接落地（和例2"奖学金"同一个骨架）。

## 二、思路分析

为什么必须用结构体？队名、积分、用时是**一条记录的三个字段**，排序时要整条一起动。用三个平行数组，交换时漏搬一列就"张冠李戴"。

cmp 的万能模板："**不相等就分胜负，相等交给下一层**"：

```cpp
if (a.score != b.score) return a.score > b.score;
if (a.time  != b.time)  return a.time  < b.time;
return a.name < b.name;
```

第一行管降序（`>`），第二行管升序（`<`），第三行 string 直接用 `<` 比字典序——三行三个方向，全在一个函数里说清楚。

## 三、代码讲解

- `sort(t, t + n, cmp)` 一行完成排序，O(n log n)；
- string 的 `<` 就是字典序比较，不用自己逐字符写；
- 输出用 `"\n"`，1000 行规模无压力。

## 四、易错点

1. cmp 写 `>=` / `<=` → 破坏严格弱序，sort 直接运行错误（RE），这是本题最重要的一课；
2. 降序升序搞混：积分要**大**的在前（`>`），用时要**小**的在前（`<`）；
3. 忘了第三关键字 → 并列时输出顺序不稳定，随机 WA；
4. 队名里没有空格，`cin >>` 直接读即可，不需要 getline。

## 五、小结

排行榜、奖学金、成绩单——所有"先比A再比B再比C"的题，都是同一个 cmp 模板。写熟到闭眼能默。
