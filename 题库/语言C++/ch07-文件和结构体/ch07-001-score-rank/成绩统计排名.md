# 讲解稿：成绩统计排名（ch07-001）

## 一、题目解读

输入 N 个学生的姓名、语文、数学成绩，按总分从高到低排；总分相同的，保持输入的先后顺序。课件例 7.2。本章新主角登场：**结构体（struct）**和**自定义排序**。

## 二、思路分析

一个学生有姓名、两科成绩、总分等多项信息，它们属于同一个人，理应"绑在一起"。这就是 **struct** 的用处：把若干不同类型的数据打包成一个"自定义类型"。定义好 `Student` 后，就能开 `Student s[105]` 数组，每个元素是一整个学生。

排序要求有两层：主规则"总分降序"，附加规则"同分保持输入序"。后者叫**稳定性**——排序不打乱相等元素的原有先后。C++ 的 `stable_sort` 正好保证这点；比较函数只写主规则"总分大的在前"即可，稳定性交给 `stable_sort`。

## 三、代码讲解

```cpp
struct Student {
    string name;
    int total;
};

bool cmp(const Student &a, const Student &b)
{
    return a.total > b.total;      // 总分大的排前面
}
...
stable_sort(s, s + n, cmp);
```

三个新知识点：
- **结构体定义**：`struct Student { ... };`（末尾分号别丢），之后 `Student` 就是一个能用的类型；用 `s[i].name`、`s[i].total` 点出成员；
- **比较函数 cmp**：返回 `a 是否应排在 b 前面`。要降序就写 `a.total > b.total`；
- **stable_sort vs sort**：普通 `sort` 不保证相等元素的相对顺序；`stable_sort` 保证。本题"同分按输入序"必须用 `stable_sort`（或手写冒泡，冒泡天然稳定）。

样例里 bob 和 carol 都是 176 分，bob 先输入，所以 bob 排在 carol 前——正是稳定排序的效果。

## 四、易错点

1. 用 `sort` 而非 `stable_sort`——同分顺序可能被打乱，"同分按输入序"的测试点挂掉。
2. 结构体定义末尾漏分号——编译报一堆莫名其妙的错。
3. cmp 里写成 `>=` 或 `<`——`>=` 在某些实现下会引发未定义行为，比较函数必须是严格"小于/大于"语义。
4. 姓名用 `char[]` 读入还行，但用 `string` + `cin >>` 最省心（遇空格停，正好一个单词）。

## 五、小结

结构体把"属于一个实体的多项数据"打包管理，是处理带属性对象的利器。自定义 `cmp` + `sort/stable_sort` 是竞赛排序的标准姿势。稳定性这个概念要记牢：**题目说"同某值按原顺序"，就得用稳定排序**。
