# 讲解稿：奖学金（ch07-003）

## 一、题目解读

n 名学生，每人语文、数学、英语三科成绩。按"总分 → 语文 → 学号"三级规则排名，输出前 5 名的学号和总分。改编自 NOIP2007 普及组第一题。本题专攻**多关键字排序**。

## 二、思路分析

排序规则有三层优先级，像字典排序一样"层层裁决"：
1. 先比总分，高的在前；
2. 总分打平，比语文，高的在前；
3. 语文还打平，比学号，小的在前（学号即输入顺序）。

这叫**多关键字排序**。实现关键在比较函数 cmp——**按优先级从高到低依次判断**：某一层能分出胜负就立即返回，分不出（相等）才看下一层。

用结构体存"学号 + 语文 + 总分"三个字段（数学、英语只用来算总分，可以不单独存）。学号作为最后一道裁决线，保证任意两个学生都能被严格分出先后，排序结果唯一。

## 三、代码讲解

```cpp
bool cmp(const Stu &a, const Stu &b)
{
    if (a.total != b.total)     return a.total > b.total;   // 第一关键字
    if (a.chinese != b.chinese) return a.chinese > b.chinese; // 第二关键字
    return a.id < b.id;                                     // 第三关键字
}
```

这个"if 链"是多关键字排序的**标准模板**，务必记牢：
- 每层先判"是否相等"，**不等**才用它决定顺序（`return ...`），相等就往下走；
- 前两层降序用 `>`，第三层学号升序用 `<`；
- 最后一层不写 if，直接 return——因为学号互不相同，一定能分出。

主函数里 `id = i + 1`（学号从 1 计），总分 = 三科之和，`sort` 后输出前 5 名。因为学号已保证唯一裁决，这里用普通 `sort` 即可（不需要 stable_sort）。

## 四、易错点

1. cmp 里各层的比较方向记错（总分/语文降序、学号升序别搞混）。
2. 少写某一层——两个学生总分语文都相同就会顺序不定，前 5 名可能错。
3. 每层忘了先判"不等"，直接 `return a.total > b.total && ...` 之类——逻辑就错了。老老实实用 if 链。
4. n ≥ 5 题目保证，但仍要确认输出正好 5 行。

## 五、小结

多关键字排序 = 比较函数里的"if 链"，从高优先级到低优先级逐层裁决。这是竞赛里出镜率极高的模板（排名、日程、字典序……）。配一个"绝对能分胜负"的末级关键字（如学号/编号），能让排序结果稳定唯一，避免玄学 bug。
