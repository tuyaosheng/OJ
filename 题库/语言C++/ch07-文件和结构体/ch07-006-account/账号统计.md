# 讲解稿：账号统计（ch07-006）

## 一、题目解读

N 个注册账号，分身份证号和 QQ 号两类。统计身份证里男/女人数（第 17 位数字奇男偶女），以及所有 QQ 号的平均值（向下取整）。课件例 7.5。本章综合题：**按类型分流处理 + 字符串取位 + 分类统计**。

## 二、思路分析

每行数据先有一个类型标识（`I` 身份证 / `Q` QQ 号），格式不同、处理不同——这叫**分流**：先读类型字符，再按类型决定后面怎么读、怎么统计。

- 遇 `I`：读一个 18 位字符串，看第 17 位判性别，男计数或女计数；
- 遇 `Q`：读一个整数，累加进 QQ 总和、QQ 计数 +1。

身份证第 17 位怎么取？字符串下标**从 0 开始**，所以"第 17 位"是 `s[16]`。它是字符，要转成数字得减 `'0'`：`s[16] - '0'`，再判奇偶。

最后平均值 = QQ 总和 / QQ 个数，整数除法天然"向下取整"，正合题意。

## 三、代码讲解

```cpp
char type;
cin >> type;
if (type == 'I')
{
    string id;
    cin >> id;
    int gender = id[16] - '0';        // 第 17 位（下标 16）
    if (gender % 2 == 1) male++;
    else                 female++;
}
else   // 'Q'
{
    long long qq;
    cin >> qq;
    qqSum += qq;
    qqCnt++;
}
...
cout << male << " " << female << " " << qqSum / qqCnt << endl;
```

四个讲点：
- **先读类型再分支**：`cin >> type` 拿到 I/Q，`cin >>` 会自动跳过前导空格，稳妥；
- **字符串取位 + 字符转数字**：`id[16] - '0'`——"第 17 位"对应下标 16 是经典的"差 1"，`- '0'` 把字符 '5' 变成数字 5（第 2 章 ASCII 知识联动）；
- **qqSum 用 long long**：QQ 号可到 10⁹，1 万个相加达 10¹³，int 必爆；
- **向下取整**：整数除法 `qqSum / qqCnt` 自动舍去小数，正好是"取整"。

样例两个 QQ 号 12345、67890，平均 (12345+67890)/2 = 40117（整除）。身份证两人一男一女，输出 `1 1 40117`。

## 四、易错点

1. 第 17 位取成 `id[17]`（下标从 0 数，第 17 位是 16）——差 1，性别全判错。
2. `id[16]` 忘减 '0'，直接拿字符去判奇偶——字符 '5' 的 ASCII 是 53，`53 % 2` 恰好也是奇……有时蒙对有时错，务必减 '0' 转成真数字。
3. qqSum 用 int——大数据溢出。
4. 题目保证至少一个 QQ 号，所以 qqCnt 不为 0，除法安全；但要养成"除前想除数会不会为 0"的习惯。

## 五、小结

按类型分流 + 字符串定位取字符 + 分类累加，是"混合格式数据处理"的通用套路。它综合了本章的结构化思维、第 2 章的字符运算、以及一贯的数据范围警觉。第一部分（语言 C++）主体到这里就打通了——你已经具备读题、建模、用结构体组织数据、写函数与递归的完整能力，可以正式进军第二部分的算法世界了。
