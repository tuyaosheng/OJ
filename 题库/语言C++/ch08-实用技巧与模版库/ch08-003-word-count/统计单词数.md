# 讲解稿：统计单词数（ch08-003）

## 一、题目解读

读入一整行文本，统计里面有多少个单词（单词间可能有多个空格，首尾也可能有空格）。课件讲的"getline 读整行 + 逐词处理"就是干这个的。难点在于**空格数量不固定**。

## 二、思路分析

如果直接 `while (cin >> word) cnt++`，其实 cin 会自动跳过所有空白，也能数对单词——但它会一直读到文件末尾，不止一行。本题是"一行文本"，更严谨的做法是先用 **getline 读这一行**，再切分。

切分的利器是 **stringstream**（字符串流）：把整行塞进一个 stringstream，然后像用 cin 一样 `ss >> word`——`>>` 自动跳过任意多的空格、一次吐一个单词，读到流尾结束。多空格、首尾空格全部自动摆平。

## 三、代码讲解

```cpp
string line;
getline(cin, line);           // 读入一整行（含中间空格）
stringstream ss(line);        // 把这行接到字符串流
string word;
int cnt = 0;
while (ss >> word) cnt++;     // >> 自动跳空格，一次一个词
cout << cnt << endl;
```

- **`getline(cin, line)`**：读一整行（直到换行），保留行内空格——这是它和 `cin >>` 的关键区别（`cin >>` 遇空格就停）；
- **`stringstream ss(line)`**：需要 `#include <sstream>`，把字符串当成输入流；
- `while (ss >> word)`：和 `while (cin >> x)` 同理，读到流末尾自动停止；
- 空行（全是空格或没有内容）：`ss >> word` 一次都不成功，cnt = 0，正确。

## 四、易错点

1. 用"数空格个数 +1"来算单词数——多个连续空格、首尾空格会让你算错。用 `>>` 自动跳空格最稳。
2. `getline` 前如果有 `cin >> n` 读过数字，缓冲区残留的换行会让 getline 读到空行——本题没有这个前置读入，安全；但要知道这个坑。
3. 忘 `#include <sstream>`。

## 五、小结

`getline` 读整行、`stringstream` 切单词，是处理"一行里若干个词/数"的黄金组合。`>>` 自动跳空白的特性帮我们免去所有空格处理的烦恼。这个套路在读格式灵活的输入时特别好用。
