# 讲解稿：排队叫号（ch08-005）

## 一、题目解读

模拟医院叫号：`1 x` 让病人 x 排到队尾，`2` 让队首病人出队并输出编号。课件第四节 FIFO 队列。这题是 **queue（队列）** 的教科书式应用。

## 二、思路分析

排队的规则是"先来先服务"——先排队的先被叫号，这在计算机里叫 **FIFO（First In First Out，先进先出）**。STL 的 `queue` 正是这种结构：
- 进：只能从**队尾**加（push）；
- 出：只能从**队首**取（front）和删（pop）。

题目两种操作直接对应 queue 的两组动作，照着做即可，是最纯粹的"数据结构模拟题"。

## 三、代码讲解

```cpp
queue<long long> q;
if (op == 1) { cin >> x; q.push(x); }   // 入队到队尾
else { cout << q.front() << "\n"; q.pop(); }  // 输出并删队首
```

- **`queue<long long> q`**：需要 `#include <queue>`（编号可到 10⁹，其实 int 够，用 long long 保险）；
- `q.push(x)`：入队（加到队尾）；
- `q.front()`：查看队首元素（不删除）；
- `q.pop()`：删除队首（注意 pop 不返回值，要先 front 拿到再 pop）；
- 题目保证 `2` 操作时队列非空，所以不用判空；但实战中 `q.front()`/`q.pop()` 前应确认 `!q.empty()`，否则未定义行为。

## 四、易错点

1. 以为 `q.pop()` 会返回队首值——它**不返回**，必须先 `front()` 取值再 `pop()` 删除。
2. 把队列当栈用（从同一端进出）——queue 是两端分工：尾进首出。
3. 对空队列 front/pop——本题有保证，但要养成判空习惯。
4. 忘 `#include <queue>`。

## 五、小结

`queue` 实现先进先出，是排队、任务调度、以及第 18 章 **BFS 广度优先搜索**的核心容器。记住三件套：`push`（尾进）、`front`（看首）、`pop`（删首）。下一题的"优先队列"是它的升级版——出队的不是最早来的，而是最小/最大的。
