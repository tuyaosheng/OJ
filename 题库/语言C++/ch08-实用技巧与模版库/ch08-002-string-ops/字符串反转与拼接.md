# 讲解稿：字符串反转与拼接（ch08-002）

## 一、题目解读

把 s2 反转后接到 s1 后面输出。课件第三节 string。这题很短，目的是熟悉 **string 类型**——比字符数组好用太多的字符串工具。

## 二、思路分析

两步：反转 s2、拼接。string 让这两件事都变得极简：
- 反转：`reverse(s2.begin(), s2.end())`（algorithm 头文件），原地把 s2 倒过来；
- 拼接：`s1 + s2`——string 支持直接用 `+` 连接，甚至 `s1 += s2`。

对比字符数组：字符数组不能写 `s2 = s1`（那只是拷贝指针），拼接要用 `strcat`，反转要手写循环。string 把这些封装成了直观的运算符。

## 三、代码讲解

```cpp
string s1, s2;
cin >> s1 >> s2;
reverse(s2.begin(), s2.end());   // 原地反转
cout << s1 + s2 << endl;         // + 拼接
```

- `s2.begin()`/`s2.end()`：string 的"起点/终点"迭代器，很多 STL 函数都用这对参数表示范围；
- `reverse` 把 `[begin, end)` 内的字符前后颠倒；
- `s1 + s2` 生成一个新字符串。也可写 `s1 += s2;` 再输出 s1。

如果不用 reverse，手写也简单：双指针从两端往中间交换（下一题、第 9 章都会再练）。

## 四、易错点

1. 以为字符数组也能 `s2 = s1`、`s1 + s2`——那是 string 才有的能力，字符数组会出错。
2. `reverse` 忘了 `#include <algorithm>`。
3. `reverse(s2.begin(), s2.end())` 的范围写错（比如只写 begin）。

## 五、小结

string 把字符串当作"能赋值、能相加、能比较"的一等公民，配合 `reverse`、`+`、`[]` 下标，字符串处理变得轻松。以后除非特殊需要，字符串一律优先用 string。下一题我们用 string 流来切分单词。
