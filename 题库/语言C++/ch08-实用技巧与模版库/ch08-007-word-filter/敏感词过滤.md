# 敏感词过滤——讲解稿

## 一、题目解读

聊天消息里的敏感词换成 `*`——真实游戏、论坛都在跑的功能。规则里有一句关键话："从被替换段的**后一个位置**继续找"，它规定了重叠情况的答案（`aaa` 滤 `aa` 得 `**a` 而不是 `***`），也决定了代码怎么写。

## 二、思路分析

三件套循环：**找到 → 替换 → 从段后继续**。

- `find(w, pos)` 带起点的查找是关键：替换完从 `p + w.size()` 继续，天然实现"已替换部分不再匹配"；
- 替换物 `string(len, '*')` 用 string 的"重复字符构造"一行生成；
- 每轮至少前进 w.size() ≥ 1 个位置，1000 长度的消息最多扫 1000 轮，不会死循环。

## 三、代码讲解

`find` 的返回类型是 `size_t`（无符号）——用 `size_t p` 接住，和 `string::npos` 比较才安全。用 int 接、再和 npos 比，在某些平台上会出诡异 bug，这是 string 使用的一个经典细节。

## 四、易错点

1. 循环里 find 忘带起点参数 → 每次从头找，配合替换成 `*` 虽然结果碰巧对，但要能说清楚为什么；
2. `p + 1` 继续（而不是 `p + w.size()`）→ 与题目规定的非重叠语义不符，`aaa`/`aa` 这类用例出错；
3. 找不到时 find 返回 npos，直接拿去 replace 会越界崩溃——while 条件先挡住；
4. 消息里只有小写字母，用 `cin >>` 读即可；若含空格就得 getline（本题不需要，但要知道分界）。

## 五、小结

find + replace + 带起点续查，字符串批量替换的标准三件套。把"重叠怎么算"想清楚再动手，是字符串题的通用心法。
