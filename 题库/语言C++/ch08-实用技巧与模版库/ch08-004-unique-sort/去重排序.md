# 讲解稿：去重排序（ch08-004）

## 一、题目解读

输入 n 个整数，去掉重复的，把剩下的不同数从小到大输出，并报告个数。这就是经典的"明明的随机数"。本题让 STL 的 **set** 大显身手——它天生就会去重和排序。

## 二、思路分析

朴素做法：排序后扫一遍，跳过与前一个相同的数。可行。

但更省事的是 **set（有序集合）**：它有两个自带的超能力——
1. **自动去重**：插入已存在的元素不会重复保存；
2. **自动有序**：内部始终按从小到大维护。

于是全部 `insert` 进 set 后：`set.size()` 就是去重后的个数，从头遍历 set 就是从小到大的顺序。一个容器把两件事全干了。

## 三、代码讲解

```cpp
set<int> s;
for (int i = 0; i < n; i++) { int x; cin >> x; s.insert(x); }
cout << s.size() << endl;
for (int x : s) { ... cout << x; }   // 遍历即从小到大
```

- **`set<int> s`**：需要 `#include <set>`；
- `s.insert(x)`：插入，重复的自动忽略；
- `s.size()`：元素个数（已去重）；
- **`for (int x : s)`**：范围 for 循环，依次取出 set 里每个元素——因为 set 有序，取出顺序就是从小到大；
- set 底层是红黑树，插入/查找都是 O(log n)，n=10 万也很快。

## 四、易错点

1. 输出格式：先输出个数、再输出这些数（两行），注意行尾无多余空格。
2. 以为 set 会保留插入顺序——它是**排序顺序**，不是输入顺序。本题正需要排序顺序。
3. 忘 `#include <set>`。
4. 若要"去重但保持原顺序"，set 就不合适了，得用别的办法（本题要排序，正好用 set）。

## 五、小结

`set` = 自动去重 + 自动排序，是"要不重复的有序集合"时的首选。它和 `map`（键值对）、`vector`（动态数组）一样，都是 STL 送给你的现成数据结构——学会挑对容器，很多题就迎刃而解。下一题看队列 `queue`。
