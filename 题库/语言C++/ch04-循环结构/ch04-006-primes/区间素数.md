# 讲解稿：区间素数（ch04-006）

## 一、题目解读

输出 L~R 之间的所有素数，每行一个；一个都没有则输出 -1。课件例 4.16（100~200 的素数）的一般化。本章综合题：**双重循环 + break + bool 标志 + 空结果特判**，含金量十足。

## 二、思路分析

结构拆成两层：

- **外层**：i 从 L 到 R，挨个候选人过筛子；
- **内层**：判断 i 是不是素数——试除法：用 j = 2, 3, … 去除 i，找到一个约数就宣判"不是素数"。

试除到哪儿为止？**只需到 √i**。道理：若 i = a×b 且 a ≤ b，那么 a ≤ √i——约数总是成对出现，小的那个不会超过根号。这一下把内层从 i 次砍到 √i 次，R=10000 时整体不到 10⁶ 次运算，飞快。

判断"√j 以内"的写法有讲究：用 **`j * j <= i`** 代替 `j <= sqrt(i)`——整数乘法没有浮点误差，也省了每轮调函数。

## 三、代码讲解

```cpp
for (int i = L; i <= R; i++)
{
    bool isPrime = true;              // 先假设是素数
    for (int j = 2; j * j <= i; j++)
        if (i % j == 0)
        {
            isPrime = false;          // 抓到约数，推翻假设
            break;                    // 没必要再试了，提前离场
        }
    if (isPrime) { cout << i << endl; cnt++; }
}
if (cnt == 0) cout << -1 << endl;
```

三个精华点：
- **bool 标志变量**（isPrime）：内层循环的"结论"要带出来给外层用，标志变量是标准载体。"先假设成立，找到反例推翻"——这个模式在搜索、验证类问题里无处不在；
- **break**：找到约数后剩下的试除毫无意义，立刻跳出内层。注意 break 只跳出**一层**循环；
- **cnt 计数 + 特判 -1**：测试点 `24 28`（区间里全是合数）专门验收这个分支。另外注意 2 是素数：i=2 时内层条件 `j*j<=2` 一次都不执行，isPrime 保持 true——代码天然正确，测试点 `2 2` 验证的就是这个边界。

## 四、易错点

1. 内层写成 `j <= i/2` 甚至 `j < i`——能对但慢；写 `j*j <= i` 才是标准姿势。
2. 把 1 当素数（本题 L≥2 帮你挡掉了，但概念要清楚：1 不是素数）。
3. 忘记 -1 特判，空区间输出空白。
4. isPrime 定义在外层循环**外面**——第二个数开始标志没复位，全乱。**标志变量必须每轮重置**，所以定义在外层循环体内。

## 五、小结

试除法判素 = 内层循环 + 根号优化 + break + 标志变量，四件套一次配齐。它是数论题的敲门砖——以后学素数筛（一次算出一批素数），你会回头感激今天把"单个判素"吃透了。第 4 章完结，程序会重复了；下一章给程序装上"仓库"——数组。
