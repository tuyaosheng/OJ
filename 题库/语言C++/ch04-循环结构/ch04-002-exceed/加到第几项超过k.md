# 讲解稿：加到第几项超过k（ch04-002）

## 一、题目解读

s = 1 + 2 + 3 + … 一直加下去，问加到第几项时 s 首次**超过** k？输出项数和此时的 s。这是课件例 4.5 的一般化（课件里 k=1000）。

它和上一题的本质区别：上一题循环次数**事先知道**（就是 n 次）；这一题**事先不知道**要加多少项——什么时候停，取决于运行中的计算结果。

## 二、思路分析

"次数未知、看条件停"的循环，用 **while** 最自然：

> 只要 s 还没超过 k（`s <= k`），就再加一项。

循环体里做两件事：项数 n 加一、把第 n 项加进 s。循环一退出，说明 s 刚刚**第一次**超过 k——此时的 n 和 s 就是答案。

for 和 while 怎么选？口诀：**数得清用 for，数不清用 while。**

## 三、代码讲解

```cpp
long long k, s = 0, n = 0;
cin >> k;
while (s <= k)
{
    n++;
    s += n;
}
cout << n << " " << s << endl;
```

- 循环条件是 `s <= k`：注意题目要求"超过"（严格大于），所以"没超过"就是 `<=`，等于 k 时还要继续加。测试点 `5050`（恰好是 1+…+100）就是卡这个的：s 加到 5050 时等于 k、不算超过，还得加第 101 项，正确答案是 `101 5151`。**"超过"和"达到"一字之差，条件差一个等号**；
- k 最大 10^12，早已超出 int，k、s、n 统统 long long（n 大约到 141 万，其实 int 够，但统一用 long long 省心）；
- 循环体两句的顺序：先 `n++` 再 `s += n`——先报项号再加值。反过来写就错位了，样例一验就穿帮。

## 四、易错点

1. 条件写成 `s < k`：k 恰好等于某个前缀和时提前停了。
2. int 存 k——10^12 直接爆。
3. `n++` 和 `s += n` 顺序颠倒。
4. 输出忘了带 s，或顺序反了。

## 五、小结

while 处理"条件驱动"的循环；写条件时抠字眼——"超过"是 `>`，取反就是 `<=`。测试点最爱埋在"恰好相等"的临界处，写完先拿临界值走一遍脑内模拟，是避坑的不二法门。
