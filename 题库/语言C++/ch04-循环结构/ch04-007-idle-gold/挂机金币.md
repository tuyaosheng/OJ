# 挂机金币——讲解稿

## 一、题目解读

每秒收益翻倍（等比数列），问累计和第一次达到 k 是第几秒。它和例2"加到第几项超过k"是同一个骨架，换了两处：递增规则从"+1 项"变成"×2"，数据范围从普通 int 飙到 10^17。

## 二、思路分析

翻倍增长快得吓人：a=1 时 57 秒累计就超过 10^17。所以循环次数其实很少（最多约 60 次），**本题的陷阱全在数据类型**：

- k 最大 10^17，int 存不下（约 2.1×10^9 就爆）；
- 累计 sum、单秒收益 gain 在过程中也会到 10^17 级别；
- 三个量都必须 **long long**。

## 三、代码讲解

```cpp
long long sum = 0, gain = a;
while (sum < k) { sum += gain; gain *= 2; t++; }
```

循环不变式："每轮开始时，sum 是前 t 秒的累计"。先加当前收益、再翻倍、再计数，顺序别乱。

可以手推验证：a=1, k=10 → (t=1,sum=1) (t=2,sum=3) (t=3,sum=7) (t=4,sum=15) 停，输出 4。

## 四、易错点

1. 用 int 存 k / sum → 大数据溢出成负数，死循环或答案错；
2. 先翻倍再累加（顺序反）→ 第 1 秒就变 2a；
3. 循环条件写 `<=` → 恰好等于 k 时多挂一秒。

## 五、小结

看到"数据范围 10^17"先喊 long long；看到"到什么时候才…"选 while。两个反射都练到了。
