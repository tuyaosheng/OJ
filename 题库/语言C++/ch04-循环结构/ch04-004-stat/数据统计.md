# 讲解稿：数据统计（ch04-004）

## 一、题目解读

输入 n 个整数，输出最小值、最大值和平均值（保留 3 位小数）。课件例 4.8 原题。一道题串起三个本领：打擂台（第 3 章）、累加器（本章）、浮点输出（第 2 章）——期中小综合。

## 二、思路分析

要不要把 n 个数都存下来？**不需要！**求最值和平均值只要"看一眼就处理"：来一个数，跟当前最小/最大打擂台，再累加进 sum。全程只用 4 个变量，这叫**边读边处理**（在线处理）。数据量再大也不怕内存不够——这个意识很值钱（下一章遇到"必须存下来"的问题，才轮到数组出场）。

初值怎么设？擂台题的标准答案：**读第一个数，直接用它当 minn 和 maxn 的初值**。拍脑袋设 `minn = 999999` 之类的"魔法数"，一旦数据范围变了就翻车。

## 三、代码讲解

```cpp
cin >> n;
cin >> x;                       // 第一个数单独读
int minn = x, maxn = x;
long long sum = x;
for (int i = 2; i <= n; i++)    // 从第 2 个数开始循环
{
    cin >> x;
    if (x < minn) minn = x;
    if (x > maxn) maxn = x;
    sum += x;
}
double avg = (double)sum / n;
cout << minn << " " << maxn << " "
     << fixed << setprecision(3) << avg << endl;
```

三个讲点：
- 循环从 i=2 开始——第一个数已经在外面处理过了，这是"首元素特殊处理"的常用结构；
- `(double)sum / n`：**强制类型转换**。sum 和 n 都是整型，直接除会把小数砍光（35/8 = 4 而不是 4.375）。把 sum 转成 double，除法就升级为浮点除法。写 `sum * 1.0 / n` 效果相同；
- `fixed << setprecision(3)`：保留 3 位。样例 35 ÷ 8 = 4.375 正好整；测试点里 5 ÷ 3 = 1.666… → 输出 1.667（四舍五入自动完成）。

测试点覆盖：单元素（min=max）、全相同、含 ±1000 极值、除不尽的平均值。

## 四、易错点

1. `sum / n` 忘转 double——平均值只剩整数部分，样例都过不了。
2. minn/maxn 初值用 0 或魔法数——全正数或全负数数据翻车。
3. n=1 时循环一次都不走——首元素在外面处理的写法天然正确，检验你的结构是否健壮。
4. 平均值保留位数写错（本题 3 位）。

## 五、小结

边读边处理省内存；初值取自第一个数；整数相除记得转 double。这题的结构——"读首个 → 循环更新 → 结算输出"，以后统计类题目直接套用。
