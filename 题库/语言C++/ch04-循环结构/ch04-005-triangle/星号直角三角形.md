# 讲解稿：星号直角三角形（ch04-005）

## 一、题目解读

输入 n，打印 n 行星号直角三角形：第 i 行 i 个星。课件例 4.13 原题。第 1 章我们"手动"打过固定的菱形，今天用**循环嵌套**打印任意大小的图形——从"死"图形到"活"图形。

## 二、思路分析

打印图形的万能分析法——**先回答两个问题**：

1. 一共几行？→ n 行 → 外层循环 `i = 1..n`；
2. 第 i 行有什么？→ i 个星号 → 内层循环 `j = 1..i`，打一个星。

内外层的关系要用一句话焊死在脑子里：**外层走一步，内层跑全程**。i=1 时内层打 1 个星，i=2 时打 2 个……内层的终点 `j <= i` 用到了外层的 i——这正是"每行内容不同"的来源。

## 三、代码讲解

```cpp
for (int i = 1; i <= n; i++)      // 第 i 行
{
    for (int j = 1; j <= i; j++)  // 本行打 i 个星
        cout << "*";
    cout << endl;                 // 本行结束，换行
}
```

最要紧的细节是 `cout << endl;` 的**位置**：它在内层循环外面、外层循环里面——每行打完星号才换一次行。挪错位置的两种惨案：
- 放进内层：每个星号后面都换行，图形变成一竖条；
- 放到外层外面：所有星号挤在一行。

写嵌套循环时，用缩进对齐来"看"清楚每条语句归谁管，是最有效的自查手段。

## 四、易错点

1. `endl` 位置放错（上面两种惨案）。
2. 内层条件写成 `j <= n`——打出 n×n 的实心方块。
3. 行尾多打空格——本题星号后面什么都不要加。
4. 内外层循环变量都写 i——变量名冲突，行为诡异。

## 五、小结

图形题两问：几行？每行什么？外层管行、内层管列，`endl` 卡在两层之间。学会这套，倒三角、空心三角、金字塔都是换个内层条件的事——课后把"倒直角三角形"（第 1 行 n 个星，递减到 1 个）写出来，检验一下。
