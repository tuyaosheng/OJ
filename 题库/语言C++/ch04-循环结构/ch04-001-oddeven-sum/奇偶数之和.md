# 讲解稿：奇偶数之和（ch04-001）

## 一、题目解读

计算 1~n 中奇数的和与偶数的和。这是课件例 4.3 的一般化版本（课件里 n=100），考察 for 循环最核心的应用——**累加器模式**。

## 二、思路分析

想象两个存钱罐：sum1 收奇数，sum2 收偶数。让 i 从 1 数到 n，每个数来了先看奇偶（第 3 章的 if），再投进对应的罐子（累加）。

**循环 + 分支的组合**从这题开始成为常态：for 负责"每个数都过一遍"，if 负责"这个数怎么处理"。

关键细节是**数据范围**：n 最大 100 万，偶数和约 2.5×10^11，早就超过 int 上限（约 2.1×10^9）了。所以两个累加器必须用 **long long**。这是本题真正的"考点"——循环写对了但用 int，大数据全错，只能拿部分分。

## 三、代码讲解

```cpp
long long sum1 = 0, sum2 = 0;   // 累加器必须清零 + long long
for (int i = 1; i <= n; i++)
{
    if (i % 2 == 1) sum1 += i;
    else            sum2 += i;
}
cout << sum1 << " " << sum2 << endl;
```

- for 的三段式：`for (初始化; 条件; 调整)`——i 从 1 出发，每轮加 1，直到超过 n 停下；
- 累加器**初值必须是 0**，且要在循环外定义（放循环里每轮都会归零）；
- `sum1 += i` 是 `sum1 = sum1 + i` 的缩写。

验算样例：n=100，奇数和 = 1+3+…+99 = 50² = 2500，偶数和 = 2+4+…+100 = 2550。（等差数列求和，数学可以秒出答案——但本章练的是循环，两种方法互相验证是好习惯。）

## 四、易错点

1. **累加器用 int**：n=10^6 时溢出成负数或乱值。先估算"最坏情况的和"再定类型。
2. 累加器忘清零或定义在循环内部。
3. 循环条件 `i < n` 少算了 n 本身——差一错误（off-by-one），循环题永远的痛。

## 五、小结

累加器模式三件事：**循环外定义、初值清零、类型够大**。"循环过数据 + 分支做决定"是接下来所有题的骨架。顺手留个思考：不用循环，用等差数列公式 O(1) 直接算，怎么写？两种都会，才算真懂。
