## 上课怎么开场

黑板上写：`1 + 2 + 3 + ... + 100`。"这道题谁会做？"——总有学生喊"高斯公式，n(n+1)/2"。"厉害，那如果我不让你用公式，只让你用加法呢？"

停一下，等学生反应过来："这不就是重复做同一件事 100 次吗？"——对，就是这句话。前三章你们写的程序，从第一行执行到最后一行，一次过；但计算机真正厉害的地方，是能把同一句话不知疲倦地重复几万次、几亿次。**循环**要解决的问题只有一个：把"重复"这件事从"你重复写代码"变成"让计算机重复执行代码"。

学会循环之后，"数据规模"这个词才第一次有意义——n 是 10 还是 10 万，对你写的代码几乎没区别，对计算机的耗时才有区别。这也是本章之后所有算法章节的地基。

## for 循环与累加器：从 1 加到 n 的奇偶拆分（例1）

黑板上写题目：输入 n，分别求 1~n 中所有奇数的和、所有偶数的和。先别写代码，**手算** n=6 的情况，边算边把过程记在一张表里：

| i | i 是奇数还是偶数 | sum1（奇数和） | sum2（偶数和） |
|---|---|---|---|
| 1 | 奇 | 0+1=1 | 0 |
| 2 | 偶 | 1 | 0+2=2 |
| 3 | 奇 | 1+3=4 | 2 |
| 4 | 偶 | 4 | 2+4=6 |
| 5 | 奇 | 4+5=9 | 6 |
| 6 | 偶 | 9 | 6+6=12 |

走到 i=6，n 用完了，最终 sum1=9，sum2=12。问学生一句："这张表里，每一行是不是都在做同一件事？"——是，都是"看一眼 i 的奇偶，加到对应的桶里"。**这种"看一眼、决定往哪加"的重复动作，就是 for 循环该干的事**。

翻译成代码：

```cpp
int sum1 = 0, sum2 = 0;      // 累加器：用之前必须先清零
for (int i = 1; i <= n; i++) // 三段式：初始化；继续条件；步进
{
    if (i % 2 == 1) sum1 += i;
    else            sum2 += i;
}
```

关键是让学生在脑子里"走"一遍执行顺序，而不是把 for 当成一个黑盒：先执行 `int i = 1`（只做一次），然后反复三件事——**判断 `i <= n`**，成立就**执行循环体**，再**执行 `i++`**，回到判断，直到条件不成立为止。这三件事的先后顺序，就是黑板上那张表每一行诞生的过程：i 每变一次，表就多一行。

到这里切 `循环追踪演示.html` 的"for 循环"页签，把 n 设成 6，一步步点"下一步"。注意看代码框里高亮的那一行会在"判断条件"和"执行循环体"和"步进 i++"之间来回跳——**一次循环并不是走一步，是三步、有时候还不止**。这一点光讲不演示，学生很难建立起直觉。

停下来问一句："如果把 `for (int i = 1; i <= n; i++)` 写成 `i < n`，n=6 时最后一次会漏掉哪个数？"——会漏掉 i=6，sum2 少加 6，变成 6。这是循环里最常见的"差一错误"（off-by-one），以后每次写 for 都要下意识确认一下边界。

## while 循环：条件循环，不知道要跑几次（例2、练1）

例1 的循环次数是已知的——n 给多少就跑多少次。但例2 问的是："s = 1+2+3+…，加到第几项时 s 会首次超过 k？"（课件里 k=1000）。这里的次数**未知**，你不知道要加到第几项才够，只知道"什么时候该停"这个**条件**。这正是 for 和 while 的分工：**知道次数用 for，只知道停止条件用 while**。

代码：

```cpp
long long k, s = 0;
long long n = 0;
cin >> k;
while (s <= k)   // 只要还没超过 k，就继续加
{
    n++;
    s += n;
}
```

手算一下 k=1000 时前几步和最后几步，别指望全部 45 步都写在黑板上，但**头几步和收尾那一步一定要走一遍**：

| n | s（累加后） | s <= 1000 ？ |
|---|---|---|
| 1 | 1 | 是，继续 |
| 2 | 3 | 是，继续 |
| 3 | 6 | 是，继续 |
| … | … | … |
| 44 | 990 | 是，继续 |
| 45 | 1035 | **否，循环结束** |

问学生："第 44 步的时候 s=990，还没超过 1000，所以循环体还要再跑一次，变成 n=45，s=1035。这时候再检查一次 `s <= k`，发现 1035 已经超过 1000 了，循环才停。"——**判断永远在循环体执行之后再检查一次**，这是 while 循环"先干后查"还是"先查后干"要讲清楚的地方：这里是 `while(...)` 打头，是**先查后干**——如果一开始 s 就已经超过 k（比如 k 是负数），循环体一次都不会执行。

到这里切 `循环追踪演示.html` 的"while 循环"页签。演示时把 k 设成一个小一点的数字（比如 20）方便完整看完，别设成 1000——不是原理变了，只是 45 行看不过来。屏幕上会看到：n=5 时 s=15，还不够；n=6 时 s=21，超过 20，循环结束。跟黑板上 1000 的例子是同一套逻辑，只是数字小方便投屏演示，真正考试遇到的 k 该多大就多大。

【练1】调和级数问的是"1 + 1/2 + 1/3 + … 加到第几项超过 k"，骨架跟例2一模一样，只是累加器换成了 `double`。比如 k=2 时：n=1，s=1（不够）；n=2，s=1.5（不够）；n=3，s≈1.8333（不够）；n=4，s≈2.0833，超过 2，停。这里的坑是 `1/n`——n 是整数，`1/n` 在 C++ 里做的是**整数除法**，n≥2 时结果全是 0，必须写成 `1.0/n` 强制变成浮点除法。这个坑几乎每届都有人踩，讲到这道题务必现场敲一遍 `1/n` 和 `1.0/n` 的区别给学生看。

## 边读边算：不存数据也能统计（练2）

【练2】数据统计要求边输入边求最大值、最小值、平均值，**不需要把 n 个数存起来**。手算一遍数据 `3, -2, 8, 0, 5`：

| 读入的数 | min | max | sum |
|---|---|---|---|
| 3（第一个，初始化用） | 3 | 3 | 3 |
| -2 | -2 | 3 | 1 |
| 8 | -2 | 8 | 9 |
| 0 | -2 | 8 | 9 |
| 5 | -2 | 8 | 14 |

n=5，sum=14，平均值 14/5=2.800。代码是"打擂台"模式（第 3 章学过）套进循环里：

```cpp
int x; cin >> x;
int minn = x, maxn = x;      // 第一个数就是当前的擂主
long long sum = x;
for (int i = 2; i <= n; i++)
{
    cin >> x;
    if (x < minn) minn = x;
    if (x > maxn) maxn = x;
    sum += x;
}
```

问一句容易漏的："如果我图省事，把 `minn` 初始化成 0，会有什么后果？"——让学生自己举反例：如果这组数全是负数，比如 `-5, -3, -8, -1`，真正的最大值是 -1，但如果 `maxn` 一开始就是 0，循环里 `x > maxn` 永远不成立（-1 也小于 0），最后输出的最大值会错误地停在 0。**擂主必须用数据本身的第一个值来初始化**，不能想当然用 0，这是这道题最容易挖坑考的地方。

## 双重循环：外层管行，内层管列（例3）

星号直角三角形：输入 n，打印 n 行，第 i 行有 i 个星号。n=4 时黑板上画出来是这样：

```
*
**
***
****
```

问学生："第 3 行有几个星号？"——3 个，"跟行号什么关系？"——相等。这是双重循环最朴素的心法：**先只看外层变量 i，找出"这一行要做几次内层动作"的函数关系**，剩下的就是套模板：

```cpp
for (int i = 1; i <= n; i++)      // 外层：第几行
{
    for (int j = 1; j <= i; j++)  // 内层：这一行打印几个星号，取决于 i
        cout << "*";
    cout << endl;                 // 一行结束才换行，别放错位置
}
```

n=4 一共打印了 1+2+3+4=10 个星号，也就是内层循环体总共执行了 10 次——**双重循环的执行次数是内外两层次数相乘（或求和），不是简单的 n 次**，这是"复杂度"这个概念在本章最直观的第一次现身，第 10 章讲枚举、第 12 章讲排序时还会反复用到这句话。

## 枚举 + 判定：区间素数与 break（例4）

本章收官题：输出区间 [L, R] 内所有素数。先复习素数定义："只能被 1 和自己整除的数（大于1）"，判断 x 是不是素数的笨办法是从 2 试除到 x-1，但更快的办法是**只试到 `sqrt(x)`**——问学生为什么够用："如果 x 有一个大于 `sqrt(x)` 的因数，那它一定还有一个小于 `sqrt(x)` 的因数跟它配对，配对的那个早就在前面被试出来了。"

黑板上手算 L=10，R=20：

| i | 试除过程 | 结论 |
|---|---|---|
| 10 | j=2 时 10%2=0 | 不是素数 |
| 11 | j=2,3 都除不尽（j=4 时 4×4=16>11，停） | **素数** |
| 12 | j=2 时 12%2=0，立刻 `break` | 不是素数 |
| 13 | j=2,3 除不尽（4×4=16>13，停） | **素数** |
| 14 | j=2 时整除 | 不是素数 |
| 15 | j=3 时整除 | 不是素数 |
| 16 | j=2 时整除 | 不是素数 |
| 17 | j=2,3,4 都除不尽（5×5=25>17，停） | **素数** |
| 18 | j=2 时整除 | 不是素数 |
| 19 | j=2,3,4 都除不尽（5×5=25>19，停） | **素数** |
| 20 | j=2 时整除 | 不是素数 |

答案：11、13、17、19，共 4 个。代码：

```cpp
for (int i = L; i <= R; i++)
{
    bool isPrime = true;
    for (int j = 2; j * j <= i; j++)
        if (i % j == 0) { isPrime = false; break; }  // 找到一个因数就够了，不用继续试
    if (isPrime) { cout << i << endl; cnt++; }
}
```

拿 12 和 17 对比着讲：12 在 j=2 那一步立刻查出有因数，`break` 直接跳出内层循环，不会傻乎乎地继续试 j=3；17 一路试到 j=4 都没找到因数，`j*j<=i` 不满足了才自然退出循环，两种"退出方式"——`break` 主动跳出、条件不满足自然结束——学生要能分清楚。

## 复杂度与几个通用心法，一句带过

for 循环适合"次数已知"，while 适合"条件已知、次数未知"；双重循环的执行次数是内外层相乘；`break` 提前结束整个循环，`continue` 只跳过当前这一轮——本章之后见到"数据规模"三个字，脑子里要能反应出"这段代码大概要跑多少次"。

## 学生最容易栽的坑

带过几届课下来，这几个错误年年都有人犯：

1. 累加器忘清零（多组数据时尤甚）——上一组的残留值悄悄加进了这一组。
2. `for (i = 1; i <= n; i++)` 写成 `<`，少跑一次——边界差一（off-by-one）是循环第一大坑，例1 的 n=6 漏加 6 就是这个错。
3. while 循环体里忘了改变条件变量，比如漏写 `n++` 或 `s += n` 中的一句 → 死循环，程序卡死交上去直接 TLE。
4. 最值初始化成 0，遇全负数就错——练2 的反例 `-5,-3,-8,-1` 讲一遍学生印象最深。
5. 双重循环内外层变量写混（都用 i，内层该用 j 却手滑写成 i）——编译器不会报错，但结果全乱。
6. 判素数：1 不是素数、2 是素数，两个特判都别丢；`1.0/n` 写成 `1/n` 是调和级数这道题的专属坑。
7. 循环里 `cin` 读入失败没察觉（数据个数和 n 不符），后面的判断全部基于错误数据继续跑。
