**思考方式：一个位置一个位置地填**

我们要生成一个长度为 n 的排列。可以这样想：

> **第 1 个位置放谁？** 有 n 种选择。
> **第 2 个位置放谁？** 从**没用过**的数里选，有 n−1 种。
> **……**
> **全部填满后**，就得到了一个完整的排列，输出它。

用递归表达："**填第 pos 个位置**"这件事：

```cpp
int path[10];       // path[i] 记录第 i 个位置填了什么
bool used[10];      // used[v] 标记数字 v 是否已经被用掉

void dfs(int pos, int n)
{
    if (pos > n)                    // 【边界】n 个位置都填满了
    {
        for (int i = 1; i <= n; i++)     // 输出这个完整的排列
            cout << path[i] << (i == n ? "\n" : " ");
        return;
    }

    // 在第 pos 个位置上，依次尝试每一个数字
    for (int v = 1; v <= n; v++)
    {
        if (used[v]) continue;      // v 已经用过了，跳过（排列中每个数只能出现一次）

        path[pos] = v;              // ① 尝试：把 v 填在第 pos 位
        used[v] = true;             // ② 标记 v 已被使用

        dfs(pos + 1, n);            // ③ 递归：去填下一个位置

        used[v] = false;            // ④ ★撤销★：把 v 释放掉，好让别的分支能用它
    }
}
```

从 `dfs(1, n)` 开始调用。

---

**最关键的一行：`used[v] = false;`（撤销）**

这是**回溯的灵魂**，也是初学者**最容易漏掉**的一行。

**为什么必须撤销？**

假设 n = 3。当我们探索完 `1 2 3` 和 `1 3 2` 这两个分支后（即"第 1 位填 1"的所有可能），要回来尝试"第 1 位填 2"。

此时如果不把 `used[2]`、`used[3]` 恢复成 `false`，它们就还带着上一个分支的"脏数据"——后面的分支会误以为 2 和 3 已经被用了，导致**大量排列丢失**。

> **形象地说**：递归就像走迷宫探路。你走进一条岔路（做标记），走到底发现是死路（或已走完），**回来时必须把标记擦掉**，否则会影响你走另一条路。
>
> **"来的时候做标记，走的时候擦掉"** —— 这就是回溯。

---

**为什么天然就是字典序？**

因为在每个位置上，我们都是**从小到大**（`for v = 1 to n`）尝试的。所以先生成的排列，字典序一定更小。**不需要额外排序。**

**复杂度**：O(n! × n)。n = 8 时 8! = 40320 个排列，每个输出 8 个数，共 32 万次输出，很快。

**（拓展）** C++ 其实内置了 `next_permutation` 函数可以直接生成下一个排列。但**本题的价值在于亲手实现递归回溯框架**——这是下一章的必备基础，请务必手写一遍。
