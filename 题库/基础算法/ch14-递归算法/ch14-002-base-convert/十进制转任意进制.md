# 讲解稿：十进制转任意进制（ch14-002）

## 一、题目解读

把十进制数 n 转成 k 进制（2 ≤ k ≤ 16），超过 9 的数位用大写字母 A~F 表示。

例：30 转 16 进制 = **1E**（30 = 1×16 + 14，14 → E）。

**这题展示了递归的一个"循环做不到"的独门绝技。**

## 二、思路分析

### 进制转换的原理：不断除以 k，取余数

这是大家熟悉的"除 k 取余法"：

```
30 ÷ 16 = 1 ... 余 14  (E)     ← 最低位
 1 ÷ 16 = 0 ... 余 1           ← 次低位
（商为 0，停止）
```

把余数**倒着读**：1、E → **`1E`** ✓

### 麻烦来了：顺序是反的！

注意：

- **余数产生的顺序**：从**低位到高位**（先得到 E，再得到 1）
- **要求输出的顺序**：从**高位到低位**（先打印 1，再打印 E）

**正好相反！**

**用循环怎么办？** 只能先把余数**存进数组**，再**倒着遍历**打印：

```cpp
int digits[64], cnt = 0;
while (n > 0) {
    digits[cnt++] = n % k;      // 存起来
    n /= k;
}
for (int i = cnt - 1; i >= 0; i--)   // 倒着打印
    cout << digitChar(digits[i]);
```

能用，但要**额外开一个数组**，还要小心下标。

### 递归的绝技：让顺序"自动"反转

**递归可以不用数组，直接倒序输出。** 秘诀只有一句话：

> ### **把输出语句，放在递归调用的【后面】。**

```cpp
void convert(long long n, int k)
{
    if (n == 0) return;             // 边界：除到 0 就停

    convert(n / k, k);              // ★ 先递归（处理更高位）

    cout << digitChar(n % k);       // ★ 后输出（当前位）
}
```

### 为什么这样就反转了？——推演一遍

以 `convert(30, 16)` 为例，**盯住每一步在干什么**：

| 步骤 | 发生了什么 | 已输出 |
|------|-----------|--------|
| 1 | `convert(30)` 开始。**先**去调用 `convert(1)`（30/16=1） | （空） |
| 2 | `convert(1)` 开始。**先**去调用 `convert(0)`（1/16=0） | （空） |
| 3 | `convert(0)` → 触发边界，**立即返回** | （空） |
| 4 | **回到** `convert(1)`。现在轮到它输出了：`1 % 16 = 1` | `1` |
| 5 | **回到** `convert(30)`。现在轮到它输出了：`30 % 16 = 14 → E` | `1E` |

**最终输出 `1E`** ✓

**关键在于**：因为 `cout` 写在递归调用**之后**，所以它不会在"往下深入"的时候执行，而是在**"往回返回"的路上**才执行。

而**返回的顺序，恰好和调用的顺序相反**——最深层（最高位）最先返回，也就最先被打印。

> ### 递归的"去"与"回"
>
> 递归调用有两个阶段：
> - **"去"（递）**：一层层深入，拆解问题。
> - **"回"（归）**：一层层返回，处理结果。
>
> **`cout` 放在递归【前】 → 在"去"的路上执行 → 正序输出**
> **`cout` 放在递归【后】 → 在"回"的路上执行 → 倒序输出**
>
> **一行代码的位置，决定了输出的顺序。** 这就是递归的魅力。

（这个"在返回路上做事"的特性，正式的名字叫**回溯**。下一章我们会大量用到它。）

## 三、代码讲解

### 数位转字符

```cpp
char digitChar(int r)
{
    if (r < 10)  return '0' + r;         // 0~9  → '0'~'9'
    else         return 'A' + (r - 10);  // 10~15 → 'A'~'F'
}
```

利用了字符在 ASCII 中**连续排列**的特性。比如 `r = 12`：`'A' + (12-10) = 'A' + 2 = 'C'` ✓

### 本题最容易漏的坑：n = 0

递归边界是 `if (n == 0) return;`。

那么当**输入的 n 本身就是 0** 时会发生什么？

`convert(0, k)` 被调用 → 立刻触发边界 → **直接返回，什么都不输出！**

程序会打印一个**空行**，而正确答案应该是 **`0`**。

**必须单独特判**：

```cpp
if (n == 0) { cout << 0 << "\n"; return 0; }
```

> **教训**：写完递归，一定要**单独检查"输入就是边界值"的情况**。递归函数往往在边界处"什么都不做"，而这恰恰可能是题目要求输出的东西。

（测试数据里专门有 n=0 的一组。）

## 四、易错点

1. **忘记特判 n = 0** —— 输出空行。**本题头号坑。**
2. **把 `cout` 放在递归前面** —— 输出变成倒序（`E1` 而不是 `1E`）。
3. **字母转换写错** —— 忘了 `- 10`，或者用了小写字母。
4. **用 int 存 n** —— n 可达 2×10^9，接近 int 上限，建议用 `long long` 保险。
5. **递归边界写成 `n < 0`** —— 永远不会触发，无限递归。

## 五、小结

**核心口诀**：

> **想正序输出，`cout` 放递归【前】；**
> **想倒序输出，`cout` 放递归【后】。**

这个技巧的应用远不止进制转换：

- **倒序打印链表**（不修改链表结构）
- **递归输出数字的每一位**
- **树的先序 / 后序遍历**（本质上就是"在递归前做事"和"在递归后做事"的区别！）

**更深的领悟**：

递归函数不是"调用一次就完事"，它有**两个时机**可以做事——**下去的时候**和**回来的时候**。学会利用"回来的时候"，是掌握递归的重要一步。
