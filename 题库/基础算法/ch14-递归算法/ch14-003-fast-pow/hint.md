**分治推导**

分两种情况讨论指数 b 的奇偶：

**b 是偶数**：`a^b = (a^(b/2))²`

例如 `a^8 = (a^4)²` —— 只要算出 `a^4`，平方一下就行。

**b 是奇数**：`a^b = (a^(b/2))² × a`

例如 `a^9 = (a^4)² × a` —— 因为 `9 / 2 = 4`（整数除法丢掉了余数 1），所以要**补乘一个 a**。

**递归边界**：`a^0 = 1`。

**代码**：

```cpp
long long power(long long a, long long b, long long p)
{
    if (b == 0) return 1 % p;           // 边界！注意是 1 % p 不是 1

    long long half = power(a, b / 2, p);    // 递归算出"一半"的幂
    long long res = half * half % p;        // 平方

    if (b % 2 == 1)                     // b 是奇数，补乘一个 a
        res = res * a % p;

    return res;
}
```

**注意：`half` 只算【一次】！**

千万别写成 `power(a,b/2,p) * power(a,b/2,p)` —— 那样会**调用两次**，复杂度退化回 O(b)，完全白费！

必须**先把结果存进变量 `half`，再平方**。（这个坑和第 1 题的斐波那契异曲同工：**避免重复计算**。）

---

**三个致命的溢出/边界陷阱**：

1. **`b` 必须用 `long long`** —— 它可达 10^18，int 装不下。

2. **乘法会溢出！** `half * half` 时，half 最大接近 p ≈ 10^9，平方就是 **10^18** —— `long long` 上限 9.2×10^18，**刚好装得下**。但如果 p 再大一点（比如 10^18），就必须用 `__int128` 或"龟速乘"了。**本题 p ≤ 10^9，用 long long 安全。**

3. **`return 1 % p`，不能直接 `return 1`！**
   因为 **p 可能等于 1**！此时任何数 mod 1 都应该是 **0**，但如果你返回 1，答案就错了。
   （测试数据里专门有 p = 1 的一组，专治这个 bug。）

**另外**：a 也要先取模（`a %= p`），防止 a 本身就比 p 大。
