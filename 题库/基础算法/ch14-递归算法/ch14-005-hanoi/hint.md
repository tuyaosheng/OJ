**关键：不要试图想清楚每一步！**

初学者最大的误区，是想在脑子里把 n=5 的每一步都推演出来——**那是自找苦吃**。

递归的精髓是：**信任递归**（"递归信仰"）。你只需要想清楚**一层**该怎么做，把剩下的**交给递归自己**。

---

**汉诺塔的递归结构**

要把 **n 个盘子**从 **A** 移到 **C**（借助 B），只需三步：

```
       A            B            C
    ┌──┴──┐
    │ 上面 │
    │ n-1 个│
    ├─────┤
    │ 第n号 │  ← 最大的那个
    └─────┘
```

**第 ① 步**：把上面的 **n−1 个**盘子，从 **A** 移到 **B**（借助 C）。
> **怎么移？别管！** 这是一个规模为 n−1 的**同类子问题**，交给递归。

**第 ② 步**：把**最大的第 n 号**盘子，从 **A** 直接移到 **C**。
> 此时 A 上只剩它一个，C 是空的 —— 一步到位，直接输出这次移动。

**第 ③ 步**：把那 **n−1 个**盘子，从 **B** 移到 **C**（借助 A）。
> 同样交给递归。

**完事！** 因为第 ② 步移动的是**最大**的盘子，而此时 C 是空的，所以绝不会违反"大压小"的规则。

---

**代码（核心就三行）**

```cpp
// 把 n 个盘子，从 from 柱，借助 via 柱，移动到 to 柱
void hanoi(int n, char from, char via, char to)
{
    if (n == 0) return;                  // 边界：没有盘子要移，收工

    hanoi(n - 1, from, to, via);         // ① n-1 个：from -> via（借助 to）

    step++;                              // ② 移动第 n 号盘子：from -> to
    cout << "第" << step << "步：将第" << n
         << "号盘子从" << from << "柱移动到" << to << "柱\n";

    hanoi(n - 1, via, from, to);         // ③ n-1 个：via -> to（借助 from）
}
```

调用：`hanoi(n, 'A', 'B', 'C')`。

**注意三个柱子参数的顺序！** 这是最容易搞混的地方：
- 第 ① 步：目标是 **via**，所以"借助"的柱子变成了 **to**；
- 第 ③ 步：起点是 **via**，"借助"的柱子变成了 **from**。

**建议**：把函数签名理解成 `hanoi(要移几个, 从哪来, 借助谁, 到哪去)`，然后对着上面三步逐一对应。

---

**总步数**：设 T(n) 为移动 n 个盘子的步数，由上面的三步可得：

**T(n) = T(n−1) + 1 + T(n−1) = 2·T(n−1) + 1**

配合 T(0) = 0，解得：

### **T(n) = 2^n − 1**

n = 15 时是 **32767** 步。（传说中的"64 个盘子"需要 2^64−1 ≈ 1.8×10^19 步，每秒移一个也要 5800 亿年——比宇宙年龄还长。）

**输出量提醒**：n=15 有 3 万多行输出，建议加 `ios::sync_with_stdio(false)` 加速。
