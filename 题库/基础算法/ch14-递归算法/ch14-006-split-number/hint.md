**核心难点：如何避免重复？**

如果不加限制地枚举，`2 3` 和 `3 2` 会被当成两种方案——但它们其实是同一种拆分。

**解决办法极其巧妙**：**强制要求拆出来的数【非递减】**（后一个 ≥ 前一个）。

这样一来，`3 2` 这种"后面比前面小"的写法**根本不会被生成**，每种拆分**有且仅有一个**合法的表示形式 → **天然不重不漏！**

**怎么实现"非递减"？** 给递归函数加一个参数 `start`，表示"**这一层最小只能从 start 开始选**"：

```cpp
int path[35];   // 记录当前已选的数
int n;

// rest  = 还剩多少没拆
// start = 这一层最小能选的数（保证非递减）
// cnt   = 已经选了几个数
void dfs(int rest, int start, int cnt)
{
    if (rest == 0)                      // 拆完了！
    {
        if (cnt >= 2)                   // 至少要有 2 个数（排除 n = n 自己）
        {
            for (int i = 0; i < cnt; i++)
                cout << path[i] << (i == cnt - 1 ? "\n" : " ");
        }
        return;
    }

    // 这一层选一个数 v，必须满足：v >= start（非递减）且 v <= rest（不能超）
    for (int v = start; v <= rest; v++)
    {
        path[cnt] = v;                  // ① 尝试选 v
        dfs(rest - v, v, cnt + 1);       // ② 递归：剩余变少，下次最小从 v 开始
        // ③ 撤销：这里不需要显式撤销！
        //    因为 path[cnt] 会在下一轮循环中被直接覆盖，且我们只用前 cnt 个元素
    }
}
```

调用：`dfs(n, 1, 0)` —— 要拆 n，最小从 1 开始选，当前已选 0 个。

**关键在这一行**：`dfs(rest - v, v, cnt + 1)`

注意第二个参数传的是 **`v`**（不是 `v + 1`！）。因为**允许重复使用同一个数**（比如 `1 1 1 1 1`），所以下一层最小仍可以选 `v`。

（如果传 `v + 1`，就变成"每个数只能用一次"了 —— 那是另一类问题。）

---

**为什么这题不用显式"撤销"？**

上一题（全排列）里，我们必须写 `used[v] = false`。这题为什么不用？

因为**状态的记录方式不同**：

- 全排列用了一个**全局的 `used[]` 标记数组**，它会被"污染"，所以必须手动擦干净。
- 这题的"状态"全部通过**函数参数**（`rest`、`start`、`cnt`）传递 —— 参数是**每层独立的**，递归返回时自动恢复，无需手动撤销。而 `path[cnt]` 会被下一轮循环直接覆盖，也不影响。

> **经验**：能用**参数**传递状态时，就不必手动撤销；用**全局变量/数组**记录状态时，就**必须**记得撤销。

---

**为什么天然是字典序？** 因为每层都从小到大枚举 `v`。

**至少 2 个数**：在边界处判断 `cnt >= 2`。若不判断，会多输出一行 `n` 本身。

**复杂度**：方案数随 n 增长（n=30 时约 5600 种），完全能承受。
