斐波那契数列的定义大家已经很熟悉了：

**F(1) = 1，F(2) = 1，F(n) = F(n−1) + F(n−2)**

上一章我们用**递推**（循环，从小往大推）求过它。这一章我们换个视角——用**递归**（函数自己调用自己，从大往小拆）来求。

给定 n（1 ≤ n ≤ 90），请输出 F(n)。

**⚠️ 但这题有个陷阱。** 如果你直接写最朴素的递归：

```cpp
long long fib(int n)
{
    if (n <= 2) return 1;
    return fib(n - 1) + fib(n - 2);    // 看起来很优雅……
}
```

代码只有三行，优雅极了——**但它会超时**。n = 90 时，这个函数会被调用**几十亿次**，跑到天荒地老。

**为什么？问题出在哪？该怎么救？** 这正是本题要教给你的东西。
