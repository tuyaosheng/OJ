n 个盘的最优解结构是三段：

```
[前 2^(n-1) − 1 步]  移 n-1 个盘（子问题）
[正中间第 2^(n-1) 步] 移动第 n 号盘（最大盘唯一的一步！）
[后 2^(n-1) − 1 步]  再移 n-1 个盘（子问题）
```

所以设 mid = 2^(n−1)：

- k == mid → 答案就是 n；
- k < mid → 答案在前半段，等价于子问题 (n−1, k)；
- k > mid → 答案在后半段，等价于子问题 (n−1, k − mid)。

每递归一层 n 减 1，最多 60 层——这就是"每次砍掉一半"的分治递归。（彩蛋：答案其实等于"k 的二进制末尾 0 的个数 + 1"，想想为什么？）
