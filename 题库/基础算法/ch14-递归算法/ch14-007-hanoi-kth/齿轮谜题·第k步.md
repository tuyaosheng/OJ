# 齿轮谜题·第k步——讲解稿

## 一、题目解读

不模拟整个过程（2^60 步，宇宙热寂都跑不完），直接回答"第 k 步移谁"。这是汉诺塔（例4）的思维续作：例4 让你**信任递归**把过程走完，本题让你**利用递归结构**在过程里精确定位。

## 二、思路分析

回忆例4 的三段式：n 个盘 = [n−1 盘子问题] + [移第 n 号盘 1 步] + [n−1 盘子问题]。

三段的长度是 (2^(n-1)−1) + 1 + (2^(n-1)−1)。所以第 n 号盘**有且只有一步**，恰好落在正中间 mid = 2^(n−1)。

于是第 k 步三选一：

- 正中 → n 号盘；
- 前半 → 就是 (n−1) 盘问题的第 k 步；
- 后半 → 后半段和前半段是**完全同构**的搬运过程，第 k 步对应子问题的第 k − mid 步。

每层砍掉一半步数、盘数减一，最多 60 层递归——O(n) 出答案。

## 三、代码讲解

```cpp
long long mid = 1LL << (n - 1);
if (k == mid) return n;
if (k < mid) return solve(n - 1, k);
return solve(n - 1, k - mid);
```

- `1LL << (n-1)`：**必须写 1LL**！`1 << 59` 是 int 移位，直接溢出成未定义行为——这是位运算最著名的坑；
- k 用 long long 全程携带；
- 递归边界藏在数学里：n=1 时 k 只能是 1==mid，第一分支必命中，不会递归到 n=0。

**彩蛋验证**：序列 n=3 是 1,2,1,3,1,2,1——第 k 步的盘号 = k 的二进制末尾 0 个数 + 1（k=4=100₂ 末尾两个 0 → 3 号盘 ✓）。用这个规律可以写一行解，也可以当第二种实现做交叉验证。

## 四、易错点

1. `1 << (n-1)` 忘写 LL → n ≥ 32 全错；
2. 后半段忘了把 k 平移（直接传 k）→ 越界或错答案；
3. k 用 int 读入 → 大 k 直接读炸；
4. 试图打表/模拟 → n=60 无法完成，读清数据范围再动手。

## 五、小结

"结构三段式 + 中点定位 + 半区递归"——在指数大的过程里 O(层数) 定位某一步，是递归结构分析的漂亮应用。同款思维还能回答："第 k 步是从哪根柱子移到哪根柱子？"（进阶挑战，欢迎自己推。）
