# 装备负重选择（游戏背景） 讲解稿

## 考点
【例1】采药的直接变式：换游戏皮肤，识别模型。

## 引入（1 分钟）
直接布置这题，先不点破"这是背包问题"，让学生自己判断——负重上限、装备重量、战斗力加成，这些词能不能对应到"背包容量、代价、价值"？

## 核心推导（简要，重点在对照）
- 负重上限 `W` → 背包容量；
- 装备重量 `w[i]` → 代价；
- 战斗力加成 `p[i]` → 价值；
- "每件装备最多带一件" → 01 背包的核心限制。

对照清楚后，代码和【例1】完全一样：

```cpp
for (int j = W; j >= w; j--) {
    dp[j] = std::max(dp[j], dp[j - w] + p);
}
```

## 易错点
- 这题本身没有新的算法难点，最容易出的问题反而是"想复杂了"——看到游戏场景描述，误以为需要考虑装备之间的联动效果（比如套装加成），其实题目没有这类设定，就是纯粹的 01 背包。
- 提醒学生：**读题时先抓"数值约束关系"（负重上限、每件重量、每件价值、能不能重复选），而不是被故事情节带偏**。

## 课堂串讲提示
可以在这题之后追问一句："如果游戏允许重复携带同一件装备的多个副本呢？"——引导学生意识到这样一改就变成了完全背包（例3的模型），检验他们是否真的掌握了"根据规则选模型"这件事，而不是死记这题的代码。
