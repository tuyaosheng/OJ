# 限量采药 讲解稿

## 考点
多重背包：介于 01 背包和完全背包之间的模型，和上一章"摆花"的枚举思路呼应。

## 引入（1 分钟）
采药系列走到第三种规则："每种草药最多采 `c[i]` 次"——不是只能采一次（01 背包），也不是随便采（完全背包），而是有一个具体的次数上限。问学生："能不能把'01 背包'和'完全背包'的写法结合一下？"

## 核心推导（重点，讲透）
最直接的想法：既然第 `i` 种草药能采 `0` 到 `c[i]` 次，就把"采几次"当成一个显式的选择枚举出来——这和上一章"摆花"的思路是同一件事：那题枚举"这种花摆几株"求方案数，这题枚举"这种草药采几次"求最大价值：

```
for j = T downto t[i]:                        // 和 01 背包一样，从大到小
    for k = 1 to min(c[i], j / t[i]):          // 枚举采几次
        dp[j] = max(dp[j], dp[j - k*t[i]] + k*v[i])
```

**为什么外层 `j` 还是从大到小**：这一步是把"这种草药最多采 `c[i]` 次"当成一个整体来处理——枚举 `k` 的过程中，用到的 `dp[j - k*t[i]]` 必须是"处理这种草药之前"的值。如果 `j` 从小到大遍历，`dp[j - k*t[i]]` 可能已经被这种草药自己更新过，会导致次数超过 `c[i]` 的限制被打破。

## 代码逐行讲解
```cpp
for (int j = T; j >= t; j--) {
    int maxK = std::min(c, j / t);
    for (int k = 1; k <= maxK; k++) {
        dp[j] = std::max(dp[j], dp[j - k * t] + k * v);
    }
}
```
- `maxK` 取 `min(c, j/t)`：既不能超过这种草药的数量上限 `c`，也不能让 `k` 次的总时间超过当前的 `j`。
- 复杂度是 `O(n × T × max(c[i]))`，三重循环，本题数据范围下足够快。

## 易错点
- `k` 的枚举范围写错：漏掉 `min` 中的任意一项都可能导致越界访问或者结果错误。
- 忘记这题本质是"01 背包 + 摆花的枚举思路"的结合，凭空想复杂——提醒学生先想"这种草药能选几次"这个简单问题，再套用已经会的框架。
- 数据范围较大（`c[i]` 特别大）时，朴素三重循环会超时，需要用"二进制拆分"优化成 01 背包（把 `c[i]` 拆成 `1, 2, 4, ...` 这样的若干份，转化成 01 背包问题）——这是进阶技巧，本题不要求，但可以作为课后了解的方向。

## 课堂串讲提示
到这里，01 背包、完全背包、多重背包三种模型的转移写法都出现过了，建议做一张对照表，把三段核心代码贴在一起，让学生自己总结"什么时候用哪种写法"。
