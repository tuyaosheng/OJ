- 和【例1】对比着记：01 背包"每件物品最多选一次"，一维数组优化时 `j` 要**从大到小**遍历，保证每件物品的贡献只被用一次；完全背包"每种物品能选无限次"，一维数组优化时 `j` 要**从小到大**遍历：
  ```
  for i = 1 to n:
      for j = t[i] to T:      // 注意：j 从小到大遍历，和例1相反！
          dp[j] = max(dp[j], dp[j - t[i]] + v[i])
  ```
- **为什么方向反过来反而是对的**：`j` 从小到大遍历时，`dp[j - t[i]]` 可能**已经被这一种草药更新过**——这正是我们想要的效果：意味着"这次决策"可以建立在"已经采过若干次同一种草药"的基础上，等价于允许重复选取。
- **状态和边界**：和【例1】完全一样，`dp[j]` 表示"总时间不超过 `j` 分钟能获得的最大价值"，`dp[0] = 0`。
- 这题时间范围 `T` 比【例1】大得多（最大 `10^5`），乘以草药种数 `n`（最大 `1000`），一维数组的写法是必须的——如果还写成二维数组，内存会直接爆掉（`1000 × 100000` 个整数远超内存限制）。
