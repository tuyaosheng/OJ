# 装箱问题 讲解稿

## 考点
识别背包模型：换一种问法，本质仍是 01 背包。

## 引入（1 分钟）
直接把题面读给学生听，问："这是背包问题吗？"——不少学生第一反应可能没看出来，因为题目问的是"剩余空间最小"，不是"价值最大"。这正是这题要练的能力：**遇到新题，先想想能不能转化成已经学过的模型**。

## 核心推导（重点，讲透）
关键的转化：把"箱子容积 `V`"看成背包容量，把"每件物品的体积 `v[i]`"**同时**当成 01 背包里的"代价"和"价值"——选一件物品占用 `v[i]` 的容量，同时也让"已装体积"多了 `v[i]`。这样，"让已装体积尽量大（从而剩余空间尽量小）"就变成了标准的 01 背包问题："容量不超过 `V` 时，能装下的最大体积和是多少"。

想清楚这一步转化后，代码和【例1】几乎一模一样，答案是 `V - dp[V]`（容积减去能装下的最大体积和）。

## 代码逐行讲解
```cpp
for (int j = V; j >= v; j--) {
    dp[j] = std::max(dp[j], dp[j - v] + v);
}
```
- 和【例1】的转移方程逐字对比：`t[i]` 和 `v[i]` 变成了同一个 `v`——因为这题的"代价"和"价值"就是同一个数字。

## 易错点
- **别忘了最后要用 `V` 减一下**：直接输出 `dp[V]` 会得到"能装下的最大体积和"，而不是题目要的"剩余空间"，这是本题最容易漏掉的一步。
- 转移方向依然是 `j` 从大到小（01 背包，每件物品只能选一次），不要和后面的完全背包搞混。

## 课堂串讲提示
可以在黑板上把这题和【例1】的转移方程并排写出来，让学生自己发现"除了变量名，这两行代码一模一样"——这个"啊哈"时刻，比直接讲"这是同一个模型"更有说服力。
