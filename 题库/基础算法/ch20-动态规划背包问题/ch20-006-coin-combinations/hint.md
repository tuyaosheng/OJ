- 和【例3】对照：转移方向沿用完全背包的写法（`j` 从小到大，允许同一种硬币反复使用），只是把 `max` 换成"加起来"：
  ```
  dp[0] = 1
  for i = 1 to n:
      for j = w[i] to S:      // 完全背包方向：j 从小到大
          dp[j] = (dp[j] + dp[j - w[i]]) % MOD
  ```
- **循环顺序决定了"算组合数"还是"算排列数"，这是本题最容易踩的坑**：
  - **外层枚举硬币种类、内层枚举金额**（上面的写法）：处理完第 `i` 种硬币后才会处理第 `i+1` 种，"先用哪种硬币、后用哪种硬币"不会被区分成不同方案——这样统计出的是**组合数**（不分顺序），正是本题要求的答案。
  - 如果反过来，**外层枚举金额、内层枚举硬币种类**，"用 1 元凑 3 元时选了 2 元硬币"和"用 2 元凑 3 元时选了 1 元硬币"会被当成两条不同的路径分别计数，统计出的会是**排列数**（区分顺序），不是本题要的答案。
  - 拿不准的时候，可以用一个只有两种面值（比如 1 元和 2 元）、凑 3 元的小例子手动模拟一遍两种循环顺序，观察结果是 2（组合：1+1+1、1+2）还是 3（排列：1+1+1、1+2、2+1），加深理解。
- **边界**：`dp[0] = 1`（凑出 0 元，只有"什么都不用"这一种方案）。
