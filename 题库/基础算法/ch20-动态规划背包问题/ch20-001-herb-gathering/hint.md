- **状态**（二维版本）：`dp[i][j]` = 只考虑前 `i` 株草药、总时间不超过 `j` 分钟时，能获得的最大价值。
- **转移**：第 `i` 株草药只有"采"或"不采"两种选择——
  - 不采：`dp[i][j] = dp[i-1][j]`；
  - 采（前提是 `j >= t[i]`，时间够）：`dp[i][j] = dp[i-1][j-t[i]] + v[i]`；
  - 两者取较大值。
- **边界**：`dp[0][j] = 0`（没有草药可采，价值是 0）。
- **答案**：`dp[n][T]`。
- **滚动数组优化（重要）**：观察转移方程会发现，`dp[i][...]` 只依赖 `dp[i-1][...]`，不需要保留更早的层，可以把二维数组压缩成一维 `dp[j]`，省下大量内存。压缩后循环写法：
  ```
  for i = 1 to n:
      for j = T downto t[i]:      // 注意：j 从大到小遍历
          dp[j] = max(dp[j], dp[j - t[i]] + v[i])
  ```
  **`j` 必须从大到小遍历**：如果从小到大遍历，`dp[j - t[i]]` 可能已经被"这一株草药"更新过了，会导致同一株草药被计算了不止一次（相当于变成了可以重复采摘），这就不是 01 背包了。这是本题最容易出错、也最需要理解透彻的一个细节。
