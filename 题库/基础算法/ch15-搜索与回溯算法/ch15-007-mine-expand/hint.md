先给每个安全格算出"周围 8 格的雷数"（第 5 章扫雷·数雷干过的活）。然后从点击格 DFS：

```cpp
void dfs(int x, int y) {
    if (越界 || 是雷 || vis[x][y]) return;
    vis[x][y] = true;  cnt++;      // 翻开
    if (num[x][y] > 0) return;     // 数字格：翻开但不扩展
    for (8 个方向) dfs(nx, ny);    // 0 格：向外蔓延
}
```

**vis 要不要撤销？**——vis 的含义是"这个格子已经被翻开"，翻开是永久事实，**绝不撤销**（和例3 细胞个数同一阵营；对照例2 迷宫计数的"必须撤销"想清楚为什么）。

特判：点击的格子本身数字 > 0，只翻开它自己，答案 1。
