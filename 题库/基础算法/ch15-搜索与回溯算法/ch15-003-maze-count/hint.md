**DFS 走迷宫的框架**

```cpp
int n, m, sx, sy, tx, ty;
int g[10][10];          // 迷宫
bool vis[10][10];       // ★ vis[i][j] = 格子(i,j)是否在【当前路径】上
int ans = 0;

// 四个方向的偏移量（上、下、左、右）
int dx[4] = {-1, 1, 0, 0};
int dy[4] = {0, 0, -1, 1};

void dfs(int x, int y)
{
    if (x == tx && y == ty)     // 到达终点！
    {
        ans++;                  // 找到一条路径
        return;                 // 注意：到了终点就不要再往下走了
    }

    for (int d = 0; d < 4; d++)         // 尝试四个方向
    {
        int nx = x + dx[d];
        int ny = y + dy[d];

        // 判断这一步能不能走：
        if (nx < 1 || nx > n || ny < 1 || ny > m) continue;  // 走出边界
        if (g[nx][ny] == 1) continue;                        // 是障碍
        if (vis[nx][ny]) continue;                           // 已在当前路径上（不能重复经过）

        vis[nx][ny] = true;     // ① 做选择：标记走过
        dfs(nx, ny);            // ② 递归：从新位置继续走
        vis[nx][ny] = false;    // ③ ★撤销★ 退回来，擦掉标记
    }
}
```

主函数里：`vis[sx][sy] = true; dfs(sx, sy);`

---

### 全题的灵魂：`vis[nx][ny] = false`（撤销）

**这一行如果漏掉，答案会严重偏小（往往只能找到 1 条路径，甚至 0 条）。**

**为什么？**

`vis` 数组的含义是"**这个格子是否在【我当前正在走的这条路径】上**"。

- 当我从格子 A 走到格子 B 时，标记 `vis[B] = true` —— 意思是"B 已经在我脚下这条路上了，不能再踩"。
- 当我把**经过 B 的所有可能**都探索完了，**要退回 A** 去尝试别的方向时——**B 就不在我的路径上了！**

  此时**必须**把 `vis[B]` 改回 `false`，否则接下来走另一条路时，程序会误以为"B 已经被占用"，从而**错失所有经过 B 的其他路径**。

> ### 打个比方
>
> 你在迷宫里探路，手里拿着粉笔。
>
> - **往前走**：在脚下的格子画个叉（"这条路上我已经踩过这里了"）。
> - **走到死胡同、往回退**：**必须把刚才画的叉擦掉**——因为你已经离开这个格子了，它不再属于你当前的路径。
>
> **如果不擦**：你走另一条岔路时，会看到满地的旧粉笔印，误以为"到处都走过了"，于是无路可走。
>
> **"进来时画叉，出去时擦掉"** —— 这就是回溯。

**其他细节**：

**方向数组**（`dx[]` / `dy[]`）是网格搜索的标准写法，比写四个 `if` 优雅得多：

```
上：(x-1, y)   dx=-1, dy=0
下：(x+1, y)   dx=+1, dy=0
左：(x, y-1)   dx=0,  dy=-1
右：(x, y+1)   dx=0,  dy=+1
```

**别忘了标记起点**：`vis[sx][sy] = true`，否则路径可能会绕回起点。

**特判**：起点 == 终点时，答案是 **1**（原地不动就是一条路径）。上面的代码天然处理了这种情况（一进 dfs 就到达终点）。

**复杂度**：最坏情况是指数级的（6×6 的空迷宫路径极多），但 n, m ≤ 6，实测很快。
