# 讲解稿：单词方阵（ch15-006）

## 一、题目解读

n×n 的字母方阵，找出所有沿 **8 个方向直线排列**的单词 `yizhong`。构成单词的字母**保留**，其余位置用 `*` 代替，输出整个方阵。

**这是本章的综合演练**，考察三件事：

1. **8 方向搜索**（比之前多了 4 个斜方向）
2. **沿固定方向直线前进**（**不能拐弯**！这是个重要的新概念）
3. **标记与输出的时机**

## 二、思路分析

### 关键理解：这不是"自由乱走"的搜索！

**这是本题最容易搞错的地方，请务必想清楚。**

回忆迷宫题：每走一步，我们都可以**任选**四个方向之一——路径可以**任意拐弯**：

```
起点 → 右 → 右 → 下 → 左 → 下 …   （随便拐）
```

**但本题不行！** 单词 `yizhong` 必须**直线**排列。也就是说：

> ### **一旦选定了一个方向，就必须【一直沿着这个方向】走到底，中途绝不能变向。**

如果你套用迷宫的 DFS 框架（每层都重新枚举 8 个方向），就会找出**弯弯曲曲**的 "yizhong"——**大错特错**。

### 正确做法：方向固定，只有步数在变

```cpp
// 从 (x,y) 出发，沿【固定方向 d】，检查能否拼出完整的 word
bool check(int x, int y, int d)
{
    for (int k = 0; k < 7; k++)         // k = 第几个字母
    {
        int nx = x + dx[d] * k;         // ★ 方向 d 固定，只有步数 k 在变！
        int ny = y + dy[d] * k;

        if (nx < 1 || nx > n || ny < 1 || ny > n) return false;   // 走出方阵
        if (g[nx][ny] != word[k]) return false;                   // 字母对不上
    }
    return true;        // 7 个字母全部匹配 ✓
}
```

**盯住这一行**：

```cpp
int nx = x + dx[d] * k;
```

- `d` 是**参数**，在整个 `check` 里**固定不变** → 保证走的是**直线**
- `k` 从 0 到 6 → 沿这条直线**走 7 步**

**这就是"直线搜索"的标准写法。** 和迷宫的"每层重新选方向"截然不同。

> **其实本题严格来说不算"回溯"**——它没有"试错 + 撤销"的过程，只是**枚举起点 × 枚举方向 × 直线验证**。
>
> **这提醒我们**：搜索题不一定都要写递归 DFS。**想清楚问题的结构，用最简单直接的方式实现即可。**

### 8 个方向怎么写？

把 (−1, 0, +1) × (−1, 0, +1) 的 9 种组合，**去掉 (0,0)**（原地不动），剩下 8 个：

```cpp
int dx[8] = {-1,-1,-1, 0, 0, 1, 1, 1};
int dy[8] = {-1, 0, 1,-1, 1,-1, 0, 1};
```

| d | (dx, dy) | 方向 |
|---|----------|------|
| 0 | (−1,−1) | 左上 ↖ |
| 1 | (−1, 0) | 上 ↑ |
| 2 | (−1,+1) | 右上 ↗ |
| 3 | ( 0,−1) | 左 ← |
| 4 | ( 0,+1) | 右 → |
| 5 | (+1,−1) | 左下 ↙ |
| 6 | (+1, 0) | 下 ↓ |
| 7 | (+1,+1) | 右下 ↘ |

## 三、代码讲解

### 主流程：枚举起点 × 枚举方向

```cpp
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= n; j++)            // 枚举每个起点
        for (int d = 0; d < 8; d++)         // 枚举 8 个方向
            if (check(i, j, d))             // 能拼出 yizhong 吗？
            {
                // 找到了！把这 7 个格子标记为"要保留"
                for (int k = 0; k < 7; k++)
                    keep[i + dx[d]*k][j + dy[d]*k] = true;
            }
```

### 【重要】必须先全部找完，再统一输出！

**这是本题的经典陷阱。**

**为什么？** 因为**一个字母可能同时属于多个 yizhong**！

想象两个单词**交叉**（比如一个横着、一个竖着，共用中间的某个字母），或者从同一个 `y` 出发向多个方向都能拼出单词。

**如果你边找边改方阵**（比如找到一个就把其他位置设成 `*`），就会**破坏掉还没检查的字母**——后面的单词就找不到了。

**正确做法**：

1. 用一个 `keep[][]` 布尔数组，记录"**哪些格子要保留**"；
2. **全部搜索完毕后**，再统一输出：`keep[i][j]` 为 true 就输出原字母，否则输出 `*`。

```cpp
for (int i = 1; i <= n; i++)
{
    for (int j = 1; j <= n; j++)
        cout << (keep[i][j] ? g[i][j] : '*');
    cout << "\n";
}
```

> **这是一个通用的经验**：**当"标记"和"输出"会互相干扰时，就分成两遍——第一遍只标记，第二遍只输出。**

### 为什么本题不需要"撤销"？

`keep[i][j]` 的语义是：

> **"这个格子属于某个 yizhong，要保留"** —— 这是一个**永久的结论**！

一旦确认某个格子属于某个单词，它就**永远**要被保留，不会因为后续的搜索而改变。

**所以：绝不撤销**（和「细胞个数」是同一类）✓

**又一次验证了本章的核心法则**：

> **看 `vis` / `keep` 的语义——是"当前路径上"（要撤销），还是"永久结论"（不撤销）？**

### 复杂度

O(n² × 8 × 7) —— n=100 时约 **56 万**次，**3ms** 跑完。非常快。

## 四、易错点

1. **套用迷宫的 DFS，每层重新选方向** —— 会找出**弯曲的** "yizhong"。**头号错误。** 必须**方向固定**。
2. **边找边输出 / 边找边改方阵** —— 破坏了还没检查的字母，遗漏交叉的单词。**必须先全找完，再统一输出。**
3. **8 个方向写漏或写错** —— 特别是斜方向。建议对着表格写。
4. **忘记边界检查** —— 沿方向走 7 步可能走出方阵，**每一步都要检查**（不能只检查起点和终点）。
5. **误以为要"撤销" `keep`** —— 不需要，它是永久结论。

## 五、小结

### 本题的三个要点

1. **直线搜索**：`nx = x + dx[d] * k` —— 方向固定，只有步数在变。
2. **两遍处理**：先全部标记，再统一输出（避免互相干扰）。
3. **8 方向**：`(±1, 0, ±1)` 的组合去掉 (0,0)。

## 🎓 第 15 章总结：搜索与回溯

### 六道题的知识图谱

| 题 | 类型 | 核心技巧 | `vis` 语义 | 撤销？|
|---|------|---------|-----------|-------|
| 1 组合的输出 | 组合枚举 | `start` 参数强制递增 | （用参数）| 不用 |
| 2 选数 | 组合 + 判断 | √n 素数判定 | （用参数）| 不用 |
| 3 迷宫路径计数 | **路径枚举** | 方向数组、回溯 | **在当前路径上** | **必须** |
| 4 细胞个数 | **连通块** | 洪水填充 | **曾被访问过** | **绝不** |
| 5 N 皇后 | **回溯 + 剪枝** | 逐行摆放、对角线性质 | **在当前方案上** | **必须** |
| 6 单词方阵 | 直线搜索 | 方向固定、两遍处理 | 永久结论 | 不用 |

### 本章最重要的三句话

> ### ① **搜索 = 回溯 + 剪枝**
> **回溯**保证**不重不漏**；**剪枝**保证**效率可行**。缺一不可。

> ### ② **要不要撤销？看 `vis` 的语义！**
> - `vis` = "**在当前路径/方案上**" → **必须撤销**（迷宫、全排列、N 皇后）
> - `vis` = "**曾经被访问过**" → **绝不撤销**（连通块、洪水填充）
>
> **不要背模板，要理解你的标记到底在标记什么。**

> ### ③ **搜索是暴力枚举，复杂度往往是指数级的。**
> 所以搜索题的**数据范围通常很小**（本章：n ≤ 6、n ≤ 12、n ≤ 20）。
> **反过来说：看到很小的数据范围，就该想到"可能要爆搜"。** 这是重要的解题直觉。

### 回溯的通用框架（请背下来）

```cpp
void dfs(当前状态)
{
    if (到达终态) { 记录答案; return; }

    for (每一个可能的选择) {
        if (这个选择不合法) continue;      // ★ 剪枝

        做出选择（打标记）;                 // ①
        dfs(新状态);                        // ②
        撤销选择（擦标记）;                 // ③ ★ 视语义决定要不要
    }
}
```

**这个框架，配合"剪枝"和"语义判断"，就是搜索算法的全部精髓。**
