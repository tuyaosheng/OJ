**关键理解：这不是"自由乱走"的搜索！**

前面的迷宫题里，我们每一步都可以**任选**四个方向之一——路径可以**拐弯**。

**但本题不行！** 单词必须是**直线**排列的。也就是说：

> **一旦选定了一个方向，就必须【一直沿着这个方向】走到底，中途不能变向。**

这是本题最容易搞错的地方。

**正确的做法**：

```cpp
const string word = "yizhong";      // 7 个字母

// 8 个方向（上、下、左、右、4 个斜向）
int dx[8] = {-1,-1,-1, 0, 0, 1, 1, 1};
int dy[8] = {-1, 0, 1,-1, 1,-1, 0, 1};

// 从 (x,y) 出发，沿着第 d 个方向，检查能否拼出完整的 word
bool check(int x, int y, int d)
{
    for (int k = 0; k < 7; k++)         // 逐个字母检查
    {
        int nx = x + dx[d] * k;         // ★ 沿【固定方向】走第 k 步
        int ny = y + dy[d] * k;

        if (nx < 1 || nx > n || ny < 1 || ny > n) return false;   // 出界
        if (g[nx][ny] != word[k]) return false;                   // 字母对不上
    }
    return true;        // 7 个字母全部匹配！
}
```

**注意 `x + dx[d] * k` 这个写法**：方向 `d` 是**固定**的，只有步数 `k` 在变。这就保证了"**沿直线走**"。

**主流程**：

```cpp
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= n; j++)            // 枚举每个起点
        for (int d = 0; d < 8; d++)         // 枚举 8 个方向
            if (check(i, j, d))             // 如果能拼出 yizhong
            {
                // 把这 7 个格子标记为"要保留"
                for (int k = 0; k < 7; k++)
                    keep[i + dx[d]*k][j + dy[d]*k] = true;
            }
```

**最后输出**：`keep[i][j]` 为 true 就输出原字母，否则输出 `*`。

---

**重要细节**：

**① 必须先全部找完，再统一输出。**

因为**一个字母可能同时属于多个 yizhong**（不同方向的单词可能交叉）。所以要用一个 `keep[][]` 数组记录"哪些格子要保留"，**全部搜索完毕后**再一次性输出。

（如果边找边输出，或者边找边改方阵，会把还没检查的字母破坏掉——**这是本题的经典陷阱**。）

**② 为什么本题不需要"撤销"？**

因为 `keep` 数组的语义是"**这个格子属于某个 yizhong，要保留**"——这是一个**永久的结论**，不是"当前路径"的临时状态。

**和「细胞个数」一样：标记一旦打上，就永久有效。**

**③ 8 个方向的写法**：`dx`/`dy` 数组各 8 个元素，把 (−1,0,1) × (−1,0,1) 的 9 种组合去掉 (0,0) 即可。

**复杂度**：O(n² × 8 × 7)。n=100 时约 56 万次，非常快。
