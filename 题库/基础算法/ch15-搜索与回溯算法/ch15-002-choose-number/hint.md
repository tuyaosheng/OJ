**第一步：枚举所有的组合**

和上一题一模一样——用 `start` 参数强制递增，枚举出所有 C(n, k) 个组合。

注意：本题**只要统计个数**，不需要输出组合本身。所以我们可以在递归时**顺便累加和**，走到底时判断一下即可：

```cpp
// pos   = 已经选了几个数
// start = 这一层最小从哪个下标开始选
// sum   = 当前已选数字的和
void dfs(int pos, int start, int sum)
{
    if (pos == k)                   // 已经选够 k 个
    {
        if (isPrime(sum)) ans++;    // 判断和是否为素数
        return;
    }

    for (int i = start; i < n; i++)
        dfs(pos + 1, i + 1, sum + x[i]);    // 传 i+1，保证每个数只选一次
}
```

**把 `sum` 作为参数传下去**，比走到底再回头累加要优雅得多——这也是"用参数携带状态"的又一个例子（**不需要撤销**！）。

**第二步：判断素数**

**素数**（质数）：只能被 1 和自身整除的、大于 1 的自然数。

```cpp
bool isPrime(int x)
{
    if (x < 2) return false;            // 0 和 1 都不是素数！

    for (int i = 2; (long long)i * i <= x; i++)     // 只需试到 √x
        if (x % i == 0) return false;   // 找到一个因子，不是素数

    return true;
}
```

**为什么只需试到 √x？**

如果 x 有一个大于 √x 的因子 a，那么必然还有一个对应的因子 `b = x / a`，而 **b 一定小于 √x**。

所以——**只要小于等于 √x 的范围内没有因子，那大于 √x 的范围内也不可能有。** 试到 √x 就够了。

这把复杂度从 O(x) 降到了 **O(√x)**。x 最大约 10^8（20 个 5×10^6 相加），√x = 10^4，非常快。

> **注意** `(long long)i * i <= x` 的写法——防止 `i * i` 溢出。（也可以写成 `i <= x / i`。）

**易错点**：
- `x < 2` 时返回 false —— **0 和 1 都不是素数！** 这是最常见的错误。
- 和可能很大（20 × 5×10^6 = 10^8），要用 **int**（够用）或 long long。

**复杂度**：C(20,10) = 184756 个组合 × O(√10^8) = 184756 × 10^4 —— 看起来有点大？

**别慌**：只有当 k=10 时组合数才最多，而此时每个和的 √ 判断也就 1 万次。实测完全够快（几十毫秒）。
