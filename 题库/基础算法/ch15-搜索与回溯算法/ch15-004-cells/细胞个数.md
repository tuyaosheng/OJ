# 讲解稿：细胞个数（ch15-004）

## 一、题目解读

n×m 的数字矩阵，`0` 是空白，**非 0 表示细胞组织**。上下左右相邻的非 0 格子属于**同一个细胞**。求细胞总数。

这类问题有个正式名字：**连通块计数**（Connected Components），也叫**洪水填充**（Flood Fill）。

**⚠️ 这道题会颠覆你刚刚建立的认知。**

上一题我们反复强调"**必须撤销标记**"。而这一题——**恰恰相反，绝对不能撤销！**

**读完本讲，你会真正理解 DFS。**

## 二、思路分析

### 算法：扫描 + 染色

```cpp
int ans = 0;

for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
    {
        if (g[i][j] != 0 && !vis[i][j])     // 非 0，且还没访问过
        {
            ans++;          // 发现一个【新细胞】！
            dfs(i, j);      // 把它的所有格子一次性全部标记掉
        }
    }
```

**核心思想**：

> **主循环扫描每个格子。一旦遇到"非 0 且还没被访问过"的格子，说明我们碰到了一个【全新的细胞】。**
>
> **计数 +1，然后立刻用 DFS 把这个细胞的【所有格子】全部"染色"（标记为已访问）。**
>
> **这样，同一个细胞的其他格子，之后就不会再被主循环当成"新细胞"了。**

**DFS 在这里的作用不是"找路径"，而是"把一整片连通区域全部标记掉"** —— 就像往一滴墨水，它会自动蔓延到整片连通的纸面。这就是"**洪水填充**"这个名字的由来。

```cpp
void dfs(int x, int y)
{
    vis[x][y] = true;               // 标记：这个格子归入当前细胞

    for (int d = 0; d < 4; d++)     // 向四个方向蔓延
    {
        int nx = x + dx[d], ny = y + dy[d];

        if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
        if (g[nx][ny] == 0) continue;       // 空白，不属于细胞
        if (vis[nx][ny]) continue;          // 已标记过

        dfs(nx, ny);                        // 继续蔓延
    }

    // ★★★ 这里【没有】vis[x][y] = false ★★★
}
```

## 三、【核心】为什么这题绝对不能撤销？

这是本题**唯一的、也是最重要的**知识点。

### 对比两题的 `vis` 语义

| | 迷宫路径计数（上一题） | 细胞个数（本题）|
|---|---------------------|-----------------|
| **`vis[i][j]` 的含义** | 这个格子在**我当前正在走的这条路径**上 | 这个格子**曾经被访问过**（已归入某个数过的细胞）|
| **离开这个格子后** | 它**不再**在当前路径上 → 状态**失效** | 它**永远**属于那个细胞 → 结论**永久有效** |
| **目的** | 枚举**所有**路径（同一格子要能被不同路径反复使用）| 每个格子**只访问一次**（避免重复计数）|
| **要撤销吗** | **必须撤销** ✓ | **绝不撤销** ✗ |

### 如果错误地撤销了，会发生什么？

**后果一：答案错得离谱**

DFS 结束后 `vis` 全变回 `false`，于是主循环扫到同一个细胞的**每一个格子**时，都会认为"这是个没访问过的新细胞"，`ans++`。

**结果：答案 = 非 0 格子的总数**（而不是细胞数）。样例会输出 30 多而不是 4。

**后果二：更糟——无限递归，直接爆栈**

想象两个相邻的细胞格子 A 和 B：

1. `dfs(A)` → 标记 A → 蔓延到 B
2. `dfs(B)` → 标记 B → 看看四周…… A 是非 0 的，且 `vis[A]`……
   - **正常情况**：`vis[A]` 是 `true`，跳过 ✓
   - **如果撤销了**：`dfs(A)` 在返回前会把 `vis[A]` 擦掉 —— 但它还没返回啊！它正在等 `dfs(B)` 返回……

   实际上，若在 `dfs` 末尾撤销，`dfs(B)` 看到的 `vis[A]` 仍是 true（因为 A 还没返回）。但**兄弟分支之间**会互相"解锁"，导致同一片区域被反复进入，**递归层数爆炸** → **栈溢出（RE）**。

**总之：撤销 = 灾难。**

---

> ## 一句话总结（本章最重要的一句话）
>
> ### **要不要撤销，取决于 `vis` 的【语义】：**
>
> | `vis` 的含义 | 典型问题 | 撤销？ |
> |-------------|---------|--------|
> | **"在当前路径/方案上"** | 迷宫路径、全排列、八皇后 | **必须撤销** |
> | **"曾经被访问过"** | 连通块、洪水填充、图的遍历 | **绝不撤销** |
>
> ### **不要死记"回溯就要撤销"——要想清楚：你的标记，到底在标记什么？**

**这个区别，是 DFS 的分水岭。理解了它，你就真正入门了搜索。**

## 四、代码细节

### 读入：每行是一个数字串

本题输入形如 `0234500067`（中间**没有空格**），所以要用 `string` 读整行：

```cpp
string s;
cin >> s;
for (int j = 0; j < m; j++)
    g[i][j + 1] = s[j] - '0';       // 字符转数字
```

（如果用 `cin >> g[i][j]` 读 int，会把整行当成**一个数字**读进来，大错特错。）

### 复杂度

**每个格子最多被访问一次**（因为访问过就永久标记了），所以是 **O(n × m)** = 100×100 = **10000**。飞快。

> **对比迷宫题的指数级复杂度**：为什么这题这么快？
>
> **正因为"不撤销"！** 每个格子只进一次，绝不重复。而迷宫题要枚举所有路径，同一个格子会被不同路径反复经过，所以是指数级的。
>
> **"撤销"带来了完整的枚举能力，也带来了指数级的代价。**

### 递归深度

n, m ≤ 100，最坏情况（整个矩阵是一个大细胞）递归深度可达 **10000 层**。

C++ 默认栈空间通常是 1MB~8MB，10000 层一般够用。但如果题目规模更大（比如 1000×1000 = 100 万层），就会**爆栈**——那时应改用 **BFS**（用队列，不递归）。**这是下一章的内容。**

## 五、易错点

1. **错误地撤销 `vis`** —— **本题的核心考点**。会导致答案错误 + 可能爆栈。
2. **用 `cin >> int` 读数字串** —— 整行被当成一个数。要用 `string`。
3. **判断"是细胞"写成 `g[i][j] == 1`** —— 题目说的是**非 0**（1~9 都算），不是只有 1。
4. **先访问 `g[nx][ny]` 再判出界** —— 数组越界。
5. **主循环忘了 `!vis[i][j]` 的判断** —— 同一细胞被重复计数。

## 六、小结

### 洪水填充（Flood Fill）的框架

```
for 每个格子:
    if (是目标格子 && 没访问过):
        计数++
        dfs(这个格子)      // 把整片连通区域染色

void dfs(x, y):
    vis[x][y] = true       // 标记，且【永不撤销】
    for 四个方向:
        if (在界内 && 是目标格子 && 没访问过):
            dfs(新位置)
```

**这个框架能解决一大类问题**：

- **数连通块**（本题：数细胞、数岛屿、数油田）
- **求最大连通块的面积**（在 dfs 里累加格子数）
- **填涂颜色**（把某个封闭区域染色）
- **判断两点是否连通**

**万变不离其宗。**

### 本章至此的收获

| 题 | `vis` 的语义 | 撤销？| 复杂度 |
|---|-------------|-------|--------|
| 迷宫路径计数 | 在当前路径上 | **要** | 指数级 |
| **细胞个数** | **曾经访问过** | **不要** | **O(nm) 线性** |

**同一个 DFS 框架，一行代码的差别，导致了完全不同的语义、用途和复杂度。**

**这就是为什么我说：不要背模板，要理解语义。**
