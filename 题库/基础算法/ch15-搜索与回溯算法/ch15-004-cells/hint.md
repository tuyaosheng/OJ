**这类问题叫「连通块计数」，也叫「洪水填充 Flood Fill」。**

**算法框架**：

```cpp
int ans = 0;

for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
    {
        if (g[i][j] != 0 && !vis[i][j])     // 发现一个【还没被访问过】的细胞格子
        {
            ans++;                          // 说明发现了一个【新细胞】！
            dfs(i, j);                      // 把和它连通的所有格子，全部标记掉
        }
    }
```

**核心思想**：

> **每当遇到一个"还没被访问过"的非 0 格子，说明我们发现了一个全新的细胞。**
> **计数 +1，然后用 DFS 把这个细胞的【所有格子】一次性全部"染色"（标记为已访问）。**
> **这样，同一个细胞的其他格子，之后就不会再被当成"新细胞"了。**

DFS 的作用不是"找路径"，而是"**把一整片连通区域全部标记掉**"：

```cpp
void dfs(int x, int y)
{
    vis[x][y] = true;               // 标记：这个格子属于当前细胞

    for (int d = 0; d < 4; d++)     // 向四个方向蔓延
    {
        int nx = x + dx[d], ny = y + dy[d];

        if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
        if (g[nx][ny] == 0) continue;       // 空白，不属于细胞
        if (vis[nx][ny]) continue;          // 已经标记过了

        dfs(nx, ny);                        // 继续蔓延
    }
    // ★★★ 注意：这里【没有】撤销！vis[x][y] 保持 true ★★★
}
```

---

### 【核心】为什么这题绝对不能撤销？

对比两题的 `vis` 数组，它们的**含义完全不同**：

| | 迷宫路径计数（上一题） | 细胞个数（本题） |
|---|---------------------|-----------------|
| **`vis` 的含义** | 这个格子在**我当前走的这条路径上** | 这个格子**曾经被访问过**（属于某个已数过的细胞）|
| **离开格子后** | 它就**不在**当前路径上了 → **必须撤销** | 它**永远**属于那个细胞 → **绝不能撤销** |
| **目的** | 枚举**所有**路径（需要反复尝试） | 每个格子**只访问一次**（避免重复计数）|

**如果本题错误地撤销了会怎样？**

`vis` 全部变回 `false`，于是同一个细胞的每个格子都会被主循环重新当成"新细胞"，**答案会等于非 0 格子的总数**（而不是细胞数）——大错特错。

**更糟的是**：DFS 内部也会因为 `vis` 被擦掉而**来回横跳**（A→B→A→B…），陷入**无限递归**，直接爆栈。

---

> ### 一句话总结（本章最重要的一句）
>
> **要不要撤销，取决于 `vis` 的语义：**
>
> - **`vis` = "在当前路径上"** → 枚举路径 → **必须撤销**（迷宫、全排列、八皇后）
> - **`vis` = "曾被访问过"** → 遍历/染色 → **绝不撤销**（连通块、洪水填充）
>
> **不要死记"回溯就要撤销"——要理解你的标记到底在标记什么。**

**读入技巧**：本题每行是一个**数字串**（如 `0234500067`），中间没有空格。用 `string` 读入更方便：

```cpp
string s;
cin >> s;
for (int j = 0; j < m; j++)
    g[i][j + 1] = s[j] - '0';       // 字符转数字
```

**复杂度**：每个格子最多被访问一次，**O(n × m)** = 10000，非常快。

**注意**：n, m ≤ 100，最坏情况递归深度可达 10000 层。C++ 默认栈通常够用，但要心里有数。（如果爆栈，可以改用 BFS ——那是下一章的内容。）
