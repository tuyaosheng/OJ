**第一个关键优化：逐行摆放**

题目要求 n 个皇后不能同行。既然如此——

> **我们干脆规定：第 1 个皇后放第 1 行，第 2 个放第 2 行，……，第 i 个放第 i 行。**

这样，"**不同行**"这个条件就被**自动满足**了！我们只需要为每一行**决定放在哪一列**。

搜索空间从"在 n² 个格子里选 n 个"骤降为"为每行选一列"——**巨大的简化**。

**第二个关键：怎么快速判断"能不能放"？**

在第 `row` 行第 `col` 列放皇后，需要检查它和**前面已放好的所有皇后**是否冲突：

- **同列**？→ 用 `colUsed[col]` 标记该列是否已被占用。
- **同对角线**？→ 这里有个漂亮的技巧：

> **主对角线（↘方向）**：同一条主对角线上，**`row - col` 是常数**！
> **副对角线（↙方向）**：同一条副对角线上，**`row + col` 是常数**！

（自己找几个格子验证一下，比如 (1,1)、(2,2)、(3,3) 的 `row-col` 都是 0。）

所以只需两个数组：

```cpp
bool colUsed[15];       // 第 col 列是否被占
bool diag1[30];         // 主对角线，下标用 row - col + n（加 n 防止负数！）
bool diag2[30];         // 副对角线，下标用 row + col
```

判断 O(1)，比逐个检查前面的皇后快得多。

**主体代码**：

```cpp
void dfs(int row)
{
    if (row > n)            // n 行都放好了，找到一个解！
    {
        ans++;
        return;
    }

    for (int col = 1; col <= n; col++)      // 在这一行，尝试每一列
    {
        // ★ 剪枝：这个位置会被攻击，直接跳过，不往下递归
        if (colUsed[col] || diag1[row - col + n] || diag2[row + col])
            continue;

        colUsed[col] = true;                // ① 做选择：放下皇后
        diag1[row - col + n] = true;
        diag2[row + col] = true;

        dfs(row + 1);                       // ② 递归：去放下一行

        colUsed[col] = false;               // ③ ★撤销★ 拿走皇后
        diag1[row - col + n] = false;
        diag2[row + col] = false;
    }
}
```

---

**为什么必须撤销？**

`colUsed` / `diag1` / `diag2` 的含义是"**在我当前正在摆的这个方案里**，这一列/对角线是否已被占用"。

当我们探索完"第 row 行放 col 列"的所有后续可能，要**退回来**尝试"第 row 行放 col+1 列"时——刚才那个皇后**已经被拿走了**，它占的列和对角线自然要**释放**。

**这和迷宫路径计数是同一类**（`vis` = "在当前方案/路径上"），所以**必须撤销**。

---

**关于剪枝**

`if (...) continue;` 这一行就是**剪枝**——它让我们在发现"这个位置会被攻击"时**立刻放弃**，不再往下递归。

**如果不剪枝**（先把 n 个皇后都摆完，最后再检查是否合法），复杂度是 O(n^n)；
**剪枝后**，大量无效分支在早期就被砍掉，实际搜索量大大减少。

> **剪枝是搜索算法的生命线。** 一个好的剪枝，能让指数级的搜索变得可以接受。

**为什么 `diag1` 下标要 `+n`？** 因为 `row - col` 可能是**负数**（如 row=1, col=5 时是 −4），而数组下标不能为负。加上 n 后就都变成正数了。

**答案参考**：n=4 → 2，n=8 → 92，n=12 → 14200。
