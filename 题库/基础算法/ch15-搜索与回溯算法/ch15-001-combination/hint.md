**排列 vs 组合：一个参数的差别**

回忆第 14 章的**全排列**：我们用 `used[]` 数组标记哪些数被用过，每层从 1 到 n 都尝试一遍。这样 `1 2 3` 和 `3 2 1` 都会被生成——**因为排列讲究顺序**。

但**组合不讲顺序**！`1 2 3` 和 `3 2 1` 是同一个，只能输出一次。

**怎么办？** 用和「自然数拆分」完全相同的招数：

> ### **强制递增：后选的数必须【大于】先选的数。**

这样 `3 2 1` 根本不会被生成（因为 2 < 3 不满足递增），每个组合**有且仅有一个**合法表示（就是从小到大的那个）→ **天然不重不漏！**

**实现**：加一个 `start` 参数，表示"这一层最小从哪个数开始选"。

```cpp
int path[25];
int n, r;

// pos   = 当前要选第几个数（1 ~ r）
// start = 这一层最小能选的数
void dfs(int pos, int start)
{
    if (pos > r)                        // 已经选够 r 个了
    {
        for (int i = 1; i <= r; i++)
            cout << path[i] << (i == r ? "\n" : " ");
        return;
    }

    for (int v = start; v <= n; v++)    // 从 start 开始，保证递增
    {
        path[pos] = v;
        dfs(pos + 1, v + 1);            // ★ 传 v+1：下一个必须【严格大于】v
    }
}
```

调用 `dfs(1, 1)`。

---

**关键：传 `v + 1` 还是 `v`？**

- **本题传 `v + 1`** → 下一个数必须**严格大于** v → 每个数**只能选一次** ✓（组合的要求）
- 「自然数拆分」传 `v` → 下一个数可以**等于** v → 允许重复（`1 1 3`）

**一个字符之差，两种问题。** 请务必想清楚你要的是哪一种。

---

**剪枝优化（进阶）**

上面的代码有个小浪费：如果剩下的数**不够选**了，还在傻傻地往下递归。

比如 n=5, r=3，已经选了 `4`（pos=2），那么剩下只有 `5` 一个数可选，但还要选 2 个——**不可能了**，应该立刻停止。

```cpp
for (int v = start; v <= n - (r - pos); v++)    // 剪枝：保证剩余的数够用
```

（`r - pos` 是还需要选的个数减一……可以自己推导一下这个上界。）

**剪枝**是搜索算法的核心优化手段，下一题我们会正式讲它。本题 n ≤ 20，不剪枝也能过。
