**核心套路（三步走）**

1. **读入**：用 `string` 读进来，避免任何整数类型溢出。
2. **倒着存**：把字符串**反过来**存进 int 数组——让下标 0 表示个位、下标 1 表示十位……这样"进位"就是往下标大的方向走，写起来最顺手。字符转数字：`s[i] - '0'`。
3. **逐位相加 + 进位**：
   ```
   c[i] = a[i] + b[i] + carry;   // carry 是从低一位进上来的
   carry = c[i] / 10;            // 本位满十，进 1
   c[i] %= 10;                   // 本位只留个位数
   ```
   循环长度取两数位数的较大值；循环结束后如果 `carry` 还是 1，别忘了再补一位最高位。

4. **输出**：数组是倒着存的，输出时要**从高位到低位倒着打印**。

**易错点**：两数位数不一样长时，短的那个高位要当作 0 参与运算；最后的进位（如 `999 + 1 = 1000`，位数变长了）千万不能漏。
