# 讲解稿：高精度加法（ch11-001）

## 一、题目解读

题目很短：给两个非负整数 a、b，求 a + b。

"这不是第 1 章的 A+B Problem 吗？"——如果你这么想，那就掉进坑里了。请看数据范围：**a、b 的位数最多 500 位**。

我们回忆一下 C++ 的整数类型能装多大：

| 类型 | 最大值 | 大约几位 |
|------|--------|---------|
| `int` | 2147483647 | 10 位 |
| `long long` | 9223372036854775807 | 19 位 |

500 位？`long long` 连零头都装不下。所以这道题**根本不能用 `cin >> a`（a 是整数）来读**——数还没开始算，读入的一瞬间就已经溢出了。

这就是本章的起点：当数字大到任何内置类型都装不下时，我们自己动手，把它拆开来存、拆开来算。这套办法就叫**高精度算法**。

## 二、思路分析

### 1. 怎么存？

既然一个变量装不下 500 位，那就**一位数字用一个数组元素来存**。500 位数 → 一个长度 500 的 int 数组。

读入当然要用 `string`：
```cpp
string sa, sb;
cin >> sa >> sb;
```
字符 `'7'` 转成数字 7，用 `sa[i] - '0'` 即可（这是字符编码的小技巧：数字字符在 ASCII 里是连续的）。

### 2. 关键决策：**要倒着存！**

这是初学者最容易困惑的地方，我们讲透它。

假设 a = 123，如果**正着存**：`a[0]=1, a[1]=2, a[2]=3`，那么下标 0 是百位、下标 2 是个位。

现在做加法。小学竖式怎么算？**从个位开始，往左进位**。可个位在数组的**末尾**，进位要往**下标变小**的方向走。更麻烦的是，两个数长度不一样时（比如 `123 + 45`），个位根本对不齐——`a[2]` 对 `b[1]`，全乱套了。

再看**倒着存**：`a[0]=3, a[1]=2, a[2]=1`。此时——

- **下标 0 永远是个位**，两个数天然对齐，不管长度差多少；
- 进位往**下标增大**的方向走，就是 `i` → `i+1`，顺手；
- 更妙的是：**下标 i 恰好代表这一位是 10 的 i 次方**（`a[2]=1` 就是 1×10²=100）。

一句话：倒着存，是为了**让个位对齐、让进位顺着数组方向走**。这个约定后面每道高精度题都要用，请务必记牢。

### 3. 怎么算？

完全照搬小学竖式：

```
   1 2 3
 + 4 5 6
 ---------
```
从个位开始：3+6=9，写 9；十位：2+5=7，写 7；百位：1+4=5，写 5。答案 579。

如果某位加起来 ≥ 10 呢？比如 `9 + 7 = 16`，就**留下 6、向高位进 1**。用代码表达：

```cpp
int sum = a[i] + b[i] + carry;   // carry 是低一位进上来的
c[i]  = sum % 10;                // 本位只留个位数字
carry = sum / 10;                // 满十进一（sum 最大 9+9+1=19，所以进位只会是 0 或 1）
```

## 三、代码讲解

```cpp
int len = max(la, lb);      // 结果至少这么长
int carry = 0;

for (int i = 0; i < len; i++)
{
    int sum = a[i] + b[i] + carry;
    c[i] = sum % 10;
    carry = sum / 10;
}

if (carry > 0)              // 最高位还有进位
{
    c[len] = carry;
    len++;
}
```

有两个细节值得停下来品一品：

**细节一：短的数怎么办？** 比如 `123 + 45`，b 只有 2 位，那 `b[2]` 是多少？答案是 **0**——因为 `b` 是**全局数组**，C++ 保证全局数组自动初始化为 0。而 123 + 045 = 123 + 45，补 0 完全不影响结果！所以我们**什么都不用做**，短的数的高位天然就是 0，直接参与运算即可。这就是倒序存储又一个隐藏的好处。

**细节二：最后那个 `if (carry > 0)` 千万不能漏。** 想想 `999 + 1`：三位循环跑完，carry 还是 1，此时 c 数组是 `[0,0,0]`。如果直接输出就成了 `000`，大错特错！必须把这个进位补成第 4 位，得到 `1000`。

**记住：加法的结果，位数可能比两个加数都多一位。**

最后是输出。数组是倒着存的，所以要**从高位（下标大）往低位（下标 0）**打印：

```cpp
for (int i = len - 1; i >= 0; i--)
    cout << c[i];
```

## 四、易错点

1. **用 `int`/`long long` 读入** —— 500 位数直接溢出，必须用 `string`。这是最致命的错误。
2. **忘记最后的进位** —— `999 + 1` 输出成 `000`。
3. **输出方向搞反** —— 倒序存就要倒序输出，正着打印会得到答案的反转（`579` 打成 `975`）。
4. **数组开小了** —— 500 位相加可能变 501 位，数组要留余量（本题开 600）。
5. **字符转数字忘了减 `'0'`** —— 直接用 `sa[i]` 会得到 ASCII 码（字符 `'3'` 是 51，不是 3）。

## 五、小结

高精度加法的三板斧，请刻在脑子里：

1. **`string` 读入**（绝不用整数类型）；
2. **倒序存进 int 数组**（个位在下标 0，进位方向顺手，短数高位自动补 0）；
3. **逐位相加、逢十进一**，最后**别忘补最高位的进位**，然后**倒序输出**。

这套框架是整章的地基。接下来的减法（逢十借一）、乘法（错位相加），全都建立在"倒序存数组"这个约定之上。下一题我们就来看它的镜像——高精度减法，那里会多出两个新麻烦：**借位**和**负数**。
