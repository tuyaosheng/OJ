**递推式**：`f[i] = f[i-1] + f[i-2]`，边界 `f[0] = 1`、`f[1] = 1`。

（`f[0] = 1` 是关键边界：站着不动也算一种走法。若把它设成 0，整个数列就全错了。）

**规模**：f[5000] 约有 1046 位十进制数字，必须用高精度数组存。

**实现方式**：用一个二维数组 `f[5005][1100]`，`f[i]` 本身就是一个倒序存放的高精度数。递推时对每一位做加法：

```
for (int i = 2; i <= n; i++)
    carry = 0;
    for (int j = 0; j < len; j++) {
        f[i][j] = f[i-1][j] + f[i-2][j] + carry;
        carry = f[i][j] / 10;
        f[i][j] %= 10;
    }
    // carry 若还有，就把长度 len 增加
```

**内存估算**：5005 × 1100 个 int ≈ 550 万 × 4 字节 ≈ 22 MB，在 256 MB 限制内，安全。

**优化提示**：其实只需保留最近两项（滚动数组），内存可降到 O(位数)。但本题直接开二维数组也完全够用，不必强求。

**易错点**：
1. `f[0] = 1` 别写成 0；
2. 数组第二维要开够（≥ 1100），否则高位被截断；
3. 位数 `len` 要随着数变大而增长，别固定死。
