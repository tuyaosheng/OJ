**核心套路：整体乘，再统一进位**

不要一位一位地"乘完立刻只留个位"，最省事的写法是——让每一位先大胆地存一个可能很大的中间值，最后再统一处理进位：

```
for (int i = 0; i < la; i++)
    c[i] = a[i] * b + carry;   // 本位可能变成很大的数，没关系
    carry = c[i] / 10;         // 超出个位的部分全部进位
    c[i] %= 10;                // 本位只留一位
```

**关键点**：b 最大 10000，`a[i] * b` 最大是 `9 × 10000 = 90000`，加上进位也远没到 int 上限，所以中间值用 int 存放绰绰有余。

**循环结束后 carry 可能还很大**（不止一位！），要用 `while (carry) { c[len++] = carry % 10; carry /= 10; }` 把它一位一位全部展开，而不是简单地补一位。

**特判**：b = 0 时结果是 0；如果不去前导零，会输出一长串 `000…0`。所以最后同样要去前导零、至少保留一位。
