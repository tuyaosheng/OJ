**核心套路**

1. **先比大小**：写一个比较函数 `cmp(a, b)`——先比位数，位数多的大；位数相同就**从最高位往低位**逐位比较，遇到第一个不同的位即可判定。

2. **永远用大的减小的**：若 a < b，就交换两数算 b − a，并记住最后要打一个负号。这样减法函数内部永远是"大减小"，不必处理负数。

3. **逐位相减 + 借位**：同样把数字倒着存进数组（下标 0 = 个位）。
   ```
   t = a[i] - b[i] - borrow;    // borrow 是上一位借走的 1
   if (t < 0) { t += 10; borrow = 1; }   // 不够减，向高位借 1，本位加 10
   else       { borrow = 0; }
   c[i] = t;
   ```

4. **去前导零**：算完后从最高位往下扫，把多余的 0 砍掉。但要**至少保留一位**——否则 `5 − 5` 会输出空。

**易错点**：忘记去前导零（输出 `0001`）；结果为 0 时误输出 `-0`；交换后忘了加负号。
