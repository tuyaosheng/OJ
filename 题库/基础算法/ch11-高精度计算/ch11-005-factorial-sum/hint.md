**不要每个 k! 都从头乘一遍**，那样又慢又麻烦。利用阶乘的递推性质：

**k! = (k−1)! × k**

所以只要维护一个高精度数 `fac`（表示当前的 k!），每轮把它乘以 k，就得到了下一个阶乘；同时用另一个高精度数 `sum` 把它累加起来：

```
fac = 1
sum = 0
for k = 1 to n:
    fac = fac × k        // 高精度乘单精度（第 3 题）
    sum = sum + fac      // 高精度加高精度（第 1 题）
输出 sum
```

**规模估计**：`100!` 大约有 158 位，所以数组开 200 ~ 300 足够。总共只做 100 轮，每轮 O(位数)，非常快。

**实现建议**：把"高精度乘小数"和"高精度加高精度"各写成一个函数，主程序里循环调用——这就是把前面几题的成果**封装复用**。这也是竞赛中处理高精度的标准做法。

**易错点**：`fac` 初始值必须是 1（不是 0，否则一直乘出来都是 0）；`sum` 初始值是 0。数组记得开够。
