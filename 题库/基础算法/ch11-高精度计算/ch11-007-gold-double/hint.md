就是"高精度乘单精度"做 n 次（每次乘 2）：

```cpp
for (int i = 0; i < len; i++) a[i] *= 2;   // 每位乘 2
for (int i = 0; i < len; i++) {            // 统一处理进位
    a[i + 1] += a[i] / 10;
    a[i] %= 10;
}
if (a[len]) len++;                          // 最高位进位，长度加一
```

倒序存储（个位在 a[0]）、输出时从高位倒着打——第 11 章的基本功全在里面。数组开 350 位足够（2^1000 有 302 位）。
