**为什么是 i + j？**

把数倒着存（下标 0 = 个位），那么下标 i 上的数字，真实数值是 `a[i] × 10^i`。于是：

`(a[i] × 10^i) × (b[j] × 10^j) = a[i] × b[j] × 10^(i+j)`

正好落在结果的第 `i + j` 位上。所以：

```
for (int i = 0; i < la; i++)
    for (int j = 0; j < lb; j++)
        c[i + j] += a[i] * b[j];    // 先只管累加，进位留到最后统一处理
```

**先累加、后进位**是最省心的写法。累加完毕后，c 的每一位可能是个很大的数（不止一位），再扫一遍统一进位：

```
for (int i = 0; i < len; i++) {
    c[i + 1] += c[i] / 10;   // 超出个位的部分进给高位
    c[i] %= 10;              // 本位只留一位
}
```

**会溢出吗？** 每位最多累加 500 次 `9 × 9 = 81`，即 40500，int 完全够用。但如果位数上万，就得考虑 long long 了。

**长度**：结果最多 `la + lb` 位。数组务必开够，且最后要去前导零（`0 × 12345` 会得到一串 0）。

**复杂度**：O(la × lb)，500 × 500 = 25 万，非常快。
