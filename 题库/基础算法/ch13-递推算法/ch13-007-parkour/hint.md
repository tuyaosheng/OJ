在爬楼梯（本章例1）的方程上加一个"开关"：

```cpp
f[0] = 1;                          // 站在地面算 1 种方案
f[i] = trap[i] ? 0 : (f[i-1] + f[i-2]) % MOD;
```

陷阱台阶"落不了脚"，所以它的方案数是 0——这样它对后面台阶的贡献自动消失，跳过它的方案仍由更前面的台阶传递。

两个细节：i = 1 时没有 f[-1]，单独处理（或把方程写成只加存在的项）；**每一步都取模**，别等溢出。

样例 1：n=3，陷阱 {2}：f1=1, f2=0, f3=f2+f1=1（只能 1→3 跳两级），输出 1。
