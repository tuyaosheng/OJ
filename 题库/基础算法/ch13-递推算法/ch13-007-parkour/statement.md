《地铁跑酷》一类的跑酷游戏里有一段 n 级的台阶，你从**地面（第 0 级）**出发，每一步可以向上跳 **1 级**或 **2 级**，目标是恰好落在**第 n 级**。

但是关卡设计师在其中 k 级台阶上装了**陷阱**——陷阱台阶**绝对不能踩**（可以跳过它，但不能落脚）。

请问：从地面到第 n 级，有多少种不同的跳法？答案对 **1000000007** 取模。

（如果第 n 级本身是陷阱，那么答案是 0。）
