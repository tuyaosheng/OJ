**推导 D(n)：还是盯住"最后一个"**

考虑第 n 封信。它不能进第 n 号信封，那它进了几号呢？假设它进了 **k 号**信封（k 可以是 1 ~ n−1 中任意一个，共 **n−1** 种选择）。

选定 k 之后，再看**第 k 封信**去了哪里，这里**恰好分成两种情况**：

**情况一：第 k 封信进了第 n 号信封**（两封信"交换"了信封）

此时信 n 和信 k 互相占了对方的位置，它们俩都已安置妥当。剩下的 **n−2** 封信要在剩下的 n−2 个信封里**全部装错** → **D(n−2)** 种。

**情况二：第 k 封信【没有】进第 n 号信封**

现在剩下 n−1 封信（编号 1..n−1，除去已放好的信 n）要放进 n−1 个信封（编号 1..n−1 中除去 k，再加上 n 号）。

这里有个巧妙的观察：对第 k 封信来说，"**不能进 n 号信封**"这个限制，和"**不能进自己的信封**"在**形式上完全一样**！

于是我们可以把 n 号信封**看作**第 k 封信"自己的"信封。这样一来，问题就变成了：n−1 封信放进 n−1 个信封，每封信都有一个"禁止的信封"，要求全部装错 → 这**正是 D(n−1)**！

所以：**每选定一个 k，就有 D(n−1) + D(n−2) 种方案**。而 k 有 **n−1** 种选法：

### **D(n) = (n − 1) × [ D(n−1) + D(n−2) ]**

**边界**：
- `D(1) = 0`（只有一封信一个信封，只能装对，无法装错）
- `D(2) = 1`（两封信互换，唯一一种）

验算：`D(3) = (3-1) × (D(2) + D(1)) = 2 × (1 + 0) = 2` ✓ 和题目样例一致！

`D(4) = 3 × (D(3) + D(2)) = 3 × (2 + 1) = 9` —— 这就是著名的"**九种装错法**"。

**实现要点**：

```cpp
d[i] = (long long)(i - 1) * (d[i-1] + d[i-2]) % MOD;
```

**小心溢出**：`(i-1)` 最大约 10^6，`(d[i-1] + d[i-2])` 最大约 2 × 10^9，两者相乘约 **2 × 10^15** —— **远超 int**，必须用 `long long`。而且乘法前要先转 `long long`。

**复杂度**：O(n)。
