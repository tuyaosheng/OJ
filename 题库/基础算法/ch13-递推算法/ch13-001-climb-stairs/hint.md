**推导递推式：盯住"最后一步"**

要走到第 n 级，**最后一步**只有三种可能：

- 从第 **n−1** 级迈 **1** 级上来；
- 从第 **n−2** 级迈 **2** 级上来；
- 从第 **n−3** 级迈 **3** 级上来。

这三种情况**不重不漏**（最后一步只能是 1、2、3 级中的一种）。所以：

**f[i] = f[i−1] + f[i−2] + f[i−3]**

（这个数列有个名字，叫 **Tribonacci**——斐波那契的"三项版"。）

**边界**（务必自己验证一遍）：
- `f[0] = 1`（站着不动也算一种方案，和「数楼梯」一样）
- `f[1] = 1`（只能迈 1 级）
- `f[2] = 2`（1+1，或 2）

验算 `f[3] = f[2] + f[1] + f[0] = 2 + 1 + 1 = 4`。手动数一数：`1+1+1`、`1+2`、`2+1`、`3` —— 正好 **4** 种 ✓

**关于取模**

n 可达 100 万，答案会大到天上去。题目让我们对 10^9+7 取模，所以**每加一次就取一次模**：

```cpp
f[i] = (f[i-1] + f[i-2] + f[i-3]) % MOD;
```

**为什么中途就要取模，不能最后再取？** 因为不取模的话，数值早就爆掉了 `long long`。取模的性质保证：**边算边取模**和**最后再取模**，结果完全一样。

**小心溢出**：三个数各自小于 10^9，相加最大约 3 × 10^9 —— **超过 int 上限**！所以要用 `long long` 存，或者每加一次就取模。

**复杂度**：O(n)，100 万次循环，瞬间完成。（用滚动变量还能把空间降到 O(1)。）
