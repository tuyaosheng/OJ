# 讲解稿：爬楼梯（ch13-001）

## 一、题目解读

n 级楼梯，每次可以迈 **1 级、2 级或 3 级**，问走到第 n 级有多少种走法？n ≤ 100 万，答案对 10^9+7 取模。

第 11 章的「数楼梯」里，每次只能迈 1 或 2 级。现在多了个"3 级"。

**别急着去改公式。** 本章的主题是**递推**，而递推的核心能力是——

> ### **推导，而不是记忆。**

所以请跟我一起，把这个递推式**从头推一遍**。这个过程本身，比答案重要得多。

## 二、思路分析

### 万能的思考方式：盯住"最后一步"

这是递推问题的**总钥匙**，请把它刻进脑子里：

> **要到达"终局"，最后一步是怎么走的？把所有可能的"最后一步"列出来，每一种都对应一个"更小的子问题"。**

对本题：要走到第 **i** 级，**最后一步**只可能是三选一——

| 最后一步 | 说明 | 对应的子问题 |
|---------|------|-------------|
| 迈 **1** 级 | 从第 i−1 级上来 | 走到 i−1 级有几种走法？→ `f[i-1]` |
| 迈 **2** 级 | 从第 i−2 级上来 | → `f[i-2]` |
| 迈 **3** 级 | 从第 i−3 级上来 | → `f[i-3]` |

**这三种情况不重不漏**：
- **不漏**——最后一步必然是 1、2、3 级中的某一种，没有第四种可能。
- **不重**——最后一步迈了几级是**确定的**，一种走法不可能同时"最后一步迈 1 级"又"最后一步迈 2 级"。

（**"不重不漏"是递推正确性的生命线**。每次推完式子，都要在心里过一遍这四个字。）

既然不重不漏，把三种情况的方案数**加起来**就是总数：

### **f[i] = f[i−1] + f[i−2] + f[i−3]**

（这个数列叫 **Tribonacci**——斐波那契的"三胞胎版"。但你看，我们并不需要知道它的名字，照样能推出来。）

### 边界：递推的起点

递推式告诉我们"怎么从旧的推出新的"，但总得有个**出发点**。

- **f[0] = 1**：0 级楼梯，人已经在终点了。什么都不做，算 **1 种**走法（"空方案"）。
  > ⚠️ 这是**最容易错**的边界。若写成 0，整个数列全盘崩塌。
- **f[1] = 1**：只能迈 1 级。
- **f[2] = 2**：`1+1` 或 `2`，两种。

**验算一下** f[3]：

`f[3] = f[2] + f[1] + f[0] = 2 + 1 + 1 = 4`

手动数一数 3 级楼梯：`1+1+1`、`1+2`、`2+1`、`3` —— 正好 **4 种** ✓

**推完式子一定要用小数据验算！** 这是最有效的查错手段。

## 三、代码讲解

### 取模：为什么要"边算边取"？

n 可达 100 万，方案数会大到无法想象（远超 `long long`）。所以题目要求对 **10^9+7** 取模。

关键问题：**能不能最后再取模？**

**不能！** 因为不取模的话，数值在中途就已经溢出了，溢出后的数再取模也是错的。

好在取模有个优美的性质：

> **(a + b) mod m = ((a mod m) + (b mod m)) mod m**

意思是：**边算边取模，和最后再取模，结果完全一样。** 于是我们放心地每一步都取：

```cpp
cur = (f0 + f1 + f2) % MOD;
```

### 溢出细节

`f0`、`f1`、`f2` 取模后各自小于 10^9，三个相加最大约 **3 × 10^9**。

而 `int` 的上限是约 **2.147 × 10^9** —— **溢出了！**

所以这三个变量必须是 **`long long`**。（这类"取模之后仍可能在相加时溢出"的坑非常隐蔽，务必留心。）

### 滚动变量：把空间从 O(n) 降到 O(1)

最直白的写法是开个数组 `f[1000001]`。但注意：算 `f[i]` 只用到**最近三项**，更早的再也用不着了。

所以只留三个变量就够：

```cpp
long long f0 = 1, f1 = 1, f2 = 2;    // f[0], f[1], f[2]

for (int i = 3; i <= n; i++)
{
    cur = (f0 + f1 + f2) % MOD;

    f0 = f1;    // 整体往前挪一位
    f1 = f2;
    f2 = cur;
}
```

**滚动的顺序不能乱**：必须 `f0 ← f1`、`f1 ← f2`、`f2 ← cur`，从左往右依次覆盖。若顺序反了，旧值会被提前冲掉。

（第 11 章「数楼梯」里我们已经用过这个技巧，这里是二次巩固。）

**复杂度**：时间 O(n)，空间 **O(1)**。100 万次循环，几毫秒。

## 四、易错点

1. **`f[0] = 0`** —— 头号杀手。必须是 **1**。
2. **用 `int` 存** —— 三项相加约 3×10^9，溢出。必须 `long long`。
3. **忘记取模，或只在最后取模** —— 中途早就溢出了。
4. **滚动顺序写反** —— 旧值被提前覆盖。
5. **忘记特判 n = 1、n = 2** —— 循环从 i=3 开始，n 更小时循环不执行，`cur` 是未初始化的垃圾值。

## 五、小结

本题看似简单，却把**递推的完整方法论**演示了一遍：

| 步骤 | 本题的答案 |
|------|-----------|
| ① **定义状态** | `f[i]` = 走到第 i 级的方案数 |
| ② **盯住最后一步**，列出所有可能 | 最后迈 1 / 2 / 3 级 |
| ③ **检查"不重不漏"** | ✓ 最后一步必是三者之一，且互斥 |
| ④ **写出转移方程** | `f[i] = f[i-1] + f[i-2] + f[i-3]` |
| ⑤ **确定边界** | `f[0]=1, f[1]=1, f[2]=2` |
| ⑥ **小数据验算** | f[3] = 4 ✓ |

**这套流程，本章每一道题都会用到。** 请把它变成肌肉记忆。
