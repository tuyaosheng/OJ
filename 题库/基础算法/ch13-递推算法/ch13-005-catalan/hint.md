**推导：盯住"第 1 个数（也就是数字 1）什么时候出栈"**

这题的突破口有点特别。我们来问一个问题：

> **数字 1 是第几个出栈的？**

假设数字 **1 是第 (k+1) 个出栈**的（k 可以是 0 ~ n−1）。也就是说，在 1 出栈之前，已经有 **k** 个数先出栈了。

这意味着什么？

- 1 是**最先入栈**的，所以它在栈的**最底下**。
- 要让 1 出栈，必须先把压在它上面的数**全部弹出**。
- 那些比 1 先出栈的 k 个数，只能是 **2, 3, …, k+1** 这 k 个数（它们在 1 之上，且必须在 1 出栈前清空）。

于是整个过程被 **1 的出栈**这个时刻，**劈成了两个独立的部分**：

- **左边**：数字 `2 … k+1` 这 **k** 个数，它们在 1 之前完成入栈出栈 → 这是一个规模为 **k** 的**同类子问题** → **f[k]** 种；
- **右边**：数字 `k+2 … n` 这 **n−1−k** 个数，它们在 1 之后入栈出栈 → 规模为 **n−1−k** 的子问题 → **f[n−1−k]** 种。

两部分**互不干扰**，可以自由组合，所以这种情况的方案数是 **f[k] × f[n−1−k]**。

k 可以取 0 到 n−1，把所有情况加起来：

### **f[n] = Σ (k = 0 到 n−1) f[k] × f[n−1−k]**

**边界**：`f[0] = 1`（0 个数，只有"空序列"这一种方案）。

**验算**：
- `f[1] = f[0]×f[0] = 1`
- `f[2] = f[0]×f[1] + f[1]×f[0] = 1 + 1 = 2`
- `f[3] = f[0]×f[2] + f[1]×f[1] + f[2]×f[0] = 2 + 1 + 2 = **5**` ✓ 和样例一致！

**这个数列叫「卡特兰数」（Catalan Number）**，是组合数学中最著名的数列之一。它还能解决：n 对括号的合法匹配数、n 个节点的二叉树形态数、凸多边形的三角剖分数……**同一个数列，无数张面孔。**

**实现**：

```cpp
f[0] = 1;
for (int i = 1; i <= n; i++)
{
    f[i] = 0;
    for (int k = 0; k <= i - 1; k++)
        f[i] = (f[i] + f[k] * f[i-1-k]) % MOD;    // 注意 long long
}
```

**复杂度**：两重循环 **O(n²)**。n = 5000 时约 1250 万次，完全可以接受。

**溢出警告**：`f[k] * f[i-1-k]` 两个数都可能接近 10^9，**乘积达 10^18** —— 必须用 `long long`（它的上限约 9.2 × 10^18，刚好够用）。用 int 会瞬间溢出。
