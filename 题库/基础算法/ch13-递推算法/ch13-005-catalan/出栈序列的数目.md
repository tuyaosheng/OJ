# 讲解稿：出栈序列的数目（ch13-005）

## 一、题目解读

n 个数按 `1, 2, …, n` 的顺序**依次入栈**，但每个数入栈后**可以随时出栈**。问能得到多少种不同的**出栈序列**？

n = 3 时有 5 种：`123`、`132`、`213`、`231`、`321`。

**为什么 `312` 不行？** 3 先出栈，说明 1、2、3 都已入栈（栈内从底到顶是 1、2、3）。3 弹出后，栈顶是 **2**，所以 2 必须比 1 先出。`312` 违反了这一点。

**本题的递推结构是全新的**：前面几题都是"当前项 = 前面固定几项之和"，而这题要**把一堆项两两相乘再求和**。

## 二、思路分析

### 突破口：盯住"数字 1 什么时候出栈"

前几题我们盯的是"最后一步"。这题换个角度——盯住**数字 1**。

为什么是 1？因为**1 最先入栈，所以它躺在栈的最底下**。这个特殊位置会带来强约束。

> **假设数字 1 是第 (k+1) 个出栈的。** 也就是说，在 1 出栈之前，已经有 **k** 个数先出栈了。（k 可以是 0 ~ n−1。）

### 这个假设能推出什么？

1 在栈底。要让 1 出栈，**必须先把压在它上面的数全部弹光**。

那么，比 1 先出栈的那 **k** 个数，都是谁？

- 它们必须在 1 之上 → 它们是在 1 之后入栈的；
- 它们必须在 1 出栈前就被弹出。

由于入栈顺序是 1, 2, 3, …，压在 1 上面的、且能在 1 之前弹出的，**只能是 `2, 3, …, k+1` 这连续的 k 个数**。

（想一想：如果 `k+2` 也在 1 之前出栈了，那它入栈时 `k+1` 还在栈里更下面，`k+2` 出栈没问题……但那样先出栈的就不止 k 个了，与假设矛盾。所以先出栈的恰好是最前面的 k 个。）

### 关键：问题被"劈"成了两半

**数字 1 的出栈时刻**，像一把刀，把整个过程切成了**两个互不干扰**的部分：

| | 涉及的数 | 数量 | 方案数 |
|---|---------|------|--------|
| **1 出栈之前** | `2, 3, …, k+1` | **k** 个 | 这 k 个数的入栈出栈是一个**同类子问题** → **f[k]** |
| **1 出栈之后** | `k+2, …, n` | **n−1−k** 个 | 同样是子问题 → **f[n−1−k]** |

**为什么是"同类子问题"？** 因为这 k 个数（2 到 k+1）也是按顺序入栈、随时可出栈，栈的规则完全一样——**只是数字的标签变了，结构一模一样**。（又是"同构"的思想！）

**两部分独立，可以自由组合**，所以方案数**相乘**：`f[k] × f[n−1−k]`。

### 求和

k 可以取 0, 1, 2, …, n−1，把所有情况**加起来**：

### **f[n] = Σ (k=0 到 n−1) f[k] × f[n−1−k]**

**边界**：`f[0] = 1`（0 个数，只有"空序列"这一种方案）。

**验算**：
- `f[1] = f[0]×f[0] = 1`
- `f[2] = f[0]×f[1] + f[1]×f[0] = 1 + 1 = 2`
- `f[3] = f[0]×f[2] + f[1]×f[1] + f[2]×f[0] = 2 + 1 + 2 = 5` ✓ 与样例一致！

## 三、代码讲解

```cpp
f[0] = 1;

for (int i = 1; i <= n; i++)
{
    f[i] = 0;

    for (int k = 0; k <= i - 1; k++)
        f[i] = (f[i] + f[k] * f[i - 1 - k]) % MOD;
}
```

**两重循环**：外层枚举规模 i，内层枚举"1 是第 k+1 个出栈的"。

注意 `f[k] * f[i-1-k]` 的下标：两个下标**加起来恰好等于 i−1**（因为总共 n 个数，除去数字 1，还剩 n−1 个被分成两组）。**这是卡特兰数递推的标志性特征**，看到 `f[k] * f[i-1-k]` 就该警觉。

### 溢出：必须 long long

`f[k]` 和 `f[i-1-k]` 取模后都可能接近 **10^9**。

两者相乘 ≈ **10^18**。

- `int` 上限 2×10^9 —— **早就爆了**；
- `long long` 上限 **9.2 × 10^18** —— **刚好够用**（这也是为什么模数常取 10^9+7 而不是更大：要保证两个模数相乘不超 long long）。

### 复杂度

两重循环 **O(n²)**。n = 5000 时约 **1250 万**次乘法取模，实测 37 ms，轻松通过。

（如果 n 到 10^6，O(n²) 就不行了，得用卡特兰数的**通项公式** `C(2n,n)/(n+1)`，配合**逆元**求模——那是更进阶的内容。）

## 四、卡特兰数：一个数列，无数张面孔

这个数列 **1, 1, 2, 5, 14, 42, 132, …** 叫**卡特兰数**（Catalan Number），是组合数学中最著名的数列之一。

**它能解决的问题多得惊人**：

| 问题 | 描述 |
|------|------|
| **出栈序列**（本题） | n 个数入栈，有几种出栈序列 |
| **括号匹配** | n 对括号，有几种合法的匹配方式 |
| **二叉树形态** | n 个节点，能构成几种不同形状的二叉树 |
| **三角剖分** | 凸 n+2 边形，用不相交对角线分成三角形，有几种分法 |
| **单调路径** | n×n 网格，从左下走到右上且不越过对角线的路径数 |

**为什么它们答案相同？** 因为它们**结构同构**——都能被"某个位置"劈成两个独立的同类子问题，然后**相乘求和**。

> **当你在一道新题里发现："选一个分割点，把问题劈成左右两个同类子问题，方案数相乘"——那多半就是卡特兰数。**

这种**模式识别**能力，是刷题积累出来的宝贵直觉。

## 五、小结

### 递推结构的进化

| 章节题目 | 递推结构 |
|---------|---------|
| 爬楼梯 | `f[i] = f[i-1] + f[i-2] + f[i-3]` （**加**上前面固定几项） |
| 错位排列 | `D[i] = (i-1) × (D[i-1] + D[i-2])` （前面几项的**加权**组合）|
| **出栈序列** | `f[i] = Σ f[k] × f[i-1-k]` （前面所有项**两两相乘再求和**）|

**结构越来越复杂，但方法论从未改变**：

1. **找一个"关键决策点"**（最后一步 / 数字 1 何时出栈 / 信 n 进哪个信封）；
2. **按这个决策点分类**，确保**不重不漏**；
3. **每一类都归约成更小的同类子问题**；
4. **合并**（加法原理 / 乘法原理）。

### 加法原理 vs 乘法原理

这题同时用上了两条组合计数的基本法则：

- **乘法原理**：两个**独立**的部分，方案数**相乘**（`f[k] × f[n-1-k]`）——因为左边每种走法都能和右边每种走法自由搭配。
- **加法原理**：若干**互斥**的情况，方案数**相加**（对 k 求和）——因为"1 是第几个出栈"只能是其中一种。

**"独立 → 乘"，"互斥 → 加"** ——这八个字是所有计数问题的基石。
