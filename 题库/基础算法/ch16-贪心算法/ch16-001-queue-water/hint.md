**贪心结论：打水时间短的同学先打。**

**为什么？**——假设排在相邻两个位置的同学 A、B，A 在前、B 在后。若 A 打水时间 > B 打水时间，交换 A、B 的顺序：

- 交换前：B 要多等 A 的时间（因为 A 排在他前面）；
- 交换后：A 要多等 B 的时间，但 B 的时间更短。

交换后，两人等待时间之和**不会变大**（反而更小），其他同学的等待时间完全不受影响。只要还存在"前面的比后面的慢"，就交换、就更优——这说明**排序（从小到大）是最优策略**。这种"交换看看会不会更好"的证明方法，叫**交换论证**，是贪心算法最常用的证明武器。

**代码骨架**：

```cpp
sort(t, t + n);                 // 从小到大排序
long long total = 0, wait = 0;  // wait: 当前累计的"前面同学用掉的时间"
for (int i = 0; i < n; i++) {
    total += wait;               // 第 i 个人的等待时间就是 wait
    wait += t[i];                 // 他打完水，后面的人还要多等这么久
}
printf("%.2f\n", (double)total / n);
```

n=1000、t≤1000 时，total 最大约 5×10⁸，**用 long long 存**，最后除以 n 再转 double 保留两位小数。
