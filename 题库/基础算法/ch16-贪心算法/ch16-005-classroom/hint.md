**贪心结论：按结束时间从早到晚排序，能安排就安排。**

**为什么按结束时间排序，而不是开始时间或时长？**——直觉：一个班越早结束，留给后面班级的时间就越多，选择权越大。所以优先照顾"结束得早"的申请。

```cpp
sort(act, act + n, [](auto &a, auto &b){ return a.e < b.e; });  // 按结束时间排序
int cnt = 0;
long long last_end = -1;               // 上一个被安排的班级的结束时间
for (int i = 0; i < n; i++) {
    if (act[i].s >= last_end) {        // 开始时间不早于上一个的结束时间：不冲突
        cnt++;
        last_end = act[i].e;
    }
}
```

这是"活动选择问题"的经典模型，第 10 章"车厢重组"之类的贪心/模拟题都是它的近亲。
