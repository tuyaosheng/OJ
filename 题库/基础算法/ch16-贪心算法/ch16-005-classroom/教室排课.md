# 教室排课——讲解稿

## 一、题目解读

n 个时间段申请同一间教室，选出尽量多的互不冲突的申请。这是贪心算法里最经典的模型之一——**活动选择问题（Activity Selection）**。

## 二、思路分析

为什么按**结束时间**排序而不是别的？反例能帮我们排除错误策略：

- 按**开始时间**排序贪心：可能选中一个开始很早但持续很久的活动，占满了教室，反而少安排了后面一堆短活动；
- 按**时长**排序贪心（先选短的）：短的活动可能恰好卡在两个长活动中间，导致冲突判断变复杂，且不一定更优。

按**结束时间**排序才是对的：结束得越早，给"未来"留的空间越大，是最不"贪婪占用资源"的选择。可以用交换论证严格证明：假设最优解没有选"结束最早"的那个活动，把最优解里第一个被选中的活动换成"结束最早"的那个，新方案不会更差（因为它结束得更早，后面能选的只会更多不会更少）。

## 三、代码讲解

```cpp
sort(act, act + n, cmp);   // 按 e 升序
int cnt = 0;
long long last_end = -1;
for (...) if (act[i].s >= last_end) { cnt++; last_end = act[i].e; }
```

`last_end` 滚动记录"当前教室被占到什么时候"，一旦某个申请的开始时间不早于它，就说明能背靠背安排上。O(n log n)（排序占大头），n=10⁵ 毫无压力。

## 四、易错点

1. 排序关键字选错（按开始时间或时长）——不是最优策略；
2. 判断条件用 `>` 而不是 `>=`——题目明确"结束时间恰好等于开始时间不算冲突"，漏掉等号会少选；
3. `last_end` 初始值要设成比所有可能的 s 都小（如 -1），保证第一个候选一定能被选中的判断正确。

## 五、小结

区间贪心的通用心法：**按结束时间排序，能选就选**。这题和第 10 章"车厢重组"的差分/模拟视角不同，是贪心视角处理区间问题的代表，后面遇到"教室""会议室""区间调度"字眼，先反射性想到这个模型。
