设平均值 `avg = 总和 / n`。定义每堆和平均值的**差值** `c[i] = a[i] - avg`（可能是负数）。

**关键结论**：设 `s[i] = c[1] + c[2] + ... + c[i]`（前缀和），答案就是 **`|s[1]| + |s[2]| + ... + |s[n-1]|`**。

**直觉**：`s[i]` 表示"第 1~i 堆合起来，比它们理应有的总量多了/少了多少"。这个差额必然要通过**第 i 堆和第 i+1 堆之间**的那次移动来补齐——多了就要往右移 `s[i]` 张，少了就要从右边借 `|s[i]|` 张。每两堆之间只需要移动**一次**（一次可以移任意数量），所以第 i、i+1 堆之间的移动次数下限就是 `|s[i]|`，n-1 个间隔加起来就是答案。

```cpp
long long avg = sum / n, s = 0, ans = 0;
for (int i = 0; i < n - 1; i++) {     // 只需要看前 n-1 个前缀和
    s += a[i] - avg;
    ans += abs(s);
}
```
