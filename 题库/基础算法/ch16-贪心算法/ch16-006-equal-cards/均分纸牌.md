# 均分纸牌——讲解稿

## 一、题目解读

一排纸牌堆，只能在相邻堆之间搬，目标是让所有堆相等，求最少操作次数。这题的贪心结论极其简洁，但推导过程值得细品——它用的是**前缀和**这个老朋友（第 10 章的主角），只是用在了一个新场景。

## 二、思路分析

先想：如果某一堆比平均值多，多出来的必须挪给别的堆；比平均值少，缺的必须从别处补。但纸牌只能在**相邻**堆之间移动，不能"隔空"直接给远处的堆。

关键的观察是：把第 1 堆到第 i 堆看成一个"大区域"，这个大区域**理应**有 `i * avg` 张牌，但实际有 `a[1]+...+a[i]` 张，差值就是前缀和 `s[i] = (a[1]-avg) + ... + (a[i]-avg)`。这个差额只能通过"第 i 堆与第 i+1 堆之间"的这一次移动来解决——多了就要把 `s[i]` 张挪到右边，少了就要从右边借 `|s[i]|` 张过来。

每个相邻间隔都独立计算一次移动量（一次操作能挪任意数量，所以每个间隔只需要移动 1 次），把 n-1 个间隔的移动量绝对值加起来，就是总操作次数。

## 三、代码讲解

```cpp
long long avg = sum / n, s = 0, ans = 0;
for (int i = 0; i < n - 1; i++) {
    s += a[i] - avg;
    ans += llabs(s);
}
```

只需要扫一遍数组，边算前缀和边累加绝对值，O(n)。注意循环到 `n-1`（下标 0 到 n-2），因为最后一堆（第 n 堆）不需要再往右移了——它和前面所有堆的"总账"应该刚好平衡为 0（这也是一个隐含的验证：`s[n-1]` 算出来必然是 0）。

## 四、易错点

1. 循环边界写成 `i < n`（多算一项）——虽然多出的那一项理论上是 0，但如果代码有 bug 反而会掩盖问题，规范写法就是只到 `n-1`；
2. `avg` 用 `sum / n` 整除即可，因为题目保证总数能整除 n，不会有小数；
3. 差值可能是负数，注意用 `llabs`（long long 版绝对值）而不是 `abs`（有些编译器 `abs` 只接受 int，负数溢出行为不确定）；
4. 数组、前缀和累加值可能上千万级，用 long long。

## 五、小结

这题看着是"贪心"，本质是**前缀和的巧妙应用**——把"只能相邻移动"的约束转化成"前缀和必须逐步清零"的观察。贪心类问题经常需要先做一次这样的"转化视角"，把复杂的操作规则变成一个可以直接计算的数学表达式。
