# 排序不等式·最优配对——讲解稿

## 一、题目解读

两组数一一配对求乘积和的最小值，配对方式可以任意选。n! 种配对方案暴力枚举是不可能的（n≤1000），需要贪心结论。

## 二、思路分析

结论很反直觉但很优美：**大的配小的，小的配大的**，乘积和才最小。反过来"大配大、小配小"，乘积和反而是**最大**的。

证明用的还是交换论证（和排队接水那道题手法一模一样）：假设方案里有一对"大配大"（a 更大的那个配上了 b 更大的那个），交换后乘积和的变化量算出来是 `(a[j]-a[i])(b[j]-b[i])`，两个因子同号所以乘积 ≥ 0，说明**交换成"大配小"不会更差**。反复消灭所有"大配大"的情况，最终就是"a 升序、b 降序"。

## 三、代码讲解

```cpp
sort(a, a + n);                     // 升序
sort(b, b + n, greater<int>());     // 降序
for (int i = 0; i < n; i++) ans += (long long)a[i] * b[i];
```

一行排序一个方向、一行排序另一个方向，配对时下标对齐即可。乘积用 long long 强转再相加，避免 int 溢出。

## 四、易错点

1. 两个数组都用同一方向排序——那样得到的是**最大**乘积和，不是最小；
2. `a[i] * b[i]` 不强转直接用 int 相乘再赋给 long long——乘法本身已经溢出，为时已晚，要**先转类型再乘**；
3. 想复杂了去暴力枚举配对方式——排序不等式是 O(n log n) 直接出解。

## 五、小结

这是排队接水那道题证明手法的"双数组版"：只要能通过交换论证说明"某种排法一定不劣于其他排法"，就能把贪心策略坐实。以后遇到"两组数怎么配对最优"，先想想能不能套排序不等式。
