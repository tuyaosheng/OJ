这是**排序不等式**的直接应用，结论只有一句话：

**A 升序排列，B 降序排列（"顺大配小、顺小配大"），乘积和最小；两者都升序（或都降序）配对，乘积和最大。**

**直觉证明（交换论证再登场）**：假设某个配对方案里，a 比较大的那个数配上了 b 也比较大的数（正序配对），即存在 a[i] < a[j] 但 b[i] < b[j]（i 配 i，j 配 j）。交换 b[i]、b[j] 的配对对象：

```
交换前： a[i]*b[i] + a[j]*b[j]
交换后： a[i]*b[j] + a[j]*b[i]
```

两式相减：`(交换前) - (交换后) = (a[j]-a[i]) * (b[j]-b[i]) ≥ 0`（因为 a[j]≥a[i] 且 b[j]≥b[i]）。也就是说**交换后的乘积和不会比交换前大**——只要存在"大配大"的一对，交换成"大配小"只会更好或不变。反复交换到底，就是"A 升序、B 降序"的状态。

```cpp
sort(a, a + n);                          // 升序
sort(b, b + n, greater<int>());          // 降序
long long ans = 0;
for (int i = 0; i < n; i++) ans += (long long)a[i] * b[i];
```
