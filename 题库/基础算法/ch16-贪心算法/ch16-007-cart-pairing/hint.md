**贪心结论（双指针）：排序后，最重的矿石优先和最轻的矿石配对；配不上就让最重的单独坐一辆车。**

```cpp
sort(w, w + n);
int i = 0, j = n - 1, cars = 0;
while (i <= j) {
    if (i < j && w[i] + w[j] <= W) {
        i++;         // 最轻的和最重的凑成一车
    }
    j--;              // 最重的这块（不管配没配上）已经走了，车数 +1
    cars++;
}
```

**为什么这样贪心是对的？**——最重的那块 w[j] 无论如何都要占一辆车（它是当前最重的，谁都配不了就它自己一车）；既然这辆车已经出发了，那就应该**尽量塞满**它，能塞下最轻的 w[i] 就塞（反正 w[i] 早晚要走，不占这次的名额就要占以后的）。这样每一辆车都在"最大化利用运力"，车辆数一定最少。
