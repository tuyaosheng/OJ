# 混合牛奶——讲解稿

## 一、题目解读

从多个供应商买够 need 加仑牛奶，每家单价不同、供应量有限，求最少花费。这是"**性价比贪心**"的入门模型：单价就是性价比的直接体现，谁便宜先买谁。

## 二、思路分析

贪心策略几乎不需要证明就很直觉：钱要花在刀刃上，同样的牛奶，肯定挑便宜的买。严格说：假设最优方案里买了一部分贵的、却没把某个更便宜供应商的货买满，那么把买贵的部分换成买那个便宜供应商剩下的量，**花费只会更少**——矛盾，所以最优方案一定是"能买便宜的就不买贵的"。

## 三、代码讲解

```cpp
sort(sup, sup + m, cmp);              // 按单价升序
for (int i = 0; i < m && remain > 0; i++) {
    long long buy = min(sup[i].amount, remain);
    cost += buy * sup[i].price;
    remain -= buy;
}
```

`min(sup[i].amount, remain)`——这家能卖的量和"还需要多少"取较小值，是这题的关键一行：可能这家的货绰绰有余（这时买 remain 份就够了，循环结束），也可能这家货不够（买光他的，继续找下一家）。

## 四、易错点

1. 排序方向反了（按单价降序）——那是最费钱的买法；
2. 每家买的量忘记和"还需要多少"取 min——可能买超过 need；
3. 花费用 int 存：2×10⁶ × 1000 = 2×10⁹，**超出 int 范围，必须 long long**；
4. 循环提前退出的条件 `remain > 0` 别漏，否则供应商买光了继续傻算。

## 五、小结

"排序 + 从最优的开始拿，拿不够换下一个"是性价比类贪心的通用模板，例3 合并果子会看到贪心的另一种武器——优先队列（堆）。
