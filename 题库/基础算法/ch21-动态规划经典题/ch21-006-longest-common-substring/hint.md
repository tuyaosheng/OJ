- **状态**：`dp[i][j]` = 以 `A[i]` 和 `B[j]` **同时作为结尾**的公共子串长度（注意，这个定义比 LCS 更严格：不是"前 i 个和前 j 个字符里的最长公共子串"，而是"必须以这两个字符结尾"）。
- **转移**：
  - 如果 `A[i] == B[j]`：可以接上前一段，`dp[i][j] = dp[i-1][j-1] + 1`；
  - 如果 `A[i] != B[j]`：**子串要求连续**，一旦断开就不能再接上了，`dp[i][j] = 0`（不像 LCS 那样可以取 `max(dp[i-1][j], dp[i][j-1])`，因为子串不允许"跳过"某个字符）。
- **答案**：不是 `dp[|A|][|B|]`，因为最长公共子串不一定在两个字符串的末尾结束——要在**所有** `dp[i][j]` 里取最大值。
- **和【例1】LCS 的核心区别**，务必对比着理解：
  ```
  LCS（子序列，允许跳跃）：      A[i]!=B[j] 时 dp[i][j] = max(dp[i-1][j], dp[i][j-1])
  本题（子串，要求连续）：      A[i]!=B[j] 时 dp[i][j] = 0
  ```
  这一行代码的差异，正是"子序列"和"子串"这两个概念在 DP 转移上的体现——子序列允许"跳过"不匹配的字符（所以能从别的状态转移过来），子串一旦不匹配就必须从头开始（所以直接归零）。
