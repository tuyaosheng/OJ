# 最长公共子串 讲解稿

## 考点
【例1】最长公共子序列的直接变式："子序列"变"子串"，转移方程有本质区别。

## 引入（1 分钟）
先问学生"子序列"和"子串"有什么区别——子序列可以跳着选（不要求连续），子串必须是原字符串中连续的一段。这个概念上的区别，会直接体现在 DP 转移方程上。

## 核心推导（重点，讲透）
`dp[i][j]` = **以 `A[i]` 和 `B[j]` 同时作为结尾**的公共子串长度（注意这个定义比 LCS 更"严格"：不是"前 i 个和前 j 个字符里的最长公共子串"，而是必须以这两个字符结尾）。

- 如果 `A[i] == B[j]`：可以接上前一段，`dp[i][j] = dp[i-1][j-1] + 1`；
- 如果 `A[i] != B[j]`：**子串要求连续，一旦这里断开，就不可能再接上了**，`dp[i][j] = 0`。

**和 LCS 的核心区别，对比着讲**：
```
LCS（例1，子序列，允许跳跃）：A[i]!=B[j] 时 dp[i][j] = max(dp[i-1][j], dp[i][j-1])
本题（子串，要求连续）：      A[i]!=B[j] 时 dp[i][j] = 0
```
LCS 允许"跳过"不匹配的字符，所以能从别的状态转移过来继续累积；子串一旦不匹配就必须"清零重来"，因为定义要求"连续"，前面积累的长度不能带着断点继续往后延伸。

**答案不是 `dp[|A|][|B|]`**：因为最长公共子串不一定恰好在两个字符串的末尾结束，需要在计算过程中随时更新"迄今为止见过的最大值"。

## 代码逐行讲解
```cpp
if (A[i] == B[j]) {
    dp[i][j] = dp[i - 1][j - 1] + 1;
    ans = std::max(ans, dp[i][j]);
} else {
    dp[i][j] = 0;
}
```
- 在赋值 `dp[i][j]` 的同时更新全局最大值 `ans`，不需要额外再扫一遍二维数组找最大值。

## 易错点
- **最容易犯的错**：照抄 LCS 的转移方程，`A[i]!=B[j]` 时写成 `max(dp[i-1][j], dp[i][j-1])`——这是"子序列"的写法，用在"子串"上是错的，一定要弄清楚这一行代码背后"连续"和"不连续"这两个概念的区别。
- 忘记用一个变量实时记录最大值，只输出 `dp[n][m]`——这是本题第二常见的错误。

## 课堂串讲提示
建议把这题和例1 LCS 的核心两行代码贴在一起对比，让学生自己复述一遍"为什么子串要清零、子序列不用清零"——能说清楚这句话，才算真正理解了这道变式题，而不是记住了另一份代码模板。
