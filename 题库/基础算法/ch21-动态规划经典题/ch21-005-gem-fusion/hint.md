- 撕开游戏外壳看本质：宝石的"能量值"就是石子的"重量"，"合成消耗"就是"合并代价"——这题和【例2】石子合并是完全相同的模型，只是变量名换了。
- 解法完全照抄【例2】：断环成链（把数组复制一份接在后面，变成长度 `2n`）+ 区间 DP + 前缀和：
  ```
  dp[i][j] = min( dp[i][k] + dp[k+1][j] + sum(i, j) )，其中 i ≤ k < j
  答案 = min(dp[i][i+n-1])，i 从 1 到 n
  ```
- 这题不需要重新推导，重点是巩固"断环成链"这个处理圆形结构的通用技巧——以后遇到"围成一圈"的区间类问题，条件反射想到这个套路。
