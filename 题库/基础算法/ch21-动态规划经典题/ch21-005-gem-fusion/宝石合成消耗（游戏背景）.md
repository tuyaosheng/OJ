# 宝石合成消耗（游戏背景） 讲解稿

## 考点
【例2】石子合并的直接变式：换游戏皮肤，巩固"断环成链"技巧。

## 引入（1 分钟）
直接布置这题，先不点破"这是石子合并"，让学生自己判断——"围成一圈的宝石""合成消耗等于能量值之和"，这些描述能不能对应到"石子合并"的模型？

## 核心推导（简要，重点在对照）
- 宝石的"能量值" → 石子的"重量"；
- "合成消耗" → "合并代价"；
- "围成一圈" → 需要"断环成链"处理。

对照清楚后，解法和【例2】完全一样：把数组复制一份接在后面，做区间 DP，枚举展开点取最优：
```cpp
dp[i][j] = min( dp[i][k] + dp[k+1][j] + segSum )，i <= k < j
答案 = min(dp[i][i+n-1])，i 从 1 到 n
```

## 易错点
- 这题没有新的算法难点，最容易出的问题是"断环成链"这一步忘记做，直接对原始 `n` 颗宝石做区间 DP——这样会漏掉"跨越首尾"的合成顺序，在圆圈类的数据上得到错误答案。
- 提醒学生：**看到"围成一圈""首尾相连"这类描述，条件反射想到断环成链**，这是本章要固化的一个重要技巧。

## 课堂串讲提示
可以在这题之后追问一句："如果宝石不是围成一圈，而是排成一排呢？"——检验学生是否明白"断环成链"这一步具体解决了什么问题（如果本来就是直线排列，就完全不需要复制数组这一步，直接对原始 `n` 个数据做区间 DP 即可）。
