- **状态**：`dp[i][j]` = 把 `A` 的前 `i` 个字符变成 `B` 的前 `j` 个字符，最少需要多少次操作——和【例1】LCS 的状态定义方式一模一样。
- **边界**：`dp[i][0] = i`（`B` 是空串，只能把 `A` 的 `i` 个字符全部删掉）；`dp[0][j] = j`（`A` 是空串，只能把 `B` 的 `j` 个字符全部插进来）。
- **转移**：
  - 如果 `A[i] == B[j]`：这两个字符已经相同，不需要任何操作，`dp[i][j] = dp[i-1][j-1]`；
  - 如果 `A[i] != B[j]`：三种操作各自对应一种更小的子问题，取代价最小的：
    - **替换** `A[i]` 变成 `B[j]`：`dp[i-1][j-1] + 1`；
    - **删除** `A[i]`：`dp[i-1][j] + 1`；
    - **插入**一个字符（让它等于 `B[j]`）：`dp[i][j-1] + 1`；
    - `dp[i][j] = 1 + min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1])`。
- **答案**：`dp[|A|][|B|]`。
- 和 LCS 对照：LCS 的转移在"字符相等"时只有一种选择（都往前推进一格）；这题在"字符不相等"时反而有**三种**选择——多想一步"这一步到底要做哪种操作、对应哪个更小的子问题"，转移就能推出来。
