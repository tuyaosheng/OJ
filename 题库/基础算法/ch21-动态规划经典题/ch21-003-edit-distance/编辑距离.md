# 编辑距离 讲解稿

## 考点
双序列 DP 的第二个例子：字符相等/不相等时，选择的分支从两个变成三个。

## 引入（1 分钟）
和例1 LCS 对照来讲：状态定义完全一样（`dp[i][j]` 描述两个字符串各自扫到哪里），但这题多了"替换"这个操作，转移方程会多出一种选择。

## 核心推导（重点，讲透）
`dp[i][j]` = 把 `A` 的前 `i` 个字符变成 `B` 的前 `j` 个字符，最少的操作次数。

- 如果 `A[i] == B[j]`：这两个字符已经一样，不用花代价，`dp[i][j] = dp[i-1][j-1]`；
- 如果 `A[i] != B[j]`：必须做一次操作，三种操作各自对应一个更小的子问题：
  - **替换** `A[i]` 成 `B[j]`：花 1 次操作，剩下变成"把 `A` 前 `i-1` 个变成 `B` 前 `j-1` 个"，即 `dp[i-1][j-1] + 1`；
  - **删除** `A[i]`：花 1 次操作，剩下变成"把 `A` 前 `i-1` 个变成 `B` 前 `j` 个"，即 `dp[i-1][j] + 1`；
  - **插入**一个等于 `B[j]` 的字符到 `A` 末尾：花 1 次操作，剩下变成"把 `A` 前 `i` 个变成 `B` 前 `j-1` 个"，即 `dp[i][j-1] + 1`；
  - 三者取最小值。

**和 LCS 的关键区别**：LCS "不相等"时只丢一个字符、不产生代价（因为丢弃是免费的，公共子序列本来就不要求用上所有字符）；编辑距离"不相等"时**必须花 1 次操作**（因为目标是让两个字符串完全一样，不能跳过不管）。理解了这个区别，转移方程的差异就不难记了。

## 代码逐行讲解
```cpp
for (int i = 0; i <= n; i++) dp[i][0] = i;
for (int j = 0; j <= m; j++) dp[0][j] = j;
```
- 边界：把 `A` 变成空串，只能一路删完，需要 `i` 次操作；把空串变成 `B`，只能一路插完，需要 `j` 次操作。

```cpp
dp[i][j] = 1 + std::min({dp[i - 1][j - 1], dp[i - 1][j], dp[i][j - 1]});
```
- `std::min({...})`（C++11 花括号初始化列表）可以一次比较三个数，比嵌套两次 `std::min` 更清晰。

## 易错点
- 边界初始化容易漏掉或写反：`dp[i][0]` 是"删完"，`dp[0][j]` 是"插满"，别搞混。
- "替换"操作对应的是 `dp[i-1][j-1] + 1`，很多同学第一次写会漏掉这一种选择，只考虑插入和删除——一定要记住三种操作对应三种转移来源。

## 课堂串讲提示
这题讲完后，可以把 LCS 和编辑距离的转移方程贴在一起对比：LCS 是"能白嫖就白嫖"（相等时免费前进，不相等时二选一免费丢弃），编辑距离是"必须付费"（相等时免费前进，不相等时三选一都要花 1 次代价）——这个对比能帮学生更牢固地记住两题的区别。
