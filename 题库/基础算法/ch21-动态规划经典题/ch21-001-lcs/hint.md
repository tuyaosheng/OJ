- **状态**：`dp[i][j]` = `A` 的前 `i` 个字符和 `B` 的前 `j` 个字符的最长公共子序列长度——状态"同时描述两个位置"，是这一章新出现的模式。
- **转移**：
  - 如果 `A[i] == B[j]`：这个字符可以一起选进公共子序列，`dp[i][j] = dp[i-1][j-1] + 1`；
  - 如果 `A[i] != B[j]`：这两个字符至少有一个不在最优的公共子序列末尾，`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`（要么放弃 `A` 的第 `i` 个字符，要么放弃 `B` 的第 `j` 个字符）。
- **边界**：`dp[i][0] = dp[0][j] = 0`（一个字符串是空的，公共子序列长度必然是 0）。
- **答案**：`dp[|A|][|B|]`。
- 复杂度 `O(|A| × |B|)`，本题数据范围下（最大 `1000 × 1000 = 10^6`）足够快。
