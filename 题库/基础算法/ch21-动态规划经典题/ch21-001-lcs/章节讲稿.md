## 上课怎么开场

第 19、20 两章打好了动态规划的基本功——DP 三要素、背包模型。本章是"基础算法"部分收官的一章，不引入全新的算法思想，而是练几道更"综合"的经典题：**状态需要同时描述两个位置（双序列 DP）、状态需要描述一个区间（区间 DP）、把已经学过的模型用两次再合并（双向 LIS）**。这些题目在各类考试和比赛里出现频率很高，值得专门花一章巩固。

## 例1、例3：双序列 DP——LCS 与编辑距离

给两个字符串，很自然地想到：状态是不是也要有两个维度？`dp[i][j]` 同时记录"字符串 A 扫到第几个字符、字符串 B 扫到第几个字符"，这是双序列 DP 的标准起手式。

**例1"最长公共子序列"**：字符相等就接上（`dp[i-1][j-1]+1`），不相等就丢一个（`max(dp[i-1][j], dp[i][j-1])`）。

**例3"编辑距离"**：状态定义和例1一模一样，但"不相等"时的选择从两个变成三个（替换/删除/插入）——因为编辑距离要求"必须操作"，不像 LCS 那样"丢弃是免费的"。这两题贴在一起对比讲，能帮学生把"双序列 DP 状态怎么定义"和"转移方程怎么因题而异"这两件事分开理解。

## 例2：区间 DP——石子合并，外加断环成链

这题的状态第一次变成"一个区间"：`dp[i][j]` 描述"把第 `i` 堆到第 `j` 堆合并成一堆"。转移是区间 DP 的通用套路——枚举一个分割点，拆成两个更小的区间分别解决，再合并。**循环顺序必须按区间长度从小到大**，这是区间 DP 区别于前面几种 DP 的一个新讲究。

"围成一圈"这个设定引出**断环成链**技巧：把数组复制一份接在后面，变成长度 `2n`，在其中枚举所有可能的"展开点"，取最优。这是处理"圆形结构"问题的通用手法，值得单独强调。

## 例4：双向 LIS——把学过的模型用两次

"先增后减"的山峰形状，可以拆成"上升的前半段"和"下降的后半段"，分别就是第 19 章学过的最长上升子序列。正向跑一遍求 `L[i]`，反向跑一遍求 `R[i]`，枚举峰顶合并 `L[i]+R[i]-1`。这题不引入新算法，练的是**把已经会的模型组合起来解决新问题**的能力——这也是本章想传递的核心态度：动态规划学到这个阶段，比"记住更多模板"更重要的，是看到新题时能拆解出"这部分是不是我见过的某个模型"。

## 练习：直接变式，巩固两条主线

【练1】"宝石合成消耗"是例2的直接换皮，巩固断环成链。

【练2】"最长公共子串"是例1的直接变式——"子序列"变"子串"，转移方程从"不相等时二选一"变成"不相等时清零"，这个对比是本章最容易混淆、也最值得讲透的一个细节。

## 学生最容易栽的坑

1. **区间 DP 循环顺序写错**：必须按"区间长度"从小到大遍历，不能按左端点或右端点顺序，否则会用到还没算出来的状态；
2. **忘记断环成链**：题目描述"围成一圈""首尾相连"时，直接对原始数组做区间/线性 DP 会漏掉跨越首尾的情况；
3. **子序列和子串的转移搞混**：子序列允许跳跃（不相等时降级取更小子问题的较优值），子串要求连续（不相等时直接清零）——务必理解"连续"这个概念在 DP 转移里的具体体现，而不是死记两套代码；
4. **双向 LIS 忘记减重复计算的部分**：`L[i]+R[i]` 会把第 `i` 个元素自己算两次，一定要减 1；
5. **编辑距离漏掉某一种操作**：替换、删除、插入三种操作各自对应一种转移来源，容易漏掉"替换"这一项，只写插入和删除两种。
