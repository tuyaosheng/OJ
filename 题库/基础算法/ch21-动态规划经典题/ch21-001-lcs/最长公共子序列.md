# 最长公共子序列 讲解稿

## 考点
双序列 DP 入门：状态第一次需要同时描述"两个位置"。

## 引入（1 分钟）
前面几章的状态大多只涉及一个数组、一个位置（走到第几格、以第几个数结尾）。这题给两个字符串，很自然地要问："状态是不是也要有两个维度？"——对，`dp[i][j]` 同时记录"字符串 A 扫到第几个字符、字符串 B 扫到第几个字符"，这是"双序列 DP"的标准起手式，本章接下来几道题都会用到。

## 核心推导（重点，讲透）
`dp[i][j]` = `A` 的前 `i` 个字符和 `B` 的前 `j` 个字符能凑出的最长公共子序列长度。

考虑 `A[i]` 和 `B[j]` 这两个字符：
- **相等**：那它们俩一定可以一起加入公共子序列（放着不用是不划算的，能匹配上就应该匹配上），`dp[i][j] = dp[i-1][j-1] + 1`；
- **不相等**：这两个字符不可能同时出现在公共子序列的末尾，那就丢掉其中一个——要么丢掉 `A[i]`（用 `dp[i-1][j]`），要么丢掉 `B[j]`（用 `dp[i][j-1]`），取较大值。

**为什么"不相等"时不需要考虑"两个都丢掉"**：`dp[i-1][j-1]`（两个都丢）不会比 `dp[i-1][j]` 或 `dp[i][j-1]` 更优——因为 `dp[i-1][j] >= dp[i-1][j-1]`（`B` 多考虑一个字符，最长公共子序列只会更长或不变），所以只丢一个字符的两种情况已经把"两个都丢"的可能性包含在内了，不需要单独比较。

## 代码逐行讲解
```cpp
if (A[i] == B[j]) {
    dp[i][j] = dp[i - 1][j - 1] + 1;
} else {
    dp[i][j] = std::max(dp[i - 1][j], dp[i][j - 1]);
}
```
- 双重循环 `i` 从 `1` 到 `|A|`，`j` 从 `1` 到 `|B|`，复杂度 `O(|A| × |B|)`。

## 易错点
- 字符串下标习惯从 `1` 开始存（`A[1..n]`），方便 `dp[0][...]`、`dp[...][0]` 表示"空字符串"这个边界，不用额外处理负数下标。
- `dp[i][j]` 里的 `i`、`j` 分别对应 `A`、`B` 的**前几个字符**，不是"第几个字符"，注意 `dp[i-1][j-1]` 里字符下标要写成 `A[i]`、`B[j]`（因为 `A`、`B` 数组下标从 1 开始，`dp` 下标 `i` 恰好对应 `A[i]`）。

## 课堂串讲提示
后面两道题（编辑距离、最长公共子串）都是这题的直接变式，状态定义几乎照抄，区别全在转移方程——建议讲完这题后，先让学生自己合上讲义，凭记忆写出 `dp[i][j]` 的定义，为后面对比转移方程的差异打好基础。
