- **先想直线上的情况**（不考虑圆圈）：`n` 堆石子排成一排，`dp[i][j]` = 把第 `i` 堆到第 `j` 堆合并成一堆的最小代价。
  - **边界**：`dp[i][i] = 0`（单独一堆，不需要合并，代价是 0）。
  - **转移**：枚举一个分割点 `k`（`i ≤ k < j`），把 `[i,j]` 拆成 `[i,k]` 和 `[k+1,j]` 两部分分别合并好，最后再把这两大堆合并到一起：
    ```
    dp[i][j] = min( dp[i][k] + dp[k+1][j] + sum(i, j) )，其中 i ≤ k < j
    ```
    `sum(i, j)` 是第 `i` 堆到第 `j` 堆的重量总和（最后把两大堆合并的代价），提前用**前缀和**算好，避免重复求和拖慢速度。
  - **答案**：`dp[1][n]`。
- **圆圈怎么处理——断环成链**：把原来的 `n` 堆石子数组**复制一份接在后面**，变成长度 `2n` 的数组（比如原来是 `1,2,3`，接成 `1,2,3,1,2,3`）。这样，圆圈上任意一种"连续 `n` 堆"的选法，都能在这个长度 `2n` 的数组里找到一个对应的长度为 `n` 的区间（起点从 `1` 到 `n` 各试一次）。在这个 `2n` 长度的数组上正常做区间 DP，最后答案是 `min(dp[i][i+n-1])`（`i` 从 `1` 到 `n`）——枚举"圆圈从哪里断开展开成一条链"，取最优的那一种。
- 复杂度 `O(n^3)`（区间 DP 的通用复杂度：区间长度、左端点、分割点各一层循环），本题数据范围下足够快。
