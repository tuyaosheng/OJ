# 迷宫最短路径 讲解稿

## 考点
BFS 入门：队列 + 一层层扩散 + "第一次到达即最短"。

## 引入（1 分钟）
先对比第 15 章的 DFS/回溯：DFS 是"选一个方向，一路走到黑，走不通再退回来换方向"——最终能找到一条路径，但**不保证是最短的**（除非把所有路径都试一遍再挑最短，那样效率很低）。BFS 换一种搜索顺序：**先访问离起点 1 步的所有格子，再访问离起点 2 步的所有格子……像水波纹一样一圈圈往外扩**。正因为这个"一圈套一圈"的顺序，BFS 第一次碰到某个格子时，走过的步数**一定**是最短的——不需要比较、不需要回溯，直接就是答案。

## 核心推导（重点，讲透）
BFS 的标准三件套：
1. **队列**：存放"已经发现、还没扩展"的格子，保证"先发现的先扩展"，这正是"一圈圈扩散"的实现方式；
2. **`dist` 数组**：`dist[x][y]` 记录起点到 `(x,y)` 的最短步数，初始值设为 `-1`，同时兼职当"是否访问过"的标记——`dist != -1` 就说明访问过了；
3. **方向数组**：把"上下左右"四个方向的行列偏移量提前存成两个长度为 4 的数组，扩展时用循环遍历，避免写四段重复代码。

流程：起点入队，`dist[起点]=0`；每次从队首取出一个格子，检查它的四个邻居，只要邻居"没出界、不是墙、没访问过"，就把它的 `dist` 设成"当前格子的 dist + 1"，然后入队。重复直到队列空，或者已经扩展到终点。

**为什么第一次到达就是最短**：假设队列里的格子严格按 `dist` 值从小到大排列（BFS 能保证这一点，因为每次只往队尾塞 `dist` 更大 1 的格子），那么终点第一次被放进 `dist` 数组时，赋的值一定是"当前已知的最小可能值"——因为如果有更短的路径，那条路径上的格子会更早出队，终点也会被更早发现。

## 代码逐行讲解
```cpp
while (!q.empty()) {
    auto [cx, cy] = q.front();
    q.pop();
    if (cx == tx && cy == ty) break;   // 提前退出，不是必须，但能省时间
    for (int d = 0; d < 4; d++) {
        int nx = cx + dx[d], ny = cy + dy[d];
        if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
        if (grid[nx][ny] != '.') continue;
        if (dist[nx][ny] != -1) continue;
        dist[nx][ny] = dist[cx][cy] + 1;
        q.push({nx, ny});
    }
}
```
- `dist[nx][ny] != -1` 这行判断非常关键：一个格子只能被"第一次发现它的那条路径"赋值，之后再遇到就跳过——如果没有这行判断，同一个格子可能被反复计算、反复入队，不仅浪费时间，`dist` 值也可能被后来更大的路径错误覆盖（虽然 BFS 的性质保证后来的路径不会更短，但反复入队依然是纯粹的浪费）。

## 易错点
- **千万不要用 DFS/递归实现"求最短路"**：DFS 能找到*一条*路径，但不保证最短；BFS 才有"第一次到达即最短"的性质。
- `dist` 数组要用 `-1` 初始化（用 `memset`），不能用 `0`——如果用 `0` 初始化，会分不清"起点的 dist 就是 0"和"这个格子还没访问过"。
- 数组大小按 `n, m` 最大值 1000 开，别忘了 `+5` 之类的余量，避免越界。
