# 僵尸潮扩散距离（游戏背景） 讲解稿

## 考点
【例4】烂橘子的直接变式：同样是多源 BFS，但要输出"每个格子各自的距离"，而不是"一个整体的最大值"。

## 引入（1 分钟）
换了游戏皮肤，但骨架和例4完全一样：多个刷新点同时出发，做多源 BFS。区别只在"最后要输出什么"——例4只要一个整体答案（全部感染的时间），这题要把**每个格子的答案都输出出来**（离它最近的刷新点有多远）。

## 核心推导（简要，重点在对照）
- 初始化：所有值为 `2` 的刷新点格子，`dist` 设为 `0`，一次性全部入队——和例4一模一样。
- 扩展规则的唯一区别：例4只能往"新鲜橘子"（值为 `1`）扩展；这题反过来，**障碍物（值为 `1`）不能走**，其余格子（`0` 和 `2`）都能扩展。写代码时要格外注意这个符号含义上的"反转"，不要被例4的记忆定式带偏。
- 输出：`dist` 数组算出来之后，直接按行按列输出整个矩阵即可；障碍物格子固定输出 `-1`（不管 BFS 有没有碰过它，因为按规则它从来不会被扩展到，`dist` 本来就会保持 `-1`，但为了代码清晰，输出时可以显式再判断一次）。

## 代码逐行讲解
```cpp
if (grid[nx][ny] == 1) continue;      // 障碍物不能走
```
- 对照例4的 `if (grid[nx][ny] != 1) continue;`（只有新鲜橘子能被感染）——两题的判断条件刚好是"反着写"的，因为两题里数字 `1` 的含义不同（例4的 `1` 是"可以感染的目标"，这题的 `1` 是"不能通过的障碍"）。做完这题建议把两份 `check`/扩展逻辑的代码贴在一起对比读一遍，确认自己分清楚了两题里同一个数字的不同含义。

## 易错点
- 最容易犯的错就是**沿用例4的判断条件**（写成 `!= 1` 而不是 `== 1`），本质原因是数字含义换了但脑子里的"套路"没跟着换——这正是这道"直接变式"题要练的东西：**不能死记代码，要先想清楚题目具体的规则**。
- 输出格式和【例2】马的遍历一样：数据量大（最多 100 万个数），建议用 `printf`。
- 别忘了：刷新点格子本身的距离是 `0`，不是 `-1`——初始化时要正确设置。

## 课堂串讲提示
建议把这题和例4放在同一节课连着讲，讲完例4立刻布置这题当堂练习，趁着思路还热乎的时候练"识别相同框架 + 注意符号反转"，比隔天再讲效果更好。
