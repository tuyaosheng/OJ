# 讲解稿：火柴棒等式（ch10-004）

## 一、题目解读

用 n 根火柴拼形如 `A + B = C` 的等式，A、B、C 是非负整数、A+B=C，拼出所有数字和 `+`、`=` 恰好用完 n 根。问有多少种等式。洛谷 P1149，**枚举法**的经典题。

## 二、思路分析

看似复杂，其实就是"枚举 + 验证"：
- **枚举** A 和 B（两重循环）；
- C 由 A+B 确定（不用枚举第三个）；
- **验证**：A、B、C 三个数用的火柴数，加上 `+`（2 根）和 `=`（2 根），是否恰好等于 n。

枚举范围多大？火柴总数 n ≤ 24，去掉 `+ =` 的 4 根，最多 20 根给数字。一个数字最少 2 根（数字 1），所以数不会太大——枚举 A、B 到 1000 绝对够（保险范围）。总枚举量约 100 万，秒出。

预处理：每个数字 0~9 的火柴数是固定的 `{6,2,5,5,4,5,6,3,7,6}`；写个 `cost(x)` 把 x 拆位累加各位火柴数。

## 三、代码讲解

```cpp
int digit[10] = {6,2,5,5,4,5,6,3,7,6};

int cost(int x)                  // x 需要多少根火柴
{
    if (x == 0) return digit[0];
    int c = 0;
    while (x > 0) { c += digit[x % 10]; x /= 10; }
    return c;
}
...
int total = n - 4;               // 扣掉 + 和 = 的 4 根
for (int a = 0; a <= 1000; a++)
    for (int b = 0; b <= 1000; b++)
    {
        int c = a + b;
        if (cost(a) + cost(b) + cost(c) == total) ans++;
    }
```

- `cost(x)` 拆位求火柴数，注意 x=0 要单独返回 digit[0]（否则 while 不执行返回 0）；
- 只枚举 A、B，C = A+B 自动算出——**利用约束减少枚举维度**是枚举题的关键优化；
- `total = n - 4`：若 n < 4 则 total 为负，不可能有解（代码里判 total ≥ 0）；
- A ≠ B 时 `A+B=C` 和 `B+A=C` 算两个——枚举 a、b 独立遍历，天然分别计入。

## 四、易错点

1. `cost(0)` 处理不当返回 0——0 要用 6 根（digit[0]）。
2. 把 C 也拿去枚举——没必要，C 由 A+B 定，多枚举一维还可能重复。
3. 忘了扣 `+ =` 的 4 根火柴。
4. 枚举上界太小漏解，或太大浪费时间——1000 是稳妥值。

## 五、小结

枚举法三步：定枚举对象、缩枚举范围（用约束减少维度，如 C=A+B）、逐个验证计数。它是最朴素也最万能的算法思想——想不出巧法时，先想暴力枚举能不能过。本题的"预处理火柴数 + 拆位求和"也是常见的辅助技巧。
