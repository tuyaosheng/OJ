# 讲解稿：最大子段和（ch10-002）

## 一、题目解读

给一串可能含负数的整数，求连续一段（至少一个元素）的最大和。这是 DP 思想的启蒙题，用一个 O(n) 的巧妙扫描就能解决。

## 二、思路分析

朴素做法枚举所有区间的起点终点，O(n²) 甚至 O(n³)。n 达 100 万，必须 O(n)。

**关键定义**：设 cur = "以当前元素**结尾**的最大子段和"。当新元素 a[i] 到来，以它结尾的最优子段只有两种可能：
1. 接在前一段后面：`cur + a[i]`；
2. 自己另起一段：`a[i]`（当前面那段是负的、拖后腿时）。

取两者较大：`cur = max(a[i], cur + a[i])`。然后用 cur 更新全局答案 ans。

一句话直觉：**如果前面累积的和是负的，不如丢掉、从当前重新开始**。这就是 Kadane 算法，也是"线性 DP"最简单的形态——每一步的最优只依赖前一步。

## 三、代码讲解

```cpp
long long cur = x, ans = x;      // 用第一个元素初始化
for (int i = 2; i <= n; i++)
{
    cin >> x;
    cur = max(x, cur + x);       // 接着上一段 or 另起一段
    ans = max(ans, cur);         // 更新全局最优
}
cout << ans << endl;
```

- **初值取第一个元素**（不是 0）：题目要求至少选一个，若数组全是负数，答案是最大的那个负数——初值设 0 会错误地输出 0（空段）；
- 每步两句：先更新 cur，再更新 ans；
- long long 防溢出，边读边算省内存（100 万数据不必全存）。

样例 `2 -4 3 -1 2 -4 3`：最优是 `3 + (-1) + 2 = 4`。全负样例 `-1 -2 -3 -4 -5`：答案是 -1（最大的单个元素）。

## 四、易错点

1. ans 初值设 0——全负数据会错误输出 0。必须用第一个元素初始化（保证"至少选一个"）。
2. 只更新 cur 忘了 ans，或反过来——两个都要每步更新。
3. 以为要输出子段本身——本题只要和。
4. 大数据用 int 溢出。

## 五、小结

最大子段和用一个变量 cur 滚动记录"以当前结尾的最优"，O(n) 解决。它的思维——"当前最优由前一步最优推出"——正是**动态规划**的内核。第 19 章会系统学 DP，回头看这题，你会会心一笑。
