# 讲解稿：车厢重组（ch10-006）

## 一、题目解读

n 节车厢（编号是 1..n 的排列），每次只能交换**相邻**两节，问最少交换几次能排成从小到大。课件例 2.2。答案有个漂亮的结论：**等于逆序对的个数**。

## 二、思路分析

**关键结论**：只允许交换相邻元素时，把序列排好序的最少交换次数 = **逆序对个数**。

什么是逆序对？一对位置 (i, j)，满足 i < j 但 a[i] > a[j]——即"前面的比后面的大"，是一处"乱序"。每交换一次相邻元素，恰好消除一个逆序对；要全部排好，就得消除所有逆序对，所以最少次数就是逆序对总数。

这其实就是**冒泡排序会执行的交换次数**——冒泡每次交换相邻的逆序对，总交换数正是逆序对数。

怎么数逆序对？n ≤ 10000，用最直接的 O(n²) 双重循环：对每对 (i, j)，i<j，若 a[i] > a[j] 就计数。n²=10⁸ 在 1 秒内能过。

## 三、代码讲解

```cpp
long long cnt = 0;
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)
        if (a[i] > a[j]) cnt++;      // 前大后小 = 一个逆序对
cout << cnt << endl;
```

- 双重循环枚举所有位置对 (i, j)，i < j；
- `a[i] > a[j]` 即一个逆序对，计数；
- cnt 用 **long long**：逆序对最多 n(n−1)/2 ≈ 5×10⁷，int 勉强够但 long long 更稳。

样例 `4 3 2 1`（完全倒序）：逆序对有 (4,3)(4,2)(4,1)(3,2)(3,1)(2,1) 共 6 个，需 6 次交换。

（进阶：n 若达 10⁵，O(n²) 就慢了，要用归并排序或树状数组在 O(n log n) 内数逆序对——第 12 章"数据排序"会讲。本题 n≤10⁴，暴力足够。）

## 四、易错点

1. 不知道"最少相邻交换 = 逆序对数"这个结论，去真的模拟交换——复杂且易错。
2. cnt 用 int——大数据接近溢出，用 long long。
3. 内层从 `j = i+1` 开始（只数 i 后面的），别重复计数。
4. 误以为要真的把序列排好——只需数逆序对个数。

## 五、小结

"最少相邻交换次数 = 逆序对个数"是一个必记结论，把一道"模拟交换"题变成"计数"题。本章（基础算法概述）到此完整覆盖了枚举、模拟、前缀和、差分几大基础技巧。接下来第二部分会逐个深入：高精度、排序、递推、搜索、贪心、DP……你的算法之旅正式启程。
