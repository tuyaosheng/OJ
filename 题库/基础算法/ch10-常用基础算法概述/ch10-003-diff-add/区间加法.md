# 讲解稿：区间加法（ch10-003）

## 一、题目解读

一个初始全 0 的数组，m 次操作每次把区间 [l, r] 整体加上 v，最后输出数组。这是**差分**的招牌应用——前缀和的"逆运算"，专治"多次区间修改"。

## 二、思路分析

朴素做法：每次操作都循环 l 到 r 逐个加 v，单次 O(区间长)，m 次最坏 O(nm) = 10¹⁰，超时。

**差分**的妙处：维护一个差分数组 d，给区间 [l, r] 加 v 只需**两个端点动手**：

```
d[l] += v;      // 从 l 开始，往后都 +v
d[r+1] -= v;    // 到 r+1 处，把这个 +v 撤销
```

O(1) 完成一次区间修改！所有操作做完后，对 d 求一遍**前缀和**，就还原出每个位置的真实值：`a[i] = d[1] + d[2] + … + d[i]`。

直觉：d[i] 记录"第 i 位相对第 i−1 位的变化量"。在 l 处 +v 表示"从这里开始抬高 v"，在 r+1 处 −v 表示"到这里落回去"，中间的 [l, r] 就恰好都被抬高了 v。前缀和把这些"变化量"累积成"实际值"。

## 三、代码讲解

```cpp
while (m--)
{
    int l, r, v; cin >> l >> r >> v;
    d[l] += v;                   // 差分：O(1) 区间修改
    d[r + 1] -= v;
}
long long cur = 0;
for (int i = 1; i <= n; i++)
{
    cur += d[i];                 // 对差分数组求前缀和 = 还原真实值
    cout << cur << (i < n ? " " : "\n");
}
```

- 修改只碰 `d[l]` 和 `d[r+1]` 两个位置；
- `d[r+1]` 当 r = n 时会用到 d[n+1]，数组要开够（n+2）；
- 最后前缀和还原：cur 累加 d[i] 就是位置 i 的最终值；
- long long 防溢出。

样例：初始 `0 0 0 0 0`，[1,3]+2 → `2 2 2 0 0`，[2,5]+3 → `2 5 5 3 3`。

## 四、易错点

1. 忘了 `d[r+1] -= v`——只加不减，从 l 开始后面全被抬高，右边界失控。
2. 数组开小：d[r+1] 当 r=n 时是 d[n+1]，要开 n+2。
3. 最后忘了求前缀和还原——d 本身不是答案，前缀和之后才是。
4. 暴力逐个加——O(nm) 超时。

## 五、小结

差分与前缀和互为逆运算：**前缀和**擅长"区间查询"，**差分**擅长"区间修改"。差分把每次区间加降到 O(1)，最后一次前缀和还原。它俩是基础算法里最实用的一对搭档，二维版本、树上版本都由此展开。
