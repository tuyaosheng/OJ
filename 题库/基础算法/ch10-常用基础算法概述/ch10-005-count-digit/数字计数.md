# 讲解稿：数字计数（ch10-005）

## 一、题目解读

统计区间 [L, R] 里所有整数写出来时，数字 d 一共出现多少次。例如 1~12 中数字 1 出现 5 次。洛谷 P1980 变形，**枚举 + 拆位**的入门题。

## 二、思路分析

数据范围 R ≤ 10⁶，规模不大，可以最直接地"暴力枚举 + 拆位"：
- **枚举** L 到 R 的每个整数 x；
- **拆位**：反复 `x % 10` 取个位、`x /= 10` 去掉个位，每取到一位就看它是不是 d，是就计数 +1；
- 累加所有数的计数。

R 最大 10⁶，每个数最多 7 位，总操作约 7×10⁶ 次——完全在时间限制内。

（进阶：如果 R 到 10¹²，就要用"数位 DP"按位统计，那是后话；本题范围小，暴力足矣，正好练拆位。）

## 三、代码讲解

```cpp
long long cnt = 0;
for (int x = L; x <= R; x++)
{
    int t = x;
    while (t > 0)                // 拆位
    {
        if (t % 10 == d) cnt++;  // 个位是否等于 d
        t /= 10;                 // 去掉个位
    }
}
cout << cnt << endl;
```

- 拆位是老套路：`% 10` 取末位、`/ 10` 抹末位，循环到 0；
- 用临时变量 t 拆，别毁了循环变量 x；
- cnt 用 long long：区间大、每个数多位，总数可能较大（安全起见）；
- 本题 L ≥ 1，不用处理"数字 0 本身"的特例。

样例 1~12 数字 1：1(1个)、10(1个)、11(2个)、12(1个)，共 5 个。

## 四、易错点

1. 拆位时直接改 x（循环变量）——下次循环就乱了，要用临时变量 t。
2. cnt 用 int——大区间可能溢出，用 long long 保险。
3. 统计数字 0 时若范围含 0 要小心（本题 L≥1，无此坑）。
4. `t % 10 == d` 的 d 是数字（0~9），别和字符混。

## 五、小结

"枚举每个数 + 拆位检查"是处理数位相关问题的最朴素方法，拆位口诀 `%10 取位、/10 去位` 要形成肌肉记忆。数据范围决定能否暴力：本题 10⁶ 可以，更大就得上数位 DP。先把暴力写对，是解题的第一步。
