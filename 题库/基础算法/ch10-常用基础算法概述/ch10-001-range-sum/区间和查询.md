# 讲解稿：区间和查询（ch10-001）

## 一、题目解读

给定数组，q 次询问，每次求区间 [l, r] 的和。这是**前缀和**的招牌应用，也是第二部分"基础算法"的开门第一课——学会用预处理把查询从慢变快。

## 二、思路分析

朴素做法：每次询问都从 l 累加到 r，单次 O(区间长度)，q 次最坏 O(nq)。n、q 都是 10 万，nq = 10¹⁰，必然超时。

**前缀和**的思想是"一次预处理，多次快查"：先算出 `s[i] = a[1] + a[2] + … + a[i]`（前 i 项之和），那么任意区间和：

**a[l..r] = s[r] − s[l−1]**

一次减法就出答案！预处理 O(n)，每次询问 O(1)，总共 O(n + q)，轻松通过。

为什么 `s[r] − s[l−1]`？s[r] 是前 r 项和，s[l−1] 是前 l−1 项和，相减正好剩下第 l 到第 r 项——就像"到 r 站的总路程 减 到 l−1 站的总路程 = 中间这段路程"。

## 三、代码讲解

```cpp
for (int i = 1; i <= n; i++)
{
    cin >> a[i];
    s[i] = s[i - 1] + a[i];      // 前缀和递推，s[0]=0
}
while (q--)
{
    int l, r; cin >> l >> r;
    cout << s[r] - s[l - 1] << "\n";
}
```

- s[0] = 0（全局数组自动为 0），递推 `s[i] = s[i-1] + a[i]`；
- 查询 `s[r] - s[l-1]`——注意是 `l-1` 不是 `l`；
- s 用 **long long**（10 万个 ±1000，和可达 10⁸，虽然 int 勉强够，但前缀和习惯用 long long）；
- `sync_with_stdio(false)` 加速 10 万级读写。

## 四、易错点

1. 写成 `s[r] - s[l]`——少算了第 l 项，差一错误。正确是 `s[l-1]`。
2. 每次询问暴力累加——O(nq) 超时。前缀和的意义就是避免这个。
3. s 用 int 溢出（数据大时）。
4. 忘记 s[0] = 0 的边界（l=1 时要用 s[0]）。

## 五、小结

前缀和 = 预处理一个"累计和数组"，把区间和查询从 O(n) 降到 O(1)。核心公式 `a[l..r] = s[r] - s[l-1]` 必须烂熟。它是最基础也最常用的优化技巧，二维前缀和、树上前缀和都由此拓展。下一题看它的孪生兄弟——差分（区间修改）。
