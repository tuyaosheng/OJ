- **状态**：`dp[i][j]` = 只考虑前 `i` 种花，摆放 `j` 株的方案数。
- **边界**：`dp[0][0] = 1`（前 0 种花，摆 0 株，只有"什么都不摆"这一种方案）；`dp[0][j] = 0`（`j > 0` 时，没有花可摆，不可能摆出正数株）。
- **转移**：第 `i` 种花这一株到底摆几株，是 `0` 到 `a[i]` 之间的一个选择，把每种选择的方案数**加起来**：
  ```
  dp[i][j] = sum(dp[i-1][j-k])，其中 k 从 0 到 min(a[i], j)
  ```
  意思是"第 `i` 种花摆 `k` 株，剩下的 `j-k` 株由前 `i-1` 种花摆出来，两者方案数相乘（这里第 `i` 种花摆 `k` 株只有 1 种选法，所以直接是 `dp[i-1][j-k]`），再对所有可能的 `k` 求和"。
- **答案**：`dp[n][m]`。
- 别忘了**每一步加法都要取模**，不要只在最后输出时取模一次——中间结果虽然本题不会真正溢出 `long long`，但取模是处理"方案数对某个数取模"这类问题的标准习惯，务必养成。
