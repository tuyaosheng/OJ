# 数字三角形 讲解稿

## 考点
动态规划入门：DP 三要素（状态、转移、边界）的第一次完整示范。

## 引入（1 分钟）
先问学生：这题能不能用第 15 章学的 DFS/回溯做？——能，把每一种走法都搜一遍，取最大值。但一算复杂度就会发现问题：每一步有 2 种选择，`n` 层总共 `2^(n-1)` 种走法，`n=1000` 时这个数大到无法想象，肯定超时。

那问题出在哪？画一下递归树就会发现：**很多路径会经过同一个格子**——比如从顶点出发，走"左左右"和"右左左"这两条不同的路径，可能会在中间某一步汇合到同一个格子，之后的走法完全一样，但 DFS 会把"从这个格子往后走"的所有可能性**重复计算好几遍**。这就是动态规划要解决的问题：**如果子问题会被重复用到，就把它的答案存下来，下次直接查，不再重新算**。

## 核心推导（重点，讲透）
DP 三要素，逐个讲清楚：

1. **状态**：`dp[i][j]` 表示"从第 `i` 行第 `j` 个数字出发，一路走到最后一行，能拿到的最大数字和"。想清楚状态是这道题最关键的一步——状态想对了，转移和边界基本是水到渠成的。
2. **边界**：最后一行（第 `n` 行）没有"下一步"可走，`dp[n][j]` 就是它自己的数字——这是递推的起点，不能再往下拆。
3. **转移**：`dp[i][j] = a[i][j] + max(dp[i+1][j], dp[i+1][j+1])`——从 `(i,j)` 出发，下一步只能走到 `(i+1,j)` 或 `(i+1,j+1)`，选后续能拿到更多和的那一个，加上当前格子的数字。

**为什么这样就不会重复计算**：`dp[i+1][j]` 这个值，不管它会被多少个不同的"上一步"用到（`(i,j)` 和 `(i,j-1)` 都可能走到 `(i+1,j)`），都只计算一次、存进数组，后面所有需要它的地方直接查表。这正是 DP 相比暴力 DFS 的本质区别。

**为什么选"从下往上"而不是"从上往下"**：如果按题目描述的方向"从上往下"定义状态（`dp[i][j]` = 从顶点走到 `(i,j)` 的最大和），转移时要看"上一行有没有第 `j-1` 列、有没有第 `j` 列"，边界情况稍微绕一点（第一列和最后一列各自缺少一个来源）。"从下往上"定义状态，转移时永远是"下一行的第 `j` 列和第 `j+1` 列"，下一行永远比当前行多一个数字，不会越界，代码更简洁——这提醒我们，**同一个状态可以选不同的"方向"来递推，选一个让转移最简单的方向**。

## 代码逐行讲解
```cpp
for (int j = 1; j <= n; j++) dp[n][j] = a[n][j];   // 边界：最后一行

for (int i = n - 1; i >= 1; i--) {
    for (int j = 1; j <= i; j++) {
        dp[i][j] = a[i][j] + std::max(dp[i + 1][j], dp[i + 1][j + 1]);
    }
}
```
- 外层循环 `i` 从 `n-1` 递减到 `1`，保证算 `dp[i][...]` 之前，`dp[i+1][...]` 已经全部算好了——这是"从下往上"递推顺序的直接体现。

## 易错点
- 数组开小了：`n` 最大 1000，`dp`、`a` 数组至少要开 `1005×1005`。
- 忘记倒着递推，写成从上往下扫描却用了"从下往上"的转移公式，会用到还没算出来的 `dp` 值（这是初学 DP 最常见的顺序错误）。
- 虽然本题数据范围内 `int` 不会溢出（最大和约 `10^7`），但用 `long long` 是更保险的习惯。

## 课堂串讲提示
