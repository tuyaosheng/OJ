# 最长上升子序列 讲解稿

## 考点
序列型 DP 的经典状态设计：状态描述的是"以某个位置结尾"，而不是"前多少个数里"。

## 引入（1 分钟）
先让学生尝试直接定义 `dp[i]` = "前 `i` 个数里的最长上升子序列长度"，然后现场推导会发现推不出转移方程——因为"前 `i` 个数的最长上升子序列"不一定包含第 `i` 个数，不知道该拿它和谁比较大小。这个"卡住"的过程很重要：它说明**状态定义得不好，会导致转移写不出来**，这时候要换一种定义方式。

## 核心推导（重点，讲透）
换成 `dp[i]` = "**以第 `i` 个数结尾**的最长上升子序列长度"——多了"结尾是谁"这个限定，转移一下子就清晰了：

- **边界**：`dp[i]` 至少是 `1`（只选 `a[i]` 自己，长度为 1）。
- **转移**：枚举 `i` 前面的每个位置 `j`，如果 `a[j] < a[i]`，说明 `a[i]` 可以接在"以 `a[j]` 结尾的上升子序列"后面，此时 `dp[i]` 可以更新为 `dp[j] + 1`；对所有满足条件的 `j` 取最大值。
- **答案**：不是 `dp[n]`，因为最长的上升子序列不一定以最后一个数结尾——要在**所有** `dp[i]` 里取最大值。

这里体现了状态设计的一个重要原则：**当"前 i 个里最优"推不出转移时，试试"以第 i 个结尾"这种更具体的状态**——具体到"结尾是谁"，才能明确知道下一个数能不能接上去。

## 代码逐行讲解
```cpp
for (int i = 1; i <= n; i++) {
    dp[i] = 1;
    for (int j = 1; j < i; j++) {
        if (a[j] < a[i]) dp[i] = std::max(dp[i], dp[j] + 1);
    }
    ans = std::max(ans, dp[i]);
}
```
- 双重循环，外层枚举"当前要计算哪个位置的 dp"，内层枚举"它前面所有可能的上一个位置"——`O(n^2)`，`n=5000` 时是 `2.5×10^7` 次比较，1 秒内能跑完。

## 易错点
- **别忘了取所有 `dp[i]` 的最大值**：直接输出 `dp[n]` 是最常见的错误，只有当序列本身就是完全递增时才恰好正确。
- "严格递增"是重点：`a[j] < a[i]` 不能写成 `<=`，否则相等的数会被错误地接上去。
- 这题存在更快的 `O(n log n)` 解法（用"贪心+二分"维护一个数组），本题的数据范围 `n≤5000` 是为了让 `O(n^2)` 的写法也能通过，重点是先掌握 DP 的状态设计思路；`O(n log n)` 的写法作为进阶技巧，有兴趣的同学可以课后自己查一查"patience sorting"。

## 课堂串讲提示
这题和前两题相比，状态设计的抽象程度明显提高了一步——前两题的状态都能直接对应到"走到哪个格子"，这题的状态要多想一层"以谁结尾"。可以提醒学生：**状态设计没有固定公式，多做几道类似的题，才能培养出直觉**。
