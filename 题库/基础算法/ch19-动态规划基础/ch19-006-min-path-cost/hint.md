- 和【例2】过河卒对照：那题的"马控制点"变成了这题的"障碍物"，处理方式一样——障碍格子的 `dp` 值不参与转移（相当于"走不到那里"）；那题转移是"把两个方向的方案数**相加**"，这题转移是"取两个方向里**更小**的那个代价再加上当前格子代价"。
- **状态**：`dp[i][j]` = 从起点走到 `(i,j)` 的最小代价（`dp[i][j]` 不存在/走不到时，可以用一个很大的数表示"不可达"）。
- **边界**：`dp[1][1] = a[1][1]`。
- **转移**：`dp[i][j] = a[i][j] + min(dp[i-1][j], dp[i][j-1])`（如果两个方向都走不到，`dp[i][j]` 也保持"不可达"）；障碍格子直接跳过，不设置 `dp` 值。
- **答案**：如果 `dp[n][m]` 仍是"不可达"的初始值，输出 `-1`；否则输出 `dp[n][m]`。
