**选择排序的写法**

```cpp
for (int i = 0; i < n - 1; i++)      // 依次确定第 i 个位置该放谁
{
    int minIdx = i;                  // 假设 i 位置上的数就是最小的

    for (int j = i + 1; j < n; j++)  // 到后面找找看有没有更小的
        if (a[j] < a[minIdx])
            minIdx = j;              // 记住更小的那个的位置

    swap(a[i], a[minIdx]);           // 把找到的最小数换到 i 位置
}
```

**要点**：
- 外层循环只需到 `n - 1`——因为前 n−1 个位置都确定后，最后一个位置自然就是剩下的那个最大数。
- 内层要记的是**下标** `minIdx`，不是值，这样才能 `swap`。
- 交换用 `swap(a[i], a[minIdx])`（需要 `#include <algorithm>`）。

**复杂度**：两重循环，约 n²/2 次比较，即 **O(n²)**。n = 2000 时约 200 万次，很快。但如果 n = 10 万，就是 50 亿次——必然超时。这正是下一题要解决的问题。

**输出格式**：注意行末不要多打空格。可以这样写：
```cpp
for (int i = 0; i < n; i++)
    cout << a[i] << (i == n - 1 ? "\n" : " ");
```
