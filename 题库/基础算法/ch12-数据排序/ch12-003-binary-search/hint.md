**第一步：排序**

二分查找有一个**铁律前提**——数据必须**有序**。所以先 `sort(a, a + n)`。

**第二步：二分查找"第一次出现的位置"**

注意题目要的不是"随便找到一个 x"，而是**第一次出现**的位置（因为可能有重复）。这类问题叫**二分下界**（lower_bound）。

**方法一：手写二分**

```cpp
int l = 0, r = n - 1, pos = -1;

while (l <= r)
{
    int mid = l + (r - l) / 2;      // 防溢出的写法

    if (a[mid] >= x)                // mid 处的数 >= x，答案可能是 mid 或更左边
    {
        if (a[mid] == x) pos = mid; // 找到了，但左边可能还有，继续往左找
        r = mid - 1;
    }
    else                            // a[mid] < x，答案只可能在右边
    {
        l = mid + 1;
    }
}

// pos 就是第一次出现的下标（-1 表示没找到）；输出时记得 +1 变成 1-based
```

**方法二：直接用 STL（推荐）**

C++ 标准库已经准备好了：

```cpp
int pos = lower_bound(a, a + n, x) - a;   // 第一个 >= x 的位置

if (pos < n && a[pos] == x)
    cout << pos + 1 << "\n";     // 找到了，转成 1-based
else
    cout << -1 << "\n";          // 没找到
```

`lower_bound` 返回**第一个大于等于 x 的元素**的迭代器（这里是指针），减去数组首地址就得到下标。**必须再检查一次 `a[pos] == x`**——因为 lower_bound 只保证"≥ x"，可能返回一个比 x 大的数的位置。

**易错点**：
- 忘了先排序 —— 二分的结果就是错的（而且不会报错，很难查！）
- 忘了 `pos < n` 的越界检查 —— x 比所有数都大时，pos 会等于 n。
- 忘了把 0-based 下标转成 1-based 位置（+1）。
- 10 万级读写，记得 `ios::sync_with_stdio(false)`。
