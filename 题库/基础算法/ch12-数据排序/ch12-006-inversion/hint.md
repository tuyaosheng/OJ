**归并排序回顾**

归并排序也是分治：把数组从中间劈成两半 → 递归排好左右两半 → 把两个**有序**的半边**合并**成一个有序数组。

合并时用两个指针 i、j 分别指向左右两半的开头，每次取较小的那个放进结果里。

**关键洞察：在"合并"这一步数逆序对**

假设左半边是 `L`（已排好序），右半边是 `R`（已排好序）。现在合并：

- 如果 `L[i] <= R[j]`，取 L[i]，**不产生逆序对**（L[i] 不比 R 里剩下的任何数大）。
- 如果 **`L[i] > R[j]`**，取 R[j]。此时——**L[i] 以及它后面的所有元素，都比 R[j] 大！**

  因为 L 是**有序**的，L[i] > R[j] 意味着 `L[i], L[i+1], …, L[mid]` 全都 > R[j]。而它们的下标都**小于** R[j] 的下标（左半边在前）。

  所以这一步一口气产生了 **`mid - i + 1`** 个逆序对！

```cpp
if (a[i] <= a[j])
    tmp[k++] = a[i++];
else
{
    tmp[k++] = a[j++];
    ans += mid - i + 1;      // 关键！左边剩下的所有数都与 a[j] 构成逆序对
}
```

**为什么这样不重不漏？** 归并排序的递归结构保证了：每一对 (i, j) 恰好在**唯一一次**合并中被"跨越"统计到——要么 i、j 在同一半边（由递归处理），要么分属左右两半（由这次合并统计）。

**必须注意的细节**：

1. **`ans` 必须是 `long long`**！最坏情况（完全逆序）有 `n(n-1)/2 ≈ 50 亿` 个逆序对。
2. **相等时不算逆序对**（定义是严格 `a[i] > a[j]`），所以合并时的判断要写 `a[i] <= a[j]` 取左边——**如果写成 `<` 就会把相等的也算进去，答案偏大**。
3. 需要一个**临时数组** `tmp` 存放合并结果，别在原地乱改。

**复杂度**：O(n log n)，和归并排序一样。

**（拓展）** 逆序对也可以用**树状数组**求解，那是更进阶的做法，以后学到数据结构时会再见到它。
