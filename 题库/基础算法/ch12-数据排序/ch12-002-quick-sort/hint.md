**方法一：直接用 `sort`（推荐）**

```cpp
#include <algorithm>
sort(a, a + n);          // 把 a[0] 到 a[n-1] 从小到大排序
```

就这么简单。`sort` 是 C++ 标准库提供的排序函数，复杂度 O(n log n)，经过高度优化，比你自己写的快排还快。**竞赛中请优先使用它。**

**方法二：手写快速排序（理解原理）**

快排的核心思想是**分治**——把大问题拆成小问题：

1. **选基准**：从数组里随便挑一个数当"基准"（pivot），比如取中间那个。
2. **分区**：把**比基准小**的都扔到左边，**比基准大**的都扔到右边。这样基准就到了它最终该在的位置。
3. **递归**：对左半边和右半边，分别重复上述过程。

```cpp
void quickSort(int l, int r)
{
    if (l >= r) return;              // 只剩 0 或 1 个数，无需排序

    int pivot = a[(l + r) / 2];      // 取中间的数作基准
    int i = l, j = r;

    while (i <= j)
    {
        while (a[i] < pivot) i++;    // 从左找一个 >= 基准的
        while (a[j] > pivot) j--;    // 从右找一个 <= 基准的
        if (i <= j)
        {
            swap(a[i], a[j]);        // 交换，让小的去左边、大的去右边
            i++; j--;
        }
    }

    quickSort(l, j);                 // 递归排左半边
    quickSort(i, r);                 // 递归排右半边
}
```

**复杂度**：平均 O(n log n)。100000 × 17 ≈ 170 万次，非常快。

**性能提示**：n = 10 万时读写量较大，记得加上 `ios::sync_with_stdio(false);` 关闭 C++ 与 C 的输入输出同步，能显著提速。
