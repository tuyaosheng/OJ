# 归并排序求逆序对 讲解稿

## 考点
分治算法的经典范式：真正的"把数据切两半，分别处理，再合并"。

## 引入（1 分钟）
先复习：排序有很多种写法（冒泡、选择、插入……），它们大多是 `O(n^2)`。归并排序能做到 `O(n log n)`，靠的就是分治。

## 核心推导（重点，讲透）
归并排序的三步，和上一题（快速幂）对照着讲：
- **分**：把长度为 `n` 的数组从中点切成两半 `[l, mid]` 和 `[mid+1, r]`——这次是真的把**数据**切开，不是抽象的"规模"。
- **治**：递归地把左右两半分别排好序。递归到区间只剩 1 个数时，天然有序，是递归终止条件。
- **合**：两个**已经各自有序**的子数组，用"双指针"从头开始比较，谁小就先取谁，一趟扫描就能合并成一个有序数组，这一步是 `O(n)` 的。

为什么整体是 `O(n log n)`：一共要"切"`log n` 层，每一层所有子区间的"合"加起来都是 `O(n)`，`层数 × 每层代价 = O(n log n)`。

**逆序对怎么顺便求出来**：合并两个有序区间 `[l, mid]` 和 `[mid+1, r]` 时，双指针 `i`（指向左边）、`j`（指向右边）：
- 如果 `a[i] <= a[j]`，说明不构成逆序，正常放入结果，`i++`；
- 如果 `a[i] > a[j]`，因为左边 `[i, mid]` 已经是有序的，`a[i]` 到 `a[mid]` 这一整段都 `>= a[i] > a[j]`，也就是说，**这一整段都能和 `a[j]` 构成逆序对**，一次性累加 `mid - i + 1` 个，不用一个个数，这正是分治"借助子问题已经有序"这个性质省下来的时间。

## 代码逐行讲解
```cpp
void merge(int l, int mid, int r) {
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) {
            tmp[k++] = a[i++];
        } else {
            invCount += (mid - i + 1);  // 这一步是本题比普通归并排序多出来的
            tmp[k++] = a[j++];
        }
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (int t = l; t <= r; t++) a[t] = tmp[t];
}
```
- 归并排序本身不需要求逆序对，去掉 `invCount += ...` 那一行，就是最普通的归并排序模板，可以强调"这题就是模板 + 一行统计"。
- 最后要把 `tmp` 里排好的结果拷回 `a`，否则上一层递归拿到的还是没排序的数据。

## 易错点
- `invCount` 必须是 `long long`：`n = 10^5` 时逆序对最多接近 `n(n-1)/2 ≈ 5×10^9`，超出 `int` 范围。
- `a[i] <= a[j]` 要用 `<=` 不是 `<`：相等的两个数不构成逆序对（题目要求严格 `a[i] > a[j]`），如果误用 `<`，遇到大量重复数据时结果会偏大。
- 递归写成 `mergeSort(l, r)` 时终止条件是 `l >= r`（区间只剩 0 或 1 个数），写成 `l == r` 在某些调用方式下可能漏掉空区间，养成写 `>=` 的习惯更保险。
