## 题目描述

**归并排序**是分治思想最经典的应用：把长度为 `n` 的数组从中点切成两半，分别递归排好序（"分"+"治"），再把两个有序的子数组合并成一个有序数组（"合"）。

现在给你一个长度为 `n` 的整数序列 `a[1..n]`，请你计算它的**逆序对个数**——即满足

```
i < j 且 a[i] > a[j]
```

的下标对 `(i, j)` 的个数。

直接枚举所有 `(i, j)` 需要 `O(n^2)`，当 `n` 较大时会超时。但如果借助归并排序的"合并"步骤，就可以顺便统计出逆序对：合并两个已经各自有序的子数组时，如果左边当前数 `a[i]` 比右边当前数 `a[j]` 大，那么左边从 `i` 到左半部分末尾的所有数，都会比 `a[j]` 大，一次性就能统计出一批逆序对，整体只需要 `O(n log n)`。
