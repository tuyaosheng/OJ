- 答案 `mid`（允许的最大段和）越大，越容易分出更少的段——这个**单调性**是二分答案的前提。
- 二分范围：下界 `L = max(a[i])`（段和不可能比数组里最大的一个数还小，否则装不下它），上界 `R = sum(a[i])`（干脆全放一段）。
- 判定函数 `check(mid)`：贪心地从左到右扫描，用一个累加器尽量往当前段里塞数，一旦加上下一个数就会超过 `mid`，就新开一段；扫完统计一共用了多少段，若段数 `≤ m` 说明 `mid` 可行。
- 二分答案模板：`while (L < R) { mid = (L + R) / 2; if (check(mid)) R = mid; else L = mid + 1; }`，最终 `L` 就是答案。
