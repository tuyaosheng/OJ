# 数列分段（最大值最小化） 讲解稿

## 考点
二分答案：分治思想的另一种应用——不切数据，而是切"答案的取值范围"。

## 引入（1 分钟）
问学生：如果题目问的不是"求出具体方案"，而是"求某个最优值是多少"，能不能不去想方案，而是**猜答案、验证答案**？——这就是二分答案的思路。

## 核心推导（重点，讲透）
- 二分答案能用的前提是**单调性**：设"允许的最大段和"为 `x`，`x` 越大，需要的段数就越少（或不变）——这是单调不增的关系。有了这个单调性，才能用二分去逼近临界点。
- 二分的本质也是分治："分"是把答案的可能区间 `[L, R]` 从中点切开；"治"是通过 `check(mid)` 判断 `mid` 是否可行；"合"是根据 `check` 的结果，扔掉一半区间，保留可能包含答案的那一半，不断重复直到区间收缩为一个点。
- `check(limit)` 怎么写：贪心地从左到右扫描，用一个累加器 `cur` 尽量往当前段里塞数，一旦 `cur + a[i] > limit`（再塞就超了），就新开一段，`segments++`，`cur` 重新从 `a[i]`开始累加。扫完统计一共用了几段，`segments <= m` 就说明 `limit` 可行。
- 二分范围：下界 `L = max(a[i])`（`limit` 不可能比数组里最大的一个数还小，否则那个数自己都装不进任何一段）；上界 `R = sum(a[i])`（干脆全部塞进一段，段数为 1，一定可行）。

## 代码逐行讲解
```cpp
ll L = maxA, R = sum;
while (L < R) {
    ll mid = L + (R - L) / 2;
    if (check(mid)) {
        R = mid;       // mid 可行，答案可能更小，收缩到左半区间（含 mid）
    } else {
        L = mid + 1;   // mid 不可行，答案一定更大，收缩到右半区间
    }
}
```
- 这是"求最小可行值"的二分答案标准写法：`check` 为真就把右边界收缩到 `mid`（因为 `mid` 本身可能就是答案），`check` 为假就把左边界收缩到 `mid + 1`（`mid` 肯定不是答案）。
- 循环结束时 `L == R`，就是最小的可行值。

## 易错点
- `mid` 的写法要用 `L + (R - L) / 2` 而不是 `(L + R) / 2`，虽然本题数据范围内两者结果一样，但前者能避免 `L + R` 溢出的隐患，是更安全的习惯写法。
- 段和累加、`sum`、二分边界都要用 `long long`：`n = 10^5` 个 `10^9` 级别的数相加，总和可达 `10^14`，远超 `int` 范围。
- `check` 函数里，是"再加就超"才新开一段，不是"加完再判断超没超"——如果写错成先加后判断再回退，逻辑会更绕且容易出 bug，按题解的写法（先判断要不要新开段，再决定加到哪一段）更清晰。

## 课堂串讲提示
