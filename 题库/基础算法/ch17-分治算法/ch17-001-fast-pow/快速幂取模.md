# 快速幂取模 讲解稿

## 考点
分治算法入门：把"求 a^b"这个大问题，通过指数减半拆成规模更小的同类子问题。

## 引入（1 分钟）
先问学生：直接写 `for` 循环累乘 b 次求 a^b，当 b = 10^9 时会怎样？——超时。10 亿次乘法，肯定跑不完。那有没有办法不用乘 b 次就能算出来？

## 核心推导（重点，讲透）
关键观察：
- `a^10 = a^5 * a^5`——只要算出 `a^5`，平方一下就是 `a^10`。指数从 10 降到 5，直接**减半**。
- 一般地：`b` 为偶数时，`a^b = (a^(b/2))^2`；`b` 为奇数时，`a^b = (a^((b-1)/2))^2 * a`。

这就是分治的"分-治-合"：
- **分**：把"求 a^b"变成"求 a^(b/2)"，问题规模减半；
- **治**：递归地把子问题也这样拆下去，直到 `b = 0`（此时 `a^0 = 1`，是最简单的情况，不用再拆）；
- **合**：子问题算出来后，平方就是原问题的答案（奇数再补乘一次 a）。

每拆一次指数减半，最多拆 `log2(10^9) ≈ 30` 次，所以只需要约 30 次乘法，而不是 10 亿次。这是分治"用空间换时间、用递归换效率"的典型例子——**不是把数据分成两半，而是把问题的"规模"（这里是指数）分成两半**，比后面要学的归并排序更抽象一点，适合作为分治的第一课，因为过程只有一条链，没有"左右分叉再合并"的负担，学生更容易接受。

## 代码逐行讲解
```cpp
ll fastPow(ll a, ll b, ll p) {
    if (b == 0) return 1 % p;           // 递归终止条件
    ll half = fastPow(a, b / 2, p);     // 子问题：规模减半
    ll result = half * half % p;        // 合并：平方
    if (b % 2 == 1) result = result * (a % p) % p;
    return result;
}
```
- 递归三要素在这里体现得非常干净：终止条件（`b==0`）、子问题（`b/2`）、合并（平方 + 奇偶修正）。
- 取模的位置：每一步乘法后都立刻取模，避免 `long long` 溢出（`a, p < 10^9`，两数相乘 < 10^18，在 `long long` 范围内是安全的，但如果不及时取模，累积下去的中间结果会越滚越大直到真正溢出）。

## 易错点
- `0^0` 按约定算 1，代码里 `b==0` 时直接返回 `1 % p`，天然满足这个约定，不需要特判 `a==0`。
- `p == 1` 时任何数取模都是 0，代码不需要特判，`1 % p` 自然是 0。
- 千万别忘了先把输入的 `a` 对 `p` 取模（`a %= p`），否则第一次乘法就可能溢出（虽然本题数据范围内不会溢出，但这是好习惯，数据范围一旦放大到 `10^18` 级别就会出问题）。

## 课堂串讲提示
讲完这题后，可以顺势引出"分治的本质是把问题拆小，而不一定是把数据拆两半"——为后面的归并排序（真正的"数据拆两半"）做铺垫。
