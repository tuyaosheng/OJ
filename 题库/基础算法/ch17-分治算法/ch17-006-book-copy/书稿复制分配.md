# 书稿复制分配 讲解稿

## 考点
二分答案·最小化最大值——【例3】数列分段的直接变式，换个应用场景再练一遍。

## 引入（1 分钟）
直接点破：这题和例3"数列分段"是**同一个数学模型**，只是把"分成不超过 m 段"换成了"分给不超过 m 个抄写员"。讲这道题的重点不是讲新算法，而是训练学生**识别模型**的能力——很多题目换个马甲，本质是同一道题。

## 核心推导（简要，重点在对照）
- 单调性：设"人均页数上限"为 `x`，`x` 越大，需要的抄写员越少——和例3完全一致。
- `check(limit)`：从头到尾贪心地给当前抄写员分配书，装不下就换下一个人，统计一共需要几个人，`≤ m` 就说明 `limit` 可行。
- 二分范围：下界 `L = max(a[i])`（页数最多的那本书，无论如何都得有一个人单独扛得动它），上界 `R = sum(a[i])`（一个人抄完所有书）。

## 代码逐行讲解
和例3的代码对照着看（把 `segments`/段和 换成 `copiers`/页数即可）：
```cpp
bool check(ll limit) {
    int copiers = 1;
    ll cur = 0;
    for (int i = 1; i <= n; i++) {
        if (cur + a[i] > limit) {
            copiers++;
            cur = a[i];
        } else {
            cur += a[i];
        }
    }
    return copiers <= m;
}
```
- 除了变量名，这段代码和例3的 `check` 函数逻辑完全一样——这不是偷懒，而是刻意设计：**做完这题之后，把两份代码贴在一起对比读一遍**，能帮学生确认自己是不是真的抓住了"二分答案 + 贪心判定"这套组合拳的本质，而不是记住了一道题的具体代码。

## 易错点
- 和例3一样：`L`、`R`、`sum`、`mid` 都要用 `long long`。
- "每个抄写员负责连续的若干本书（可以 0 本）"这句话是关键——意味着"不超过 m 组"而不是"恰好 m 组"，如果理解成"恰好"，`check` 函数的逻辑需要额外处理"用满 m 人"的约束，会更复杂（本题不要求做这个变化，但可以作为思考题留给学有余力的学生）。

## 课堂串讲提示
建议用这道题收尾"二分答案"这个小节：先讲例3建立模型，再讲练1（游戏背景）体会"方向相反"，最后用这道题确认"模型的识别能力"——三道题分别对应"学会一个模型、理解它的对偶、迁移到新场景"，是完整的一套教学闭环。
