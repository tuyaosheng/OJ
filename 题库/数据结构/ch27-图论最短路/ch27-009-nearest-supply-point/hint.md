不需要真的在数组里创建"第 $0$ 号点"再连边——一个更简单的实现方式：既然虚拟源点到每个补给点的边权都是 $0$，直接把**所有补给点的初始距离设成 $0$，一起扔进堆里作为起点**即可，效果完全一样：

```cpp
priority_queue<pli, vector<pli>, greater<pli>> pq;
for (int i = 1; i <= n; i++) dist_[i] = INF;
for (每个补给点 p) {
    dist_[p] = 0;
    pq.push({0, p});
}
// 剩下和普通 Dijkstra 完全一样，从堆里不断弹出、松弛
```

这个"多个点同时作为距离 $0$ 的起点压入堆"的写法，本质上就是虚拟源点技巧的简化实现——省去了真正建一个新节点、连一堆权值为 0 的边的麻烦，效果完全等价。

注意本题的边是**无向**边，读入时要把每条边加进两个方向的邻接表。
