Dijkstra 求的是"单源"最短路——固定一个起点，求它到所有点的最短距离。如果需要**任意两点之间**的最短距离（"多源"最短路），当然可以对每个点都跑一次 Dijkstra，但更简单的做法是用 **Floyd 算法**，代码只有三重循环。

**Floyd 的核心思想**：设 `dist[i][j]` 表示"目前已知的 $i$ 到 $j$ 的最短距离"，初始时 `dist[i][j]` 就是原图中 $i$ 到 $j$ 的直接边权（没有边则是无穷大），`dist[i][i] = 0`。然后依次枚举每一个点 $k$ 作为"中转点"，对所有点对 $(i, j)$ 检查：**能不能通过 $k$ 中转，让 $i$ 到 $j$ 更近**？

```cpp
for (int k = 1; k <= n; k++)
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
```

**为什么 $k$ 必须放在最外层？** 因为处理到"允许中转点编号 $\le k$"这一阶段时，`dist[i][k]` 和 `dist[k][j]` 必须是"只允许中转点编号 $\le k-1$"阶段就已经算好的最终结果，才能保证转移的正确性。如果 $k$ 放在内层，`dist[i][k]` 可能还没被这一阶段更新完全，转移就会出错。
