对每个节点定义一个"单边贡献值" `gain(node)`：从 `node` 出发、只能往一个方向（要么不往下走，要么往左子树走，要么往右子树走，二选一）能延伸出的最大路径和。这是因为如果这个节点要"继续向上、参与父节点的路径"，它自己只能贡献一条链，不能同时往左又往右（那样就在这个节点"拐了弯"，没法再往上延伸）。

```cpp
long long best = LLONG_MIN;  // 全局变量，记录答案

long long gain(Node* node) {
    if (!node) return 0;
    long long l = max(0LL, gain(node->left));   // 左边贡献为负就不要（相当于不往左走）
    long long r = max(0LL, gain(node->right));  // 右边同理
    best = max(best, (long long)node->val + l + r);  // 以 node 为"拐弯点"的路径和，更新答案
    return node->val + max(l, r);  // 但往上返回时只能选一边（不能拐弯）
}
```

关键点：`best` 在每个节点处考虑"以这个节点为路径最高点、左右都利用上"的情况（也就是可能发生拐弯的路径），但函数的**返回值**只能是"往一个方向延伸"的贡献，因为返回值是要交给父节点用的——父节点如果也想利用这个子树，只能顺着一条链往下走，不能既往左子树又往右子树（那样父节点也变成了拐弯点，会重复计算，而且不再是一条合法路径）。
