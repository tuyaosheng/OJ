《崩坏：星穹铁道》里，角色触发"连携技"时，游戏后台会记录一段连招脚本：先是一个个角色的基础技能伤害数字，再用运算符把它们组合起来结算成最终伤害——`+` 表示两段伤害**叠加**（比如普攻和追加攻击各打一次），`*` 表示对一段伤害做**倍率连乘**（比如"弱点击破"触发双倍伤害、或者"击破特攻"加成）。

这次不像本章第一题那样直接给出树的形状，而是给出一个**前缀表达式**（运算符写在前面，两个操作数写在后面，例如 `+ 3 4` 表示 `3 + 4`），你需要先把它**建成一棵表达式树**：每个叶子节点是一个具体的伤害数字，每个内部节点是一个运算符，它的左右孩子分别是这个运算符作用的两段子表达式。建好树以后，对这棵树做一次递归遍历（先算出左右子树的值，再和当前节点的运算符结合），就能算出最终结算伤害。

例如脚本 `* + 3 5 2` 表示 `(3 + 5) * 2`，建出的表达式树是：

```
      *
     / \
    +   2
   / \
  3   5
```

结算结果是 `(3 + 5) * 2 = 16`。

> 这道题和本章开头学的"由数字序列建树"不太一样——你需要**边读 token 边递归建树**：读到数字就是叶子，读到运算符就新建一个内部节点，并且**递归地**去读它的左孩子和右孩子（因为前缀表达式的写法本身就保证了"运算符后面紧跟着的一段 token 恰好构成它的左操作数"）。这也是"数据结构·栈"那一章里"逆波兰表达式求值"的另一种做法——那道题是**不建树**、直接用一个栈边扫描边计算；这道题**显式建出树**之后再递归求值，两种做法殊途同归，但体现的是"用栈模拟计算过程"和"先建结构、再对结构做递归"两种完全不同的编程思路。
