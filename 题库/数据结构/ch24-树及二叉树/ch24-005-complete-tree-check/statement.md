**完全二叉树**是指：除了最后一层，其余每一层的节点都是"满"的（左右孩子都存在）；最后一层的节点可以不满，但必须**从左往右连续排列**，不能中间有空位。

例如下面这棵树是完全二叉树（最后一层只有 4、5、6 三个节点，但它们从左到右紧挨着排列，没有跳过任何位置）：

```
        1
       / \
      2   3
     / \  /
    4  5 6
```

而下面这棵树**不是**完全二叉树（节点 2 没有右孩子，但节点 3 却有左孩子，说明最后一层出现了"跳过空位"的情况）：

```
        1
       / \
      2   3
     /    /
    4    5
```

依然用本章统一的扩展先序序列建树，判断给出的二叉树是否是完全二叉树。
