用一个全局下标 `pos` 记录当前读到扩展先序序列的第几个数，写一个递归函数 `build()`：

```cpp
int a[200005];
int pos = 0;

Node* build() {
    int v = a[pos++];
    if (v == -1) return nullptr;
    Node* root = new Node{v, nullptr, nullptr};
    root->left = build();
    root->right = build();
    return root;
}
```

每次调用 `build()` 会消耗掉当前及后续若干个数，自动把子树建好并返回子树根指针——这正是"先序"的顺序（先处理根，再递归左子树，再递归右子树）。

建好树后，中序遍历和后序遍历都是标准的递归遍历模板，注意用递归而不是自己维护栈，代码会简洁很多。

节点数最多 $10^5$，递归深度在树严重偏斜（比如所有节点都在一条链上）时可能达到 $10^5$ 层，普通递归通常也能通过，但如果担心栈溢出，可以把系统栈开大或改用手写栈迭代实现。
