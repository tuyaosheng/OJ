从本章开始，我们学习一种新的数据结构——**树**，重点是最简单也最常用的**二叉树**（每个节点最多有两个孩子，分别叫左孩子和右孩子）。

二叉树在程序里最自然的存储方式是**链式结构**：每个节点保存自己的值，以及指向左孩子、右孩子的指针（孩子不存在时指针为空）。用代码写就是

```cpp
struct Node {
    int val;
    Node *left, *right;
};
```

但是**输入数据**是一串数字，不可能直接写指针，所以我们需要一种"读一串数字就能唯一确定整棵树形状"的输入约定。本章统一采用**扩展先序遍历**：在正常先序遍历（根→左→右）的基础上，把每一个"本该访问、但其实是空"的位置也输出一个 `-1`。这样从头到尾顺序读入这串数字，每读到一个数就知道"这里应该建一个节点还是这里是空"，从而**递归**地把整棵树的形状唯一还原出来。

例如下面这棵树：

```
        1
       / \
      2   3
     /   / \
    4   5   6
```

它的扩展先序序列是：

```
1 2 4 -1 -1 -1 3 5 -1 -1 6 -1 -1
```

读法：先看到 `1`，建根节点 `1`；接下来递归建它的左子树——看到 `2`，建节点 `2`；再递归建 `2` 的左子树——看到 `4`，建节点 `4`；再递归建 `4` 的左子树——看到 `-1`，说明是空，不建；`4` 的右子树——看到 `-1`，也是空。`4` 建完了，回到 `2`，接着建 `2` 的右子树——看到 `-1`，是空。`2` 建完了，回到根 `1`，接着建 `1` 的右子树——看到 `3`……以此类推。

按照这种方式建好树之后，请你输出这棵树的**中序遍历**（左→根→右）和**后序遍历**（左→右→根）序列。

对上面的例子，中序遍历是 `4 2 1 5 3 6`，后序遍历是 `4 2 5 6 3 1`。

本章后面几道题（层序遍历、统计深度节点数、完全二叉树判断、镜像翻转）都会沿用这套"扩展先序序列"输入约定，务必先理解透彻这道题。
