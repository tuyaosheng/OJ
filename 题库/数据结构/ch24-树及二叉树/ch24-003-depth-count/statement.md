除了遍历，二叉树还有一些常用的"性质统计"：树的**深度**（也叫高度，根节点算第 1 层，最深的叶子所在层数就是深度）、**节点总数**、以及**叶子节点数**（既没有左孩子也没有右孩子的节点）。

这三个量都可以用同一种思路——**递归地把"求整棵树的答案"拆成"求左子树的答案"和"求右子树的答案"，再合并**：

- 深度：`depth(root) = 0`（空树），否则 `depth(root) = 1 + max(depth(左子树), depth(右子树))`。
- 节点数：`count(root) = 0`（空树），否则 `count(root) = 1 + count(左子树) + count(右子树)`。
- 叶子数：`leaf(root) = 0`（空树），否则如果左右孩子都不存在 `leaf(root) = 1`，否则 `leaf(root) = leaf(左子树) + leaf(右子树)`。

依然采用扩展先序序列建树，输出这三个值。

例如对下面这棵树：

```
        1
       / \
      2   3
     /   / \
    4   5   6
```

深度是 3，节点总数是 6，叶子节点数是 3（节点 4、5、6）。
