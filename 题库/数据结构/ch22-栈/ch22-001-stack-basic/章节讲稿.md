# 第 22 章 栈 —— 章节讲稿

## 一、栈是什么

栈（Stack）是一种**只能在一端进出**的线性表结构，这一端叫**栈顶**。特点是**后进先出**（LIFO, Last In First Out）——最后放进去的元素，最先被拿出来。

生活中的例子：一摞叠起来的盘子（只能从最上面拿）、浏览器的"后退"按钮（回退到最近一次访问的页面）、代码编辑器的撤销操作（撤销最近一次修改）。

## 二、两种实现方式

1. **STL `stack<T>`**：C++ 标准库自带，直接 `push`/`pop`/`top`/`empty`/`size`，本章大多数题目建议直接用它。
2. **数组模拟**：开一个数组 `a[]` 和一个"栈顶指针" `top`（初值 -1 或 0，视习惯而定），入栈 `a[++top] = x`，出栈 `top--`，栈顶是 `a[top]`。数组模拟的好处是能清楚看到栈的底层实现，某些题目（比如要遍历整个栈内容而不破坏它）用数组模拟更方便。

## 三、本章的四类考点

1. **栈的基本操作**（例 1）：入栈、出栈、查询栈顶/大小，先把 API 用熟。
2. **括号匹配**（例 2）：栈最经典的应用——遇到左括号就压栈，遇到右括号就检查栈顶是否是对应的左括号。任何"必须严格嵌套、后开的先关"的配对关系，本质都是这个模型。
3. **表达式求值 / 转换**（例 3、练 1）：
   - **逆波兰（后缀）表达式求值**：从左到右扫描，数字入栈，遇到运算符就弹出栈顶两个数字算出结果再压回去，扫描完栈里剩的唯一一个数就是答案。
   - **中缀转后缀（Shunting-yard 算法）**：用一个运算符栈，核心规则是"遇到优先级不高于栈顶的运算符，先把栈顶弹出输出，再把自己压进去"，括号则用来强制打断这个规则。
4. **单调栈**（练 2）：栈里的元素始终保持单调（递增或递减）。经典用途是 `O(n)` 求"每个元素右边（或左边）第一个比它大/小的元素"——暴力做法是双重循环 `O(n^2)`，单调栈能把它优化到 `O(n)`，因为每个元素最多入栈出栈各一次。

## 四、栈 vs 递归

递归函数调用本身就是用"系统栈"实现的——每次调用把当前的局部变量和返回地址压栈，函数返回时弹栈恢复现场。这也是为什么很多用递归写的算法，都能等价地改写成"手动维护一个栈 + 循环"的非递归版本（比如二叉树的非递归遍历）。理解了栈，就更容易理解递归的本质。
