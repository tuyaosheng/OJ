- 用 `stringstream` 或 `cin >>` 按空格切出一个个 token（字符串）。
- 对每个 token：
  - 如果它是数字（可能带负号），转成整数压入栈；
  - 如果它是运算符，从栈里弹出两个数——**先弹出的是右操作数，后弹出的是左操作数**（顺序不能反，减法和除法对顺序敏感），算出结果后把结果压回栈。
- 怎么判断一个 token 是数字还是运算符：本题的运算符 token 长度恒为 `1` 且只可能是 `+ - * /` 这四个字符之一；而负数 token（比如 `"-3"`）长度至少是 `2`。所以判断 `token.size() == 1 && (token[0] 是运算符字符)` 即可区分。
- 扫描完整个表达式后，栈里恰好剩一个数，它就是最终答案。
