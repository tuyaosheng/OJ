- 开一个大小为 `m` 的数组 `a[]`，用两个下标 `front`（队首位置）和 `rear`（下一个入队位置）来标记，初始都为 `0`。
- 入队：`a[rear] = x; rear = (rear + 1) % m;`——**取模**是关键，走到数组末尾后自动"绕回"到开头，这样数组前面被出队腾出来的位置就能被循环利用，不会浪费。
- 出队：`输出 a[front]; front = (front + 1) % m;`。
- 为什么叫"循环"：`% m` 让下标在 `0` 到 `m-1` 之间不断循环，逻辑上数组的最后一格和第一格是"相连"的，就像一个环。
- 如果直接用一个不取模、不断往后增长的下标模拟队列（比如很多同学最初会写的"用一个大数组、front/rear 一直往右走"的版本），当 `n` 很大时数组就要开得很大，非常浪费空间——这正是循环队列要解决的问题。
