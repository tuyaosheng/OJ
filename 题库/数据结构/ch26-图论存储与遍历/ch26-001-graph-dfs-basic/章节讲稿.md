# 第 26 章 图论算法（存储与遍历）—— 章节讲稿

## 一、从树到图

前两章学的二叉树、堆，本质都是"树"——每个节点最多一个父亲，不会有环。**图**是更一般的结构：节点之间的连接不再受"树形"约束，可以任意连接，甚至形成环。生活中大量场景天然就是图：道路网络（城市是点、道路是边）、社交关系（人是点、好友关系是边）、任务依赖（任务是点、"先做A才能做B"是有向边）。

本章聚焦图论最基础的两件事：**怎么存图**、**怎么遍历图**，为后面最短路、并查集、最小生成树等章节打地基。

## 二、图的存储：邻接表

- **邻接矩阵** `g[i][j]`：直观但耗内存，$n$ 大时（比如 $10^5$）根本开不下 $n^2$ 的数组。
- **邻接表** `vector<int> g[MAXN]`：每个点只存它实际连接的邻居，空间 $O(n+m)$，是本章统一使用的存法。

## 三、图的遍历：DFS 与 BFS

- **DFS**（例1）：和树的先序遍历思路一致，一条路走到黑，走不通就回溯；不同点是图可能有环，必须用 `visited` 数组防止死循环。
- **BFS**（例2）：和树的层序遍历思路一致，借助队列一层一层扩展，天然能保证"最先到达的点，走的步数最少"——这是 BFS 求"无权图最短路"的理论基础，也是练5、后面 ch27 学有权图最短路的重要铺垫。

## 四、本章的六类考点

1. **图的存储与基础遍历**（例1、例2）：邻接表建图，分别用 DFS 和 BFS 两种方式访问，体会"递归/栈"与"队列"两种遍历思路在图上的区别（和上一章"树的先序遍历 vs 层序遍历"是同一个道理，只是多了防止成环的标记）。
2. **连通性分析**（例3、例4）：一张图可能不是"浑然一体"的，而是分成若干个互不连通的"连通块"。例3 数连通块个数、例4 求最大连通块的大小，都是"对每个未访问过的点触发一次遍历，把整块标记掉"这一套路的直接应用。
3. **网格图建模**（练1）：很多"迷宫"类问题本质是图——每个格子是一个节点，相邻（上下左右）且都不是墙的格子之间连一条边，转化后直接套用 DFS/BFS 模板。这是把"图论"应用到具体场景的重要一步。
4. **图遍历的扩展应用：二分图判定**（练2）：不仅能判断"能不能到达"，遍历过程中还能给节点打上更多信息（比如交替染色），解决"这张图能不能分成两组，使得每条边都连接不同组的点"这类问题。
5. **建图技巧：由关系构造图**（练3、练4）：很多问题本身看不出是图论题——比如"单词一次改一个字母能否变成另一个单词"，需要你自己想清楚"什么是点、什么是边"，把问题转化成图上的可达性/最短路问题，这是图论里最考验建模能力的部分。
6. **BFS 求最短路径并还原路径**（练5）：不仅要知道最短需要几步，还要能具体输出"走的是哪条路"——用一个 `prev` 数组记录"每个点是从哪个点走过来的"，找到终点后顺着 `prev` 往回倒推，就能还原出完整路径。这是后面学习 Dijkstra 等最短路算法时同样会用到的核心技巧。

## 五、易错点小结

- 无向图的一条边要在两个方向的邻接表里都加一次。
- DFS/BFS 都要有 `visited` 标记，且要在"入队/进入递归"的第一时间标记，不能拖到处理完才标记。
- 图可能不连通，"是否需要对每个未访问的点都触发一次遍历"是连通块类问题的关键。
- 网格图记得处理边界（不能走出网格范围）和"墙"（不能穿过障碍格）。
