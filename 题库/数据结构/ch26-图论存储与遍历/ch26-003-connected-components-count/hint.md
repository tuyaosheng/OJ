本题不要求访问顺序，只关心"能不能到达"，所以不需要排序邻接表，也不需要在意用 DFS 还是 BFS——两者效果完全一样。

如果担心图的形状比较极端（比如所有点连成一条长链）导致递归 DFS 栈溢出，可以放心选择用 BFS 实现这个"标记一整块"的过程，因为 BFS 用的是显式队列，不受系统递归栈深度的限制：

```cpp
int cnt = 0;
for (int i = 1; i <= n; i++) {
    if (!visited[i]) {
        cnt++;
        bfs(i);   // 把 i 所在的整个连通块都标记为已访问
    }
}
cout << cnt << '\n';
```

外层循环 `i` 只是用来"依次寻找还没被处理过的起点"，每个点只会被 `bfs` 真正访问一次，总复杂度仍然是 $O(n+m)$。
