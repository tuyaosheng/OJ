和例1、例2完全一样的并查集模板，唯一的区别是处理顺序：

```cpp
// 第一阶段：把 M 条亲戚关系全部合并
for (int i = 0; i < M; i++) {
    int u, v; cin >> u >> v;
    merge(u, v);
}
// 第二阶段：统一回答 Q 条查询
for (int i = 0; i < Q; i++) {
    int a, b; cin >> a >> b;
    cout << (find(a) == find(b) ? "Yes" : "No") << '\n';
}
```

这种"先合并完、再统一查询"的结构在实际做题时经常遇到——如果发现题目的操作明显分成"建立关系"和"回答问题"两个独立阶段，直接分两段处理即可，不需要强行按输入顺序交替处理。
