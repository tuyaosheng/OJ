## 考点

并查集的基本结构与路径压缩写法，是本章乃至后面"最小生成树""图论进阶"章节都会反复用到的地基。

## 思路

并查集用一个 `fa` 数组表示"每个点的父节点"，一开始每个点的父节点是自己（各自为战）。`find` 递归地沿父指针往上走直到走到根（`fa[x] == x` 的点），`merge` 就是把其中一个根接到另一个根下面。

路径压缩的关键写法是 `fa[x] = find(fa[x])`——**先递归求出根，再把这次查找路径上的当前点直接接到根上**，不是简单地"记住根是谁"，而是真的修改了树的结构，让树越用越扁平。

## 易错点

- `find` 函数一定要写成 `return fa[x] = find(fa[x]);` 这种"边找边压缩"的形式，只调用递归不赋值回 `fa[x]` 就没有压缩效果。
- `merge` 之前一定要先分别对两个点调用 `find` 拿到各自的根，不能直接 `fa[x] = y`（那样操作的是原始节点而不是根，很快会破坏树结构的正确性）。
- 初始化 `fa[i] = i` 不能漏掉，忘记初始化会导致所有 `fa` 值是 0，逻辑全错。
