前面两章学的图遍历（DFS/BFS）已经能判断"两个点是否连通"，但如果图是**动态变化**的——不断有新的连接加进来，同时又要不断地问"这两个点现在连通了吗"——每次都重新跑一遍遍历就太慢了。这一章学习专门解决这类问题的数据结构：**并查集**（Union-Find / Disjoint Set Union，简称 DSU）。

并查集的核心思想很简单：把每个"集合"（连通块）看成一棵树，树里随便哪个节点当"代表"（通常用树根），**同一棵树里的所有点属于同一个集合**。只需要两个操作：

- **`find(x)`**：顺着父指针一路往上走，找到 $x$ 所在树的根，这个根就代表了 $x$ 所在的整个集合。
- **`union(x, y)`**：把 $x$ 所在树的根，接到 $y$ 所在树的根下面（或者反过来），两棵树就合并成了一棵。

判断 $x, y$ 是否属于同一集合，只需要比较 `find(x)` 和 `find(y)` 是否相等。

请你维护 $n$ 个人的"好友圈"关系（初始时每个人各自是一个独立的好友圈），依次处理 $m$ 个操作：

- `1 u v`：把 $u$ 和 $v$ 所在的好友圈合并成一个。
- `2 u v`：查询 $u$ 和 $v$ 现在是否在同一个好友圈里，输出 `Yes` 或 `No`。
